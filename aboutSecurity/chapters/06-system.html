1. 엔드포인트 — 가장 자주 침해되는 전장

엔드포인트(노트북·서버·모바일·IoT)는 사용자가 직접 상호작용하는 지점이며, 동시에 가장 자주 침해되는 자산입니다. 2024년 Verizon DBIR 보고서에 따르면 침해 사건의 약 70%가 엔드포인트에서 시작되거나 경유합니다. 피싱 이메일의 첨부파일, USB로 옮겨온 악성코드, 패치되지 않은 OS·소프트웨어가 대표 경로입니다.

현대 엔드포인트 방어는 단순 안티바이러스를 넘어 EDR(Endpoint Detection & Response), XDR(Extended)로 진화했습니다. EDR은 프로세스 생성·파일 변경·네트워크 연결·레지스트리 수정 등 모든 행위를 텔레메트리로 수집해 행위 기반으로 탐지하고, 침해 시 자동 격리·롤백을 수행합니다. CrowdStrike Falcon, SentinelOne, Microsoft Defender for Endpoint가 대표 상용 제품입니다.

3D · OS 권한 모델: 권한 상승과 격리
멀웨어가 안쪽 링으로 파고드는 과정과 이를 막는 격리.

2. OS 권한 모델 — 최소권한과 분리

운영체제의 보안 모델은 권한 분리의 역사입니다. 유닉스의 user/group/other 권한, Windows의 ACL과 토큰, 모바일의 앱 샌드박스가 모두 같은 원칙을 다른 방식으로 구현합니다. 핵심은 최소권한(Principle of Least Privilege): 각 프로세스는 임무 수행에 꼭 필요한 최소 권한만 가져야 합니다.

리눅스는 capabilities(setcap), seccomp(syscall 화이트리스트), namespaces(컨테이너의 기반), cgroups, SELinux/AppArmor MAC 정책 등의 세분화 도구를 제공합니다. macOS는 SIP(System Integrity Protection)·TCC(Transparency, Consent, Control)·Hardened Runtime·Notarization으로 다층 방어를 구성합니다. Windows는 UAC·AppLocker·WDAC(Windows Defender Application Control)·VBS(Virtualization-Based Security)로 동등한 기능을 제공합니다.

3. 멀웨어의 종류와 동작

멀웨어(malicious software)는 형태에 따라 분류됩니다. ① 바이러스는 다른 실행파일에 자기 코드를 삽입해 전파, ② 웜은 네트워크를 통해 자율 확산(WannaCry 2017), ③ 트로이목마는 정상 프로그램으로 위장, ④ 랜섬웨어는 파일을 암호화하고 몸값을 요구(LockBit·BlackCat), ⑤ 스파이웨어/스토커웨어는 비밀 정보 수집(Pegasus), ⑥ 루트킷은 시스템 깊숙이 숨어 탐지 회피, ⑦ 봇/RAT은 원격 제어 채널 유지(Cobalt Strike).

현대 멀웨어는 점점 fileless·LotL(Living off the Land) 기법을 씁니다. PowerShell, WMI, regsvr32, mshta 같은 정상 OS 도구를 악용해 디스크에 흔적을 거의 남기지 않습니다. 시그니처 기반 AV로는 잡히지 않으므로, 행위·메모리·텔레메트리 기반 EDR이 필수가 된 이유입니다.

4. 컨테이너·클라우드 워크로드 보안

컨테이너는 동일 커널을 공유하기 때문에 격리 수준이 VM보다 약합니다. Docker·containerd는 namespaces·cgroups로 격리하지만 커널 취약점(2019 runC CVE-2019-5736, 2022 dirty pipe CVE-2022-0847)이 직접 호스트 침해로 이어질 수 있습니다. 강화 방안은 ① rootless 모드, ② seccomp default profile, ③ AppArmor/SELinux 강제, ④ read-only root filesystem, ⑤ user namespace, ⑥ gVisor·Kata Containers 같은 추가 격리층입니다.

쿠버네티스 보안의 핵심은 Pod Security Standards(Restricted) 적용, RBAC 최소화, NetworkPolicy(default deny), Secrets 외부화(ESO·Vault), 이미지 서명 검증(cosign + admission controller), 런타임 위협 탐지(Falco·Tetragon)입니다. CNCF의 Cloud Native Security Whitepaper와 NIST SP 800-190이 정석 가이드입니다.

중 · 응용

이론 깊이 들어가기

EDR의 텔레메트리는 OS 후크 지점에 따라 다릅니다. Windows는 ETW(Event Tracing for Windows), 커널 콜백, AMSI(Anti-Malware Scan Interface)로 PowerShell·.NET·VBScript 등 동적 코드 실행을 가시화합니다. macOS는 Endpoint Security Framework(2019부터 KEXT 대체)로 syscall·파일·프로세스 이벤트를 사용자 공간 에이전트에 전달합니다. 리눅스는 audit, eBPF(가장 유연), kprobes·uprobes·tracepoints를 활용합니다. 2024년 CrowdStrike 사태(BSoD 800만 대) 이후 Microsoft는 커널 모드 의존도 축소를 위한 새 API를 제안 중입니다.

탐지 로직은 점점 MITRE ATT&CK 매핑으로 표준화되었습니다. T1059(Command and Scripting), T1055(Process Injection), T1003(Credential Dumping), T1078(Valid Accounts) 같은 기법별로 탐지 룰이 작성되고, 조직의 ATT&CK 커버리지를 heat map으로 시각화합니다. Atomic Red Team, Caldera는 이 ATT&CK 기법을 안전하게 시뮬레이션해 탐지 공백을 검증합니다.

핵심 도구 — 리눅스 강화

# 1. 자동 보안 업데이트 (Ubuntu/Debian)
sudo apt install unattended-upgrades
sudo dpkg-reconfigure -plow unattended-upgrades

# 2. SSH 강화 — /etc/ssh/sshd_config
PermitRootLogin no
PasswordAuthentication no
PubkeyAuthentication yes
MaxAuthTries 3
ClientAliveInterval 300
AllowUsers deploy

# 3. fail2ban — 무차별 대입 자동 차단
sudo apt install fail2ban
# /etc/fail2ban/jail.local 에 ssh, nginx-noscript 등 활성화

# 4. UFW + 최소 포트 노출
sudo ufw default deny incoming
sudo ufw allow 443/tcp
sudo ufw enable

# 5. 감사 로그 + auditd
sudo apt install auditd
sudo auditctl -w /etc/passwd -p wa -k passwd-changes

대표 예제

🦠 예제 1 — 2017 WannaCry 웜

NSA가 비축하다 유출된 EternalBlue 익스플로잇(SMBv1 CVE-2017-0144)을 사용한 자율 확산 랜섬웨어. 단 며칠 만에 150개국 30만 대 이상을 감염시켰고, 영국 NHS는 응급실이 마비됐습니다. 마이크로소프트는 사고 두 달 전 패치를 배포했지만, 미패치 시스템·EOL Windows XP가 광범위했죠. 핵심 교훈: 패치 관리는 보안의 "기본기"이지만 가장 자주 놓치는 영역입니다.

🦠 예제 2 — 2024 CrowdStrike Falcon 사태

7월 19일, CrowdStrike의 Falcon Sensor 채널 파일 업데이트가 Windows 커널을 충돌시켜 전 세계 약 850만 대 BSoD. 항공·은행·병원이 멈췄습니다. 직접 보안 침해는 아니지만, "보안 도구가 단일 실패점이 될 수 있다"는 경고였고, 이후 staged rollout·canary deployment·커널 의존 축소 논의가 가속화되었습니다.

응용 사례

① YARA 룰: 메모리·파일에서 멀웨어 패턴을 매칭하는 사실상의 표준. VT(VirusTotal) Retro Hunt와 결합해 과거 검체에 새 룰을 적용할 수 있습니다. ② Sigma 룰: SIEM 중립적 탐지 룰 언어. ATT&CK 기반 커뮤니티 룰셋이 활발. ③ Sysmon + ELK: 가난한 SOC의 표준 스택. Sysinternals Sysmon이 풍부한 텔레메트리를, Elastic Stack이 검색·시각화를 담당. ④ Memory forensics: Volatility 3, Rekall로 메모리 덤프에서 프로세스·DLL·네트워크 연결·악성 코드를 추출.

⚠️ 자주 하는 실수: ① EDR 깔았다고 안심 — 룰 튜닝·alert 처리 없으면 노이즈만 쌓임. ② Antivirus를 끄고 "느려서"라고 변명 — 가장 빈번한 침해 경로. ③ root/Administrator로 일상 작업 — UAC·sudo는 이유가 있음. ④ "내부망이라 패치 안 해도 됨" — 침해는 외부에서만 오지 않음. ⑤ EDR 로그만 보고 SIEM에 안 보냄 — 다중 소스 상관관계가 핵심.
상 · 심화

전문가 레벨 이해

현대 엔드포인트 보안의 핵심은 운영체제 그 자체에 내장된 보안 메커니즘입니다. macOS는 Apple Silicon의 Secure Enclave·Pointer Authentication·PAC를, Windows는 Hyper-V 기반 VBS·HVCI·Credential Guard·Kernel DMA Protection을, 리눅스는 KASLR·SMEP·SMAP·KPTI·BPF LSM을 활용합니다. 이런 하드웨어·OS 레벨 방어는 사용자 모드 EDR보다 훨씬 회피하기 어렵습니다.

특히 ROP/JOP/COP 같은 코드 재사용 공격에 대응하기 위한 CFI(Control Flow Integrity)와 ARMv8.3+ Pointer Authentication, Intel CET(Shadow Stack + IBT)는 메모리 손상 공격의 게임 체인저입니다. 2024년 Linux 6.6부터 x86 Shadow Stack이 일반 사용자도 활용 가능해졌고, Chrome·Firefox는 이미 기본 활성화입니다.

수학적·정량적 기초

$$\text{ASLR 엔트로피: } H \approx \log_2(2^{n} / \text{page size})$$ $$\text{MTTD} = \frac{\sum (\text{탐지시각} - \text{침해시각})}{\text{사건수}}, \quad \text{MTTR} = \frac{\sum (\text{복구시각} - \text{탐지시각})}{\text{사건수}}$$ $$\text{탐지 정확도: } F1 = 2 \cdot \frac{\text{Precision} \cdot \text{Recall}}{\text{Precision} + \text{Recall}}$$

SOC의 핵심 KPI는 MTTD(평균 탐지 시간)와 MTTR(평균 대응 시간)입니다. Mandiant의 M-Trends 2024 보고서에 따르면 전 세계 평균 dwell time(침해부터 탐지까지)은 약 10일까지 줄어들었습니다(2014년 205일에서). 이 단축은 EDR·XDR·SOAR·CTI 자동화의 누적 결과이며, 동시에 공격자도 더 빨라져서 ransomware 사례에서는 침해부터 암호화까지 평균 5일 미만입니다.

최신 연구와 frontier

① eBPF 기반 보안: Cilium Tetragon, Falco, Pixie 같은 도구가 커널 모듈 없이 syscall·네트워크·파일 이벤트를 실시간 가시화·시행. CrowdStrike·SentinelOne도 eBPF 전환 가속화. ② Confidential Computing: Intel TDX, AMD SEV-SNP, ARM CCA가 메모리·CPU 단위 격리 제공. 클라우드 워크로드의 데이터 처리 중 기밀성을 보장. ③ Post-Exploitation 탐지 강화: BloodHound, SharpHound로 Active Directory 공격경로 시각화 → 방어자가 동일 도구로 사전 점검. ④ Memory-safe 언어 채택: Microsoft·Google·Linux 커널이 Rust 도입 가속. 2024년 Linux 6.8에 Rust로 작성된 첫 드라이버 머지. CVE의 약 70%가 메모리 안전 결함이므로 근본적 영향.

관련 분야 연결

  • 운영체제 이론: 권한 분리, 자원 격리, 가상화 보안
  • 컴파일러: stack canary, fortify source, CFI, sanitizer
  • 하드웨어 보안: TPM, Secure Enclave, TEE, side-channel(Spectre, Meltdown, Rowhammer)
  • 형식 검증: seL4 미세커널, CompCert, Rust borrow checker
  • 데이터 분석: SIEM·UEBA·머신러닝 기반 anomaly detection
