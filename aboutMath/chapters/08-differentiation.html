1. 순간변화율 — "지금 이 순간의 속도"라는 역설

자동차가 2시간에 160km를 갔다면 평균 속도는 80km/h — 이것이 평균변화율 Δy/Δx입니다. 그런데 계기판의 바늘이 가리키는 "지금 이 순간의 속도"는 무엇일까요? 한 순간에는 Δt = 0이라 이동 거리도 0, 0/0이 되어버립니다. 이 역설을 7장의 극한이 해결합니다: 구간을 한없이 줄여 가며 평균변화율의 극한을 취하는 것.

함수 f의 x = a에서의 미분계수를 이렇게 정의합니다: f′(a) = lim_{h→0} (f(a+h) − f(a))/h. 기하적으로는 곡선 위 두 점을 잇는 할선의 기울기가, 두 점이 한없이 가까워지며 접선의 기울기로 수렴하는 것입니다 — 아래 3D의 첫 장면이 정확히 이 과정입니다. 미분이란 "곡선을 한 점에서 확대하면 직선으로 보인다"는 사실에 붙인 이름입니다.

3D · 미분: 할선이 접선이 되는 순간 — 접선 기울기를 모으면 도함수
두 점을 잇는 할선이 접선으로 수렴하는 과정을 봅니다.

2. 도함수 — 기울기를 모은 새 함수

모든 점에서 미분계수를 구해 모으면 새 함수 도함수 f′(x)가 됩니다(위 3D의 둘째 장면: 점이 곡선을 따라가며 접선 기울기가 주황 곡선으로 기록됩니다). 기본 공식은 정의에서 직접 나옵니다: (xⁿ)′ = nxⁿ⁻¹ (이항정리), (sin x)′ = cos x (5장의 sin x/x → 1), (eˣ)′ = eˣ — e가 특별한 이유가 바로 "미분해도 자기 자신"이라는 이 성질입니다.

조합 규칙 네 개로 어떤 함수든 미분합니다: (f+g)′ = f′+g′, 곱의 법칙 (fg)′ = f′g + fg′, 몫의 법칙 (f/g)′ = (f′g − fg′)/g², 그리고 가장 강력한 연쇄법칙 (g(f(x)))′ = g′(f(x))·f′(x) — 3장의 합성함수가 "변화율의 곱"으로 미분됩니다. 안에서 밖으로, 한 겹씩 벗기며 곱하면 됩니다.

3. 도함수로 읽는 함수의 모양

f′의 부호가 f의 운동 방향입니다: f′ > 0인 구간에서 증가, f′ < 0에서 감소. 따라서 f′ = 0이 되는 점(임계점)에서 증가↔감소가 바뀌면 극대·극소가 됩니다(위 3D 셋째 장면 — 접선이 수평이 되는 두 지점). 이차 도함수 f″는 "기울기의 기울기": f″ > 0이면 아래로 볼록(웃는 모양), f″ < 0이면 위로 볼록, 부호가 바뀌는 점이 변곡점입니다.

이것이 최적화의 알고리즘입니다: 닫힌 구간에서 최댓값·최솟값은 임계점과 양 끝점만 비교하면 됩니다(최대·최소 정리가 존재를 보장). "둘레가 일정한 직사각형 중 넓이 최대는 정사각형", "재료가 일정한 캔 중 부피 최대인 비율" — 모든 최적 설계 문제가 f′ = 0 풀기로 환원됩니다.

4. 미분이 여는 세계

뉴턴법: 방정식 f(x) = 0의 근을 접선으로 추적합니다 — xₙ₊₁ = xₙ − f(xₙ)/f′(xₙ). 7장 바빌로니아법의 정체이며, 이차 수렴(정확한 자릿수가 매번 2배)으로 계산기의 √ 버튼부터 딥러닝 최적화 2차 방법까지 쓰입니다. 경사하강법: 다변수 함수에서 기울기(gradient)의 반대 방향으로 한 걸음씩 — 신경망 학습의 전부가 "도함수 따라 내려가기"입니다.

그리고 미분방정식: "변화율이 현재 상태에 비례한다"(y′ = ky)고 쓰면 해는 y = Ce^{kt} — 6장의 지수 성장·감쇠가 미분의 언어로 다시 태어납니다. 행성 궤도, 전염병 모델, 회로, 약물 농도 — 자연 법칙 대부분이 미분방정식으로 표현됩니다. "자연의 언어가 수학"이라는 말의 실체는 사실 미분방정식입니다.

하 · 입문

한 줄로 이해하기

미분은 "지금 이 순간 얼마나 빨리 변하고 있나?"를 재는 도구예요. 그래프 위에 돋보기를 대고 한 점을 무한히 확대하면 곡선이 직선처럼 보이는데, 그 직선(접선)의 기울기가 미분값입니다.

왜 중요한가?

자동차 계기판의 속도, 그래프가 "꺾이는" 최고점·최저점 찾기(가격 최적화, 최대 이익), AI가 학습하는 원리(오차를 줄이는 방향 = 미분의 반대 방향) — 변화가 있는 모든 곳에 미분이 있습니다.

🌱 핵심 용어

  • 평균변화율: (변화량)/(걸린 구간) — 두 점 사이 기울기
  • 미분계수 f′(a): 구간을 0으로 줄인 극한 — 한 점의 기울기
  • 접선: 그 점에서 곡선에 "딱 붙는" 직선
  • 도함수 f′(x): 모든 점의 기울기를 모은 새 함수
  • 극대·극소: 기울기가 0이 되며 방향이 바뀌는 봉우리·골짜기

핵심 개념 풀어쓰기

등산으로 비유하면: f는 산의 높이, f′는 "지금 발밑의 경사"예요. 오르막이면 f′ > 0, 내리막이면 f′ < 0, 정상이나 골짜기에선 잠깐 평평(f′ = 0). 그래서 정상을 찾고 싶으면 "경사가 0인 곳"을 찾으면 됩니다 — 이 단순한 아이디어가 모든 최적화의 핵심이에요. 위 3D에서 점이 곡선을 따라갈 때 접선 색이 초록(오르막)↔빨강(내리막)으로 바뀌는 것을 보세요.

💡 학습 TIP: 미분 공식 연습 전에 "그래프를 보고 도함수 개형 그리기"를 먼저 하세요. 원 함수의 봉우리/골짜기에서 도함수가 0을 지나는지, 가파른 곳에서 도함수가 큰지 — 이 감각이 있으면 공식 계산이 틀렸을 때 스스로 알아챌 수 있습니다.

한 페이지 요약

  • 미분 = 순간변화율 = 접선의 기울기 = 확대하면 보이는 직선
  • (xⁿ)′ = nxⁿ⁻¹: 지수를 앞으로, 지수는 1 감소
  • f′ > 0 증가, f′ < 0 감소, f′ = 0에서 극값 후보
  • (sin)′ = cos, (eˣ)′ = eˣ — e는 "미분해도 그대로"인 유일한 밑
  • 최댓값 찾기 = f′ = 0인 점과 구간 끝점 비교
중 · 응용

이론 깊이 들어가기

정의로 직접 한 번은 계산해야 합니다. f(x) = x²: f′(x) = lim ( (x+h)² − x² )/h = lim (2xh + h²)/h = lim (2x + h) = 2x. 0/0 꼴이 인수분해·약분로 해소되는 것 — 2장의 대수 기술이 극한 계산의 도구가 되는 순간입니다. 미분가능하면 연속이지만 역은 거짓: |x|는 x = 0에서 연속이나 좌우 기울기가 −1, +1로 달라 미분 불가능(뾰족점). "매끄러움"은 연속보다 강한 조건입니다.

이론의 중심 기둥은 평균값 정리(MVT)입니다: [a,b]에서 연속이고 (a,b)에서 미분가능하면 f′(c) = (f(b)−f(a))/(b−a)인 c가 존재 — "평균 속도와 같은 순간 속도가 어딘가에 반드시 있다". 구간 단속 카메라의 원리이고, "f′ = 0이면 f는 상수", "f′ > 0이면 증가" 같은 모든 정리가 MVT에서 나옵니다.

대표 예제

🎯 예제 1 — 상자 최적화

한 변 12인 정사각형 종이의 네 모서리에서 x씩 잘라 상자를 만들 때 부피 V = x(12−2x)². V′ = (12−2x)(12−6x) = 0에서 x = 2 (x = 6은 부피 0). V(2) = 2·64 = 128로 최대. "자르는 만큼 바닥이 줄고 높이가 느는" 상충을 미분이 정확히 중재합니다.

🎯 예제 2 — 연쇄법칙 실전

y = sin(3x²)의 도함수: 바깥(sin)′ = cos을 속 그대로 두고 × 속(3x²)′ = 6x → y′ = 6x cos(3x²). "겉미분 × 속미분"을 겹겹이 — 신경망 역전파(backpropagation)는 이 연쇄법칙을 수백만 번 자동 적용하는 것입니다.

응용 사례

① 물리: 위치를 미분하면 속도, 속도를 미분하면 가속도 — F = ma는 2계 미분방정식. ② 경제: 한계비용·한계수입 = 비용·수입 함수의 도함수, "한계 = marginal = 미분". ③ 딥러닝: 손실함수의 gradient를 연쇄법칙으로 계산(역전파)해 파라미터를 갱신 — GPT의 학습도 본질은 f′ 계산. ④ 그래픽스: 곡선의 법선·곡률 계산, 베지어 곡선의 매끄러운 연결 조건이 도함수 일치입니다.

⚠️ 자주 하는 실수: ① (fg)′ = f′g′ — 곱의 법칙은 f′g + fg′. ② 연쇄법칙에서 속미분 누락: (sin 2x)′ = 2cos 2x. ③ f′(a) = 0이면 무조건 극값 — 거짓(f(x) = x³의 x = 0은 극값 아님, 부호 변화 확인 필수). ④ 분수함수를 몫의 법칙 없이 항별 미분. ⑤ 극값(local)과 최값(global) 혼동 — 끝점 비교를 잊지 말 것.
상 · 심화

전문가 레벨 이해

미분의 현대적 정의는 "선형 근사"입니다: f(a+h) = f(a) + f′(a)h + o(h) — 미분가능이란 국소적으로 일차함수(선형사상)로 근사된다는 뜻이고, f′(a)는 그 선형사상입니다. 이 관점이어야 다변수로 일반화됩니다: 도함수는 수가 아니라 야코비 행렬이라는 선형사상이 되고, 연쇄법칙은 "선형사상의 합성 = 행렬 곱"이라는 한 줄이 됩니다.

더 밀면 테일러 전개: f(a+h) = Σ f⁽ⁿ⁾(a)hⁿ/n! — 매끄러운 함수를 다항식의 극한으로 복원합니다. sin, cos, eˣ의 급수(5장)가 이렇게 나오며, "함수의 모든 정보가 한 점의 미분계수들에 담긴다"는 해석함수의 강성(rigidity)으로 이어집니다. 단 주의: 모든 도함수가 존재해도 급수가 함수와 다를 수 있습니다(e^{−1/x²}의 유명한 반례 — 매끄러움 ≠ 해석성).

수학적·정량적 기초

미분가능 ⟺ f(a+h) = f(a) + Lh + o(h), L = f′(a)
MVT: ∃c∈(a,b), f′(c) = (f(b)−f(a))/(b−a)
테일러: f(x) = Σₖ f⁽ᵏ⁾(a)(x−a)ᵏ/k! + Rₙ, 뉴턴법: xₙ₊₁ = xₙ − f/f′

뉴턴법의 이차 수렴 증명이 테일러 전개의 직접 응용입니다: 근 r 근처에서 eₙ₊₁ ≈ (f″(r)/2f′(r))·eₙ² — 오차가 제곱으로 줄어듭니다. 반면 f′(r) = 0(중근)이면 선형 수렴으로 격하 — 알고리즘의 성능이 함수의 미분 구조에 의해 결정되는 전형입니다.

최신 연구와 frontier

① 자동미분(AD): 연쇄법칙을 계산 그래프에 기계적으로 적용해 기계 정밀도의 도함수를 얻는 기술 — PyTorch/JAX의 심장이며, 수치미분(차분)과 기호미분을 모두 대체. ② 비평활 해석: ReLU처럼 미분 불가능한 점이 있는 함수의 서브그래디언트 이론 — 현대 최적화의 표준 장비. ③ 신경 미분방정식(Neural ODE): 신경망의 층을 연속 시간 흐름으로 보는 관점, 잔차망(ResNet)의 극한.

관련 분야 연결

  • 물리학: 운동방정식, 변분법(최소작용의 원리)
