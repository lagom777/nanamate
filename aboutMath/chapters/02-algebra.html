1. 방정식 — "모르는 수"를 다루는 기술

대수(algebra)의 출발점은 단순합니다: 모르는 수를 문자 x로 부르고, 알고 있는 관계를 등식으로 적은 뒤, 양변에 같은 연산을 가해 x를 고립시키는 것. 등식의 성질(양변에 같은 수를 더하거나, 0이 아닌 같은 수를 곱해도 등식은 유지된다)이 유일한 규칙입니다. ax + b = 0 꼴의 일차방정식은 해가 정확히 하나(x = −b/a)입니다.

이차방정식 ax² + bx + c = 0 (a≠0)부터 이야기가 흥미로워집니다. 근의 공식 x = (−b ± √(b²−4ac)) / 2a 에서 루트 안의 값 판별식 D = b²−4ac가 해의 운명을 결정합니다. D > 0이면 서로 다른 두 실근, D = 0이면 중근(하나), D < 0이면 실근이 없습니다. 기하적으로는 포물선 y = ax²+bx+c가 x축과 두 점에서 만나는가, 접하는가, 만나지 않는가의 문제입니다. 그런데 "실근이 없다"는 말은 끝이 아닙니다 — 아래 3D에서 보듯, 근은 사라지는 것이 아니라 보이지 않는 방향(허수축)으로 이동할 뿐입니다.

포물선이 내려오면서 x축과 만나는 점(근)이 어떻게 변하는지 봅니다.

2. 근과 계수의 관계 — 비에타 공식

이차방정식의 두 근을 α, β라 하면 전개 비교로 즉시 α + β = −b/a, αβ = c/a를 얻습니다(비에타 공식). 근을 직접 구하지 않고도 근에 대한 정보를 끌어낼 수 있어, "두 근의 제곱의 합을 구하라" 같은 문제는 α²+β² = (α+β)² − 2αβ로 근의 공식 없이 풀립니다.

역으로 두 수의 합 s와 곱 p를 알면 그 두 수는 t² − st + p = 0의 근입니다. "합이 7, 곱이 12인 두 수"는 t²−7t+12 = 0, 즉 (t−3)(t−4) = 0에서 3과 4. 방정식과 근은 서로를 완전히 결정하는 쌍둥이 정보입니다.

3. 다항식의 구조 — 인수분해와 나머지정리

다항식 P(x)를 (x−a)로 나눈 나머지는 정확히 P(a)입니다(나머지정리). 특히 P(a) = 0이면 (x−a)가 P(x)의 인수입니다(인수정리). 즉 "근을 하나 찾으면 차수를 하나 낮출 수 있다"는 것 — 고차방정식 풀이의 기본 전략입니다. 예: P(x) = x³−6x²+11x−6은 P(1)=0이므로 (x−1)로 나누면 x²−5x+6 = (x−2)(x−3), 따라서 근은 1, 2, 3.

자주 쓰는 인수분해 공식은 손에 익혀야 합니다: a²−b² = (a+b)(a−b), a³±b³ = (a±b)(a²∓ab+b²), x²+(p+q)x+pq = (x+p)(x+q). 인수분해는 "곱셈 공식을 거꾸로 읽는 것"이며, 방정식 풀이·약분·극한 계산(7장)에서 끝없이 재사용됩니다.

4. 복소수 — 마지막 확장, 그리고 완성

x² = −1을 풀기 위해 새 수 i (i² = −1)를 도입하면, 모든 복소수는 a + bi 꼴로 쓰입니다. 복소수는 평면의 점 (a, b)로 시각화되며(복소평면), 덧셈은 벡터 덧셈, 곱셈은 "회전 + 확대"가 됩니다. D < 0인 이차방정식의 두 근은 켤레 복소수 쌍 (−b ± i√|D|)/2a — 실수축에서 벗어나 허수축 방향으로 대칭 이동한 위치입니다.

복소수의 위대함은 대수학의 기본정리에 있습니다: n차 다항방정식은 복소수 범위에서 (중복 포함) 정확히 n개의 근을 가진다. 1장의 수 확장 서사(ℕ→ℤ→ℚ→ℝ→ℂ)는 여기서 완성됩니다 — 복소수에서는 더 이상 "풀 수 없는 다항방정식"이 없습니다.

🌟 한 줄 요약

방정식 풀기는 "양팔 저울의 균형을 지키며 x만 혼자 남기기" 게임이에요! 이차방정식은 답이 많아야 2개고, 판별식 D의 부호만 보면 풀기 전에 답이 몇 개인지 알 수 있어요.

🤔 이걸 왜 배워요?

공을 던지면 언제 땅에 떨어질까(물리), 얼마에 팔아야 이익이 최대일까(장사), 게임 캐릭터 둘이 언제 부딪힐까 — 전부 이차방정식이에요.

🌱 꼭 아는 말

  • 방정식: x를 잘 넣어야 참이 되는 식 — 그 x 찾기가 "풀기"
  • 근(답): 방정식을 참으로 만드는 x 값
  • 판별식 D = b²−4ac: 답 개수를 알려주는 신호등 (+: 2개, 0: 1개, −: 없음)
  • 인수분해: 식을 곱셈 꼴로 쪼개기 — (x−2)(x−3)=0이면 답이 바로 보여요
  • 허수 i: i² = −1인 신기한 수 — "실수 답 없음"의 답이 사는 곳

🍕 쉽게 풀어보기

저울 한쪽에 x+3, 반대쪽에 7이 있어요. 양쪽에서 똑같이 3을 덜어내면 x=4! 항상 "양쪽에 똑같이"가 규칙이에요. 이차방정식은 U자 곡선(포물선)을 위아래로 움직이는 것과 같아요. 푹 내려가면 바닥선을 두 번 통과(답 2개), 살짝 닿으면 한 번(중근), 떠 있으면 안 만나요(실수 답 없음). 위 3D가 바로 그 장면이에요.

💡 꿀팁: 답을 구했으면 꼭 원래 식에 다시 넣어 0이 되는지 검산! 그리고 풀기 전에 D부터 계산하면 "답 없는 문제"에 헛시간을 안 써요.

📌 한 장 정리

  • 저울 균형 지키며 x 혼자 남기기 (일차방정식 답은 1개)
  • 이차방정식: 인수분해가 되면 인수분해, 안 되면 근의 공식
  • D > 0 답 2개 / D = 0 답 1개 / D < 0 실수 답 없음
  • 두 근의 합 = −b/a, 곱 = c/a
  • 허수까지 쓰면 n차 방정식은 답이 딱 n개 (대수학의 기본정리)
중 · 응용

이론 깊이 들어가기

근의 공식은 완전제곱식 만들기에서 나옵니다. ax²+bx+c = 0의 양변을 a로 나누고 (b/2a)²을 더했다 빼면 (x + b/2a)² = (b²−4ac)/4a². 좌변은 제곱이므로 우변의 부호가 모든 것을 결정합니다 — 판별식이 "루트 안"에 있는 이유가 이것입니다. 같은 변형이 포물선의 꼭짓점 좌표 (−b/2a, −D/4a)도 줍니다. 공식 암기가 아니라 변형 과정 자체가 내용입니다.

3차·4차 방정식에도 근의 공식이 존재하지만(카르다노 1545, 페라리), 5차 이상은 거듭제곱근으로 푸는 일반 공식이 존재하지 않습니다(아벨–루피니 정리). 이 불가능성의 증명에서 군론(갈루아 이론)이 탄생했습니다 — "풀 수 없음"의 증명이 새 수학을 만든 대표 사례입니다.

대표 예제

🎯 예제 1 — 던진 공의 체공 시간

초속 20m로 위로 던진 공의 높이는 h(t) = 20t − 5t². 땅에 닿는 시각은 20t − 5t² = 0, 즉 5t(4 − t) = 0에서 t = 4초. 최고 높이는 꼭짓점 t = 2에서 h(2) = 20m. 인수분해 한 번으로 체공 시간과 최고점이 모두 나옵니다.

🎯 예제 2 — 비에타로 빠르게

x²−6x+2 = 0의 두 근 α, β에 대해 α²+β²은? 근을 구하지 않고 α+β = 6, αβ = 2이므로 α²+β² = 6²−2·2 = 32. 근의 공식으로 √7이 들어간 근을 구해 제곱하는 것보다 압도적으로 빠릅니다.

응용 사례

① 컴퓨터 그래픽스: 광선과 구(sphere)의 교차 판정은 이차방정식이며, 판별식의 부호가 "광선이 구를 비껴가는가/스치는가/관통하는가"를 그대로 판정합니다 — 레이트레이싱의 심장. ② 제어공학: 시스템 특성방정식의 근(극점)의 위치가 안정성을 결정 — 복소근의 실부가 음수여야 안정. ③ 금융: 손익분기 분석에서 이익 함수의 근이 분기점.

⚠️ 자주 하는 실수: ① 양변을 x로 나누어 근 x=0을 잃어버림 — 나누지 말고 인수분해로 묶을 것. ② D=0과 "근이 없다" 혼동 — D=0은 중근 1개. ③ 근의 공식에서 −b의 부호 실수와 2a가 분모 전체에 걸린다는 사실 누락. ④ 이차"함수"와 이차"방정식" 혼동 — 방정식의 근 = 함수 그래프와 x축의 교점의 x좌표.
상 · 심화

전문가 레벨 이해

대수학의 기본정리(FTA)는 이름과 달리 순수 대수만으로는 증명되지 않습니다 — ℝ의 완비성(해석적 성질)이 반드시 들어갑니다. 표준 증명은 복소해석의 리우빌 정리("유계인 전해석 함수는 상수")를 쓰며, 위상적 증명(편각 원리: 큰 원의 상이 원점을 n바퀴 감는다)도 우아합니다. "n차 다항식 ⇒ 근 n개"는 결국 ℂ가 대수적으로 닫힌 체라는 선언입니다.

갈루아 이론의 관점에서 방정식의 "풀 수 있음"은 그 방정식의 갈루아 군이 가해군(solvable group)인가와 동치입니다. 일반 5차 방정식의 갈루아 군은 S₅이고 S₅는 가해군이 아니므로 거듭제곱근 공식이 불가능합니다. 반면 x⁵−2 = 0처럼 특수한 5차는 풀립니다 — 불가능한 것은 "일반 공식"입니다.

수학적·정량적 기초

완전제곱: a(x + b/2a)² = D/4a   |   꼭짓점 (−b/2a, −D/4a)
비에타 일반형: x^n − e₁x^(n−1) + e₂x^(n−2) − … = 0, eₖ = 근들의 k차 기본대칭식
FTA: P ∈ ℂ[x], deg P = n ≥ 1 ⇒ P(z) = a∏(z − zᵢ), 근 n개

수치적으로 근을 구할 때는 근의 공식조차 위험할 수 있습니다. b² ≫ 4ac이면 −b + √(b²−4ac)에서 자릿수 소거(catastrophic cancellation)가 일어나므로, 실무에서는 q = −(b + sign(b)√D)/2로 두고 x₁ = q/a, x₂ = c/q를 씁니다 — 곱 αβ = c/a (비에타!)를 이용한 안정화입니다.

최신 연구와 frontier

① 수치대수기하: 다항식 연립계의 근 전부를 추적하는 호모토피 연속법(Bertini, HomotopyContinuation.jl)이 로봇 기구학·화학 평형 계산에 실전 투입. ② 희소 다항식: 항 개수가 적은 다항식의 근 개수에 대한 데카르트 부호 규칙의 고차원 일반화는 여전히 미해결(Kushnirenko 추측 관련). ③ 기계 증명: FTA의 Lean/Coq 형식화는 완료되어 mathlib에 수록.
