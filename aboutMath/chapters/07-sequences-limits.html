1. 수열 — 자연수를 입력받는 함수

수열은 자연수 n마다 수 aₙ을 대응시키는 함수입니다(3장의 함수 개념 그대로, 정의역만 ℕ). 두 기본형이 모든 것의 출발점입니다. 등차수열: 일정한 차 d로 더해감, aₙ = a₁ + (n−1)d, 합 Sₙ = n(a₁+aₙ)/2 — 가우스가 1+2+…+100 = 5050을 즉답한 "앞뒤로 접어 더하기"가 이 공식입니다. 등비수열: 일정한 비 r로 곱해감, aₙ = a₁rⁿ⁻¹, 합 Sₙ = a₁(1−rⁿ)/(1−r) — 6장의 지수 성장을 이산적으로 본 것입니다.

점화식 aₙ₊₁ = f(aₙ)은 수열을 "규칙"으로 정의하는 방식입니다. 피보나치 수열 aₙ₊₂ = aₙ₊₁ + aₙ이 대표적이고, 컴퓨터 과학의 재귀, 인구 모델, 이자 계산 모두 점화식의 언어를 씁니다. 이 장의 진짜 주제는 그 다음 질문입니다: n이 한없이 커지면 aₙ은 어디로 가는가?

3D · 수렴의 풍경: ε 띠 안으로 들어가는 점들, e로 오르는 계단, 1을 채우는 무한합
수열의 점들이 극한값으로 모여드는 과정을 봅니다.

2. 극한 — "한없이 가까워진다"를 엄밀하게

aₙ = 1/n은 0이 되지는 않지만 0에 한없이 가까워집니다. 이 직관을 19세기 수학은 다음과 같이 못 박았습니다(ε-N 정의): 어떤 작은 양수 ε을 잡아도, 어떤 번호 N 이후의 모든 항이 극한 L과의 거리 ε 안에 들어온다면 aₙ → L. 위 3D의 첫 장면이 이 정의 그 자체입니다 — 띠(ε)를 아무리 좁혀도, 충분히 큰 n부터는 모든 점이 띠 안에 들어옵니다. "무한히 가까이"라는 시적 표현이 "유한 개의 예외만 허용"이라는 검증 가능한 조건으로 바뀐 것이 해석학의 탄생입니다.

극한은 사칙연산과 사이좋게 지냅니다: aₙ→α, bₙ→β이면 aₙ±bₙ→α±β, aₙbₙ→αβ, aₙ/bₙ→α/β (β≠0). 그리고 샌드위치 정리: aₙ ≤ cₙ ≤ bₙ이고 양끝이 같은 L로 가면 가운데도 L로 — 5장의 sin x/x → 1이 이 정리의 작품입니다.

3. 단조수렴정리와 e — 1장의 완비성이 일하는 순간

모든 수열이 수렴하지는 않습니다(1, −1, 1, −1, …은 진동, n²은 발산). 수렴을 보장하는 가장 중요한 정리가 단조수렴정리입니다: 증가하면서 위로 유계인 수열은 반드시 수렴한다. 증명의 엔진이 바로 1장의 실수 완비성(상한의 존재)입니다 — 유리수 세계라면 "수렴할 곳"이 구멍일 수 있어 이 정리가 무너집니다.

대표 응용이 aₙ = (1 + 1/n)ⁿ입니다. 이항정리로 펼치면 이 수열은 증가하고 3보다 작음을 보일 수 있습니다 — 따라서 수렴하고, 그 극한을 e ≈ 2.71828이라 부릅니다. 6장의 "연속 복리"가 여기서 정식 시민권을 얻습니다: 100% 이율을 무한히 잘게 나눠 복리로 불리면 원금의 정확히 e배.

4. 급수 — 무한히 더한다는 것

수열의 항을 무한히 더한 것이 급수 Σaₙ이고, 그 정의는 "부분합 수열 Sₙ = a₁+…+aₙ의 극한"입니다 — 무한합도 결국 극한입니다. 핵심 사례인 등비급수: |r| < 1이면 Σ a rⁿ⁻¹ = a/(1−r). 예컨대 ½ + ¼ + ⅛ + … = 1 — 위 3D의 마지막 장면처럼, 정사각형의 절반, 남은 것의 절반…을 무한히 채우면 정확히 전체가 됩니다. 제논의 "아킬레스는 거북을 못 따라잡는다" 역설은 무한 개의 양수를 더해도 유한할 수 있다는 이 사실로 해소됩니다.

주의 사례 하나: 조화급수 1 + ½ + ⅓ + ¼ + …는 항이 0으로 가는데도 발산합니다(묶음 비교: ⅓+¼ > ½, ⅕+…+⅛ > ½, …). "항이 0으로 간다"는 수렴의 필요조건일 뿐 충분조건이 아닙니다 — 무한을 다룰 때 직관이 처음으로 배신하는 지점이자, 8~9장의 미적분이 요구하는 엄밀함의 이유입니다.

aₙ→L ⟺ ∀ε>0 ∃N: n≥N ⇒ |aₙ−L|<ε  |  (1+1/n)ⁿ → e  |  |r|<1 ⇒ Σarⁿ⁻¹ = a/(1−r)

하 · 입문

한 줄로 이해하기

수열은 "번호 붙은 수의 줄", 극한은 "그 줄이 결국 도착하는 곳"이에요. 1/2, 1/3, 1/4, …는 0에 도착하지는 않지만, 0이 "도착지"라는 것은 누구나 압니다 — 그 직관을 정확한 약속으로 만든 것이 극한입니다.

왜 중요한가?

스마트폰 화면의 곡선이 매끄러워 보이는 것(픽셀의 극한), 적금의 복리 계산, 0.999… = 1 논쟁, 그리고 다음 두 장(미분·적분)의 모든 정의 — 전부 극한 위에 서 있습니다. 극한은 미적분이라는 건물의 기초 공사입니다.

🌱 핵심 용어

  • 등차수열: 같은 수를 더해감 (3, 7, 11, 15, …)
  • 등비수열: 같은 수를 곱해감 (3, 6, 12, 24, …)
  • 수렴: 한 값에 한없이 가까워짐 / 발산: 그렇지 않음
  • 극한값: 수렴이 도착하는 그 값
  • 급수: 수열을 무한히 더한 것 — 부분합의 극한

핵심 개념 풀어쓰기

"한없이 가까워진다"를 게임으로 만들면 극한의 정의가 됩니다. 상대가 "0.001 안으로 들어와 봐"라고 도전하면(ε), 나는 "1001번째 항부터는 전부 들어가 있어"라고 답합니다(N). 상대가 아무리 작은 수로 도전해도 내가 항상 답할 수 있으면 — 그게 "수렴한다"입니다. 위 3D에서 띠가 좁아져도 점들이 결국 다 들어가는 장면이 이 게임의 시각화예요.

💡 학습 TIP: 수열 문제를 만나면 첫 몇 항을 직접 계산해서 나열해 보세요(최소 4~5개). 등차인지 등비인지, 커지는지 작아지는지, 어디로 가는 것 같은지 — 패턴이 보이면 공식은 따라옵니다. "공식 먼저"가 아니라 "항 먼저"가 정석입니다.

한 페이지 요약

  • 등차: aₙ = a+(n−1)d, 합 = n(첫항+끝항)/2
  • 등비: aₙ = arⁿ⁻¹, |r|<1이면 무한합 = a/(1−r)
  • 수렴 = 어떤 ε 띠를 줘도 유한 개 빼고 다 들어감
  • 증가 + 위로 막힘 ⇒ 반드시 수렴 (단조수렴정리)
  • ½+¼+⅛+… = 1, 하지만 1+½+⅓+…는 발산
중 · 응용

이론 깊이 들어가기

ε-N 정의로 실제 증명을 한번 써 보면 안개가 걷힙니다. aₙ = (2n+1)/(n+3) → 2의 증명: |aₙ−2| = |(2n+1−2n−6)/(n+3)| = 5/(n+3). ε이 주어지면 5/(n+3) < ε ⟺ n > 5/ε − 3이므로 N = ⌈5/ε⌉로 잡으면 충분합니다. 패턴은 항상 같습니다: |aₙ−L|을 n의 식으로 정리 → ε보다 작아지는 N 찾기.

점화식 수열의 극한 구하기 2단계: ① 극한 L이 존재한다고 가정하면 L = f(L)에서 후보를 구함(예: aₙ₊₁ = ½aₙ + 3 → L = ½L+3 → L = 6), ② 존재 자체는 단조수렴정리 등으로 별도 증명. ②를 건너뛰면 함정에 빠집니다 — aₙ₊₁ = 2aₙ에서 L = 2L → L = 0이라고 답하면 틀리는 이유(발산하므로 가정 자체가 거짓).

대표 예제

🎯 예제 1 — 대출 상환의 등비급수

매달 일정액 m을 갚는 원리금균등상환에서, 대출 원금 P는 미래 상환액들의 현재가치 합: P = m/(1+i) + m/(1+i)² + … + m/(1+i)ⁿ — 등비급수 합으로 m = P·i(1+i)ⁿ/((1+i)ⁿ−1). 은행 앱의 월 상환액 계산기가 이 공식입니다.

🎯 예제 2 — 재귀 알고리즘의 수렴

√2를 구하는 바빌로니아법 aₙ₊₁ = (aₙ + 2/aₙ)/2는 a₁=2에서 2, 1.5, 1.41667, 1.414216… 으로 4번 만에 소수 5자리 정확도에 도달합니다. 극한 가정 시 L = (L+2/L)/2 → L² = 2. 뉴턴법(8장)의 원형이자 "수열 = 계산 알고리즘"의 표본입니다.

응용 사례

① 수치해석: 모든 반복 알고리즘(경사하강법 포함)의 분석은 "이 수열이 수렴하는가, 얼마나 빨리?"라는 질문입니다. ② 프랙탈: 망델브로 집합은 zₙ₊₁ = zₙ²+c가 발산하지 않는 c의 집합 — 수렴/발산의 경계가 만드는 무한 복잡성. ③ 경제학: 승수효과(정부지출 1단위 → 1+c+c²+… = 1/(1−c) 단위의 총수요)는 등비급수입니다.

⚠️ 자주 하는 실수: ① "항이 0으로 가면 급수 수렴" — 거짓(조화급수). ② 무한합에 유한합의 직관 적용: 수렴하지 않는 급수의 항 재배열·괄호 치기는 값을 바꿉니다. ③ 등비급수 공식을 |r| ≥ 1에 적용. ④ 점화식에서 극한 존재 증명 생략. ⑤ ∞−∞, ∞/∞를 0이나 1로 단정 — 부정형은 항별 분석이 필요합니다.
상 · 심화

전문가 레벨 이해

수렴의 내재적 판정이 코시 수열입니다: 극한값을 모르더라도 "항들끼리의 거리가 임의로 작아지면"(∀ε ∃N: m,n≥N ⇒ |aₘ−aₙ|<ε) 수렴을 보장 — 단, 공간이 완비일 때만. ℝ에서는 코시 ⟺ 수렴이지만 ℚ에서는 실패합니다(√2로 가는 유리수열은 코시지만 ℚ 안에 극한이 없음). 1장의 완비성이 "코시 수열의 수렴"으로 재정식화되는 것이며, 이 성질로 ℝ를 구성하는 것이 칸토어의 방법입니다.

부분수열의 관점도 필수입니다. 볼차노–바이어슈트라스 정리: 유계 수열은 수렴하는 부분수열을 가진다 — 최대·최소 정리(9장)와 컴팩트성 개념의 씨앗입니다. 진동하는 1, −1, 1, −1, …도 부분수열은 수렴하며(1로, 또는 −1로), 부분수열 극한들의 집합(집적점)이 수열의 "장기 행동"을 분류합니다.

수학적·정량적 기초

코시: ∀ε>0 ∃N: m,n≥N ⇒ |aₘ−aₙ| < ε
수렴 속도: |aₙ₊₁−L| ≤ C|aₙ−L|^p — p=1 선형, p=2 이차(뉴턴법)
Σ1/n² = π²/6 (바젤 문제)  |  Σ1/n^s = ζ(s)

수렴 "속도"는 응용의 생명입니다. 바빌로니아법이 4번 만에 끝나는 이유는 이차 수렴(자릿수가 매번 2배)이기 때문이고, 경사하강법의 선형 수렴과 뉴턴법의 이차 수렴 차이가 최적화 알고리즘 선택을 좌우합니다. 한편 Σ1/n²= π²/6(오일러, 1734)에서 출발한 ζ(s)의 연구는 리만 가설 — ζ의 비자명 영점은 모두 실부 ½ — 로 이어지며, 이는 현재 수학 최대의 미해결 문제입니다.

최신 연구와 frontier

① 가속 기법: Aitken Δ², Anderson acceleration — 느린 수열의 수렴을 외삽으로 가속, 딥러닝 옵티마이저(모멘텀, Adam)도 본질적으로 수열 가속. ② 에르고딕 이론: 수열의 시간 평균과 공간 평균의 일치 — 동역학계와 통계역학의 다리. ③ 초일관 수열 공간: 발산급수에 값을 주는 보렐 합·체사로 합이 양자장론의 재규격화에서 실제로 쓰입니다(1+2+3+… "=" −1/12의 정체).

관련 분야 연결

  • 동역학계: 점화식 = 이산 동역학, 고정점과 카오스
