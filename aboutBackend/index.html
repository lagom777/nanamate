백엔드 개발이란?

백엔드는 사용자에게 보이지 않는 서버 측 로직을 담당합니다. 클라이언트의 요청을 받아 비즈니스 로직을 처리하고, 데이터베이스와 통신하며, 안전하게 응답을 돌려보내는 모든 과정이 백엔드의 영역입니다.

이 학습 사이트에서는 Three.js 3D 시각화를 통해 서버 아키텍처, API 흐름, 인증 과정, 배포 파이프라인 등을 입체적으로 체험합니다. 단순히 코드를 읽는 것이 아니라, 데이터가 어떻게 흘러가는지 직접 눈으로 보며 직관을 쌓아가세요.

학습 로드맵

🖥️ 챕터 1–2: 서버와 API 기초

클라이언트-서버 모델, TCP/IP, HTTP 프로토콜, RESTful API 설계 원칙. 3D로 요청-응답 흐름을 시뮬레이션합니다.

⚡ 챕터 3: Node.js 실전

이벤트 루프, Express 프레임워크, 라우트 정의. 이벤트 루프의 동작 과정을 3D 애니메이션으로 관찰합니다.

🔒 챕터 4–5: 보안과 미들웨어

JWT 인증, OAuth2, 미들웨어 체인, 에러 핸들링. 인증 흐름과 미들웨어 파이프라인을 시각화합니다.

📦 챕터 6–7: 데이터 처리

파일 업로드, 스트리밍, Redis 캐싱, 메시지 큐. 데이터 청크가 파이프를 통해 흐르는 모습을 체험합니다.

🐳 챕터 8–9: 아키텍처와 배포

마이크로서비스, API Gateway, Docker, CI/CD 파이프라인. 분산 아키텍처와 배포 과정을 3D로 탐험합니다.

백엔드의 핵심 흐름

REQ → Router → Middleware → Handler → DB → RES
node server.js Server listening on port 3000... ✓ Connected to database ✓ Middleware loaded → GET /api/users 200 12ms → POST /api/auth/login 200 45ms

각 챕터에서는 이 흐름의 각 단계를 깊이 있게 탐구합니다. 왼쪽 사이드바에서 챕터를 선택하여 학습을 시작하세요.
