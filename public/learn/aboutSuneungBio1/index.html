생명과학의 이해
생물의 특성, 그리고 가설을 세우고 변인을 통제하는 탐구 방법
기출 →
물질대사
먹은 것을 세포 호흡으로 분해해 ATP를 만들고, 노폐물은 내보낸다. 에너지 균형이 깨지면 대사성 질환이 된다
기출 →
흥분 전도
Na⁺이 들어오면 막전위가 +로(탈분극), K⁺이 나가면 −로(재분극) 바뀐다
기출 →
근수축
액틴 필라멘트가 마이오신 사이로 미끄러져 들어간다 (A대 길이는 그대로, I대와 H대가 줄어든다)
기출 →
신경계
뇌는 부위마다 맡은 일이 있고, 교감 신경과 부교감 신경은 서로 반대로 일한다
기출 →
항상성
간뇌의 시상 하부가 조절 중추이고, 음성 피드백과 길항 작용(인슐린 ↔ 글루카곤)으로 유지된다
기출 →
방어 작용
비특이적 방어가 먼저 막고, 특이적 방어는 처음엔 느리게, 두 번째는 기억 세포 덕분에 빠르고 강하게 막는다
기출 →
염색체·DNA 양
DNA 양은 복제하면 2배, 분열할 때마다 절반이 된다. 핵상(2n·n)과 DNA 상대량으로 어느 세포인지 가려낸다
기출 →
세포 분열
체세포 분열은 2n → 2n, 감수 1분열에서 상동 염색체가 갈라져 2n → n이 된다
기출 →
유전(가계도)
가계도는 우열 → 상염색체/X 염색체 → 유전자형 → 확률 순서로 푼다 (DNA 상대량 표가 있으면 염색체 위치부터)
기출 →
다인자·복대립
다인자 유전은 대문자 대립유전자의 수가 표현형을 정한다. 부모 유전자형에서 표현형 가짓수와 확률을 센다
기출 →
돌연변이
염색체 비분리가 감수 1분열에서 일어나면 생식세포 4개가 모두 이상, 2분열이면 2개만 이상이다
기출 →
생태계
같은 종끼리(개체군), 다른 종끼리(군집) 어떻게 얽혀 사는지 배운다
기출 →
에너지·물질
에너지는 한 방향으로 흐르며 줄어들고, 물질(탄소·질소)은 돌고 돈다
기출 →
생물 다양성
유전적 다양성·종 다양성·생태계 다양성, 그리고 이것을 지키는 방법

이 노트가 다루는 것

수능 생명과학Ⅰ의 전 범위를 다섯 단원, 여덟 파트로 나눠 정리했습니다. 각 파트는 개념 정리 → 표·그래프 읽는 법 → 기출에서 반복되는 함정 → 대표 예제 → 짝짓기·퀴즈 → 실제 기출 풀어보기 순으로 이어지며, 파트마다 모션 노트의 해당 장면으로 바로 이동할 수 있습니다.
