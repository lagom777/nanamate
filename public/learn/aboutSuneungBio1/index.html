수능 생명과학Ⅰ의 전 범위를 다섯 단원, 여덟 파트로 나눠 정리했습니다. 각 파트는 개념 정리 → 표·그래프 읽는 법 → 기출에서 반복되는 함정 → 대표 예제 → 짝짓기·퀴즈 → 실제 기출 풀어보기 순으로 이어지며, 파트마다 모션 노트의 해당 장면으로 바로 이동할 수 있습니다.

20문항 · 50점 · 30분. 2점 10문항 + 3점 10문항. 자료(표·그래프·가계도)를 해석해 보기 ㄱ·ㄴ·ㄷ의 참/거짓을 가리는 5지 선다입니다. 3점 문항은 뒤쪽에 더 많고 유전 문항이 가장 어렵습니다.
