회당 3문항 이상이 나오는 가장 큰 파트이고, 수능의 최고난도 3점 문항(16~19번)이 여기서 나옵니다. 가계도로 유전 방식을 정하고 DNA 상대량 표와 결합해 유전자형을 확정하는 고정된 풀이 순서가 있습니다. 이 순서를 몸에 익히면 4~5번을 모두 맞힐 수 있는 영역입니다.

⚠ 이 파트 함정 — 이렇게 속입니다

  • 정상 부모에서 환자 → 우성→열성 (부모는 모두 보인자)
  • X 열성인데 환자 딸의 아버지가 정상→불가능 — 아버지도 환자
  • 일란성 쌍둥이의 형질 차이 = 유전자 차이→유전자 동일 → 환경 요인
  • A형의 유전자형은 AA 하나→AA 또는 AO
  • 감수 1·2분열 비분리를 반대로 판별→다른 상동 염색체 둘 = 1분열, 같은 복제본 둘 = 2분열
  • 다운 증후군은 유전자 돌연변이→염색체 수 이상(21번 삼염색체성)
  • 헌팅턴 무도병은 열성→상염색체 우성

수능은 이렇게 묻는다가계도 + DNA 상대량으로 유전자형 확정 → 확률(정상인데… 조건부) → 염색체 비분리 시기 판별

1. 멘델의 유전 원리

용어뜻
대립유전자상동 염색체의 같은 위치에서 하나의 형질을 결정하는 서로 다른 유전자(A, a)
동형 접합 / 이형 접합AA·aa / Aa
우성 · 열성이형 접합에서 표현형으로 나타나는 쪽 · 안 나타나는 쪽
표현형 · 유전자형겉으로 나타난 형질 · 유전자 구성
  • 분리의 법칙: 감수 분열 때 대립유전자가 분리되어 서로 다른 생식세포로 들어간다. Aa × Aa → AA : Aa : aa = 1 : 2 : 1, 우성 : 열성 = 3 : 1.
  • 독립의 법칙: 서로 다른 염색체에 있는 두 형질은 독립적으로 유전. AaBb × AaBb → 9 : 3 : 3 : 1. (같은 염색체에 있으면 연관, 교차가 없으면 함께 유전.)

2. 가계도 분석 — 풀이 순서

  1. 우열 판정: 정상 × 정상 → 발병 자녀가 있으면 발병이 열성. 발병 × 발병 → 정상 자녀가 있으면 발병이 우성.
  2. 상염색체 vs X 염색체 판정(후보를 하나씩 모순 검사):
    • X 염색체 열성이 불가능한 경우: 발병 딸의 아버지가 정상, 또는 발병 어머니의 아들이 정상.
    • X 염색체 우성이 불가능한 경우: 발병 아버지의 딸이 정상, 또는 정상 어머니의 아들이 발병.
  3. 유전자형 확정: 발병 열성은 aa, 발병 우성인 사람의 부모 중 정상이 있으면 그 자녀는 Aa, 자녀 중 열성이 나오면 부모는 둘 다 최소 Aa 등.
  4. 확률 계산: 각 사건의 확률을 곱하고, “정상인데” 같은 조건이 붙으면 조건에 맞는 경우만 분모로 잡습니다.

확률 자주 쓰는 값

Aa × Aa → 발병(aa) 1/4
정상 자녀가 보인자(Aa)일 확률 = 2/3 (AA:Aa = 1:2)
Aa × aa → 발병 1/2

3. 성염색체 유전 (X 연관)

  • 남자(XY)는 X가 하나뿐이라 X 열성 유전자 하나만 있어도 발병(적록 색맹, 혈우병). 그래서 발병률이 남자 > 여자.
  • X 열성: 어머니가 발병이면 아들은 모두 발병, 아버지가 발병이면 딸은 (어머니가 정상이라도) 보인자 이상. 아버지 → 아들에게는 X를 물려주지 않습니다.
  • X 우성: 아버지가 발병이면 딸은 모두 발병.
XHXh(보인자 어머니) × XHY(정상 아버지)
→ 딸: 모두 정상(1/2는 보인자), 아들: 1/2 정상, 1/2 발병
→ 자녀 전체에서 ‘발병 아들’ 확률 1/4, 아들 중 발병 확률 1/2

4. ABO식 혈액형 (복대립 유전)

  • 대립유전자 3개: A, B, O(=i). A와 B는 O에 대해 우성, A와 B 사이는 공동 우성.
표현형유전자형응집원(적혈구 표면)응집소(혈장)
A형AA, AOAβ
B형BB, BOBα
AB형ABA, B없음
O형OO없음α, β
  • 표현형 4가지, 유전자형 6가지. 부모가 A형(AO) × B형(BO)이면 자녀는 A·B·AB·O 모두 가능(각 1/4).
  • 응집원 A와 응집소 α가 만나면 응집. 항 A 혈청(α)에 응집하면 A형 또는 AB형, 항 B 혈청(β)에 응집하면 B형 또는 AB형.

5. 사람의 유전병과 염색체 이상

구분질환원인
단일 유전자(상염색체 우성)헌팅턴 무도병우성 대립유전자
단일 유전자(상염색체 열성)낭성 섬유증, 페닐케톤뇨증, 알비노, 낫 모양 적혈구 빈혈증열성 대립유전자(낫 모양 적혈구 빈혈증은 헤모글로빈 유전자의 염기 변화)
X 염색체 열성적록 색맹, 혈우병X 연관 열성
염색체 수 이상다운 증후군(21번 3개, 47), 터너 증후군(XO, 45, 여성), 클라인펠터 증후군(XXY, 47, 남성)감수 분열 때 염색체 비분리
염색체 구조 이상고양이 울음 증후군5번 염색체 일부 결실

염색체 비분리

비분리 시기분리 실패한 것만들어지는 생식세포 4개
감수 1분열상동 염색체n+1 2개, n−1 2개 (정상 n 없음)
감수 2분열염색 분체n+1 1개, n−1 1개, 정상 n 2개

정상 난자(n)가 n+1인 정자와 만나면 2n+1(삼염색체성), n−1인 정자와 만나면 2n−1(일염색체성)이 됩니다. 성염색체가 XXY이면 정상 X를 가진 난자 + XY 정자(아버지의 감수 1분열 비분리) 또는 XX 난자(어머니 비분리) + Y 정자로 설명됩니다. 아버지가 XY를 모두 준 경우는 감수 1분열에서만 가능하고(상동 염색체 X·Y가 분리 안 됨), 어머니가 XX를 준 경우는 감수 1 또는 2분열 어느 쪽이든 가능합니다.

자주 나오는 함정

  • 정상 부모에서 발병 자녀가 나왔으니 우성 — 열성입니다(부모는 모두 보인자).
  • X 열성에서 발병 딸의 아버지가 정상일 수 있다 — 불가능합니다. 딸이 XhXh이면 아버지에게서 Xh를 받았으므로 아버지도 발병입니다.
  • 일란성 쌍둥이의 형질 차이는 유전자 차이 — 유전자가 같으므로 환경 요인입니다.
  • A형의 유전자형은 AA 하나 — AA 또는 AO입니다(부모 정보로 확정).
  • 감수 1·2분열 비분리를 반대로 판별 — 자녀 세포에 상동 염색체 두 개(서로 다른 것)가 있으면 1분열, 같은 염색 분체 복제본 두 개가 있으면 2분열입니다.
  • 다운 증후군은 유전자 돌연변이 — 염색체 수 이상(21번 삼염색체성)입니다.
  • 헌팅턴 무도병은 열성 — 상염색체 우성입니다.

대표 예제

눌러서 풀이를 펼치세요.

정상인 아버지(1)와 어머니(2) 사이에서 발병한 딸(3)이 태어났다. 이 형질의 우열과 유전자 위치는?

정상 × 정상 → 발병 자녀이므로 발병은 열성. 발병한 딸의 아버지가 정상이므로 X 염색체 열성이 불가능합니다(딸이 XaXa면 아버지도 XaY여야 함).

따라서 상염색체 열성이며 1, 2는 모두 Aa, 3은 aa입니다.

어머니가 XHXh(보인자), 아버지가 XHY(정상)일 때, 아들 중 발병할 확률과 딸이 보인자일 확률은?

어머니 배우자 XH, Xh 각 1/2, 아버지는 XH 1/2, Y 1/2. 아들(XY)은 어머니에게서 X를 받으므로 발병(XhY) 1/2.

딸(XX)은 아버지의 XH를 반드시 받고 어머니에게서 XH 또는 Xh → 보인자 확률 1/2, 발병 확률 0.

A형(유전자형을 모름)과 B형인 부부에게서 O형 자녀가 태어났다. 이 부부의 유전자형과, 이 부부가 다음에 낳을 자녀가 O형일 확률은?

O형 자녀(OO)는 양쪽에서 O를 받았으므로 부모는 각각 O를 가집니다. A형 = AO, B형 = BO.

AO × BO → A : B : AB : O = 1 : 1 : 1 : 1이므로 O형 확률은 1/4입니다.

난이도별 한 줄 정리

쉬움

한 줄

가계도는 “정상 두 사람에게서 환자 → 열성” 한 줄로 시작합니다. 열성이면 그 환자는 aa, 부모는 둘 다 보인자입니다. 남자는 X가 하나라 X 열성 병이 더 잘 나타납니다.

  • ABO는 “A와 B는 O보다 강하고, A와 B끼리는 둘 다 나타난다”.
  • 비분리는 “짝(상동 염색체)이 안 갈라졌나(1분열), 복사본이 안 갈라졌나(2분열)”.
고급

3점 킬러(유전 가계도 + DNA 상대량 표)의 풀이 순서: (1) 조건 “유전자 ㉠은 X 염색체에 있고, ㉡은 상염색체” 같은 문장에서 위치를 먼저 확정하고, (2) 가계도로 각 형질의 우열을 정하고, (3) 표의 DNA 상대량(체세포 1개당)으로 각 구성원의 유전자형을 정합니다 — 상대량 2 = 동형 접합(또는 X 유전자의 남자 1), 1 = 이형 접합/남자의 X 연관 유전자, 0 = 그 대립유전자 없음. (4) 확정된 유전자형으로 부모→자녀 확률을 곱합니다. “⑥와 ⑦ 사이에서 태어난 아이가 (가)와 (나)가 모두 발현될 확률”은 각 형질 확률의 곱입니다(독립인 경우).

비분리 문항은 자녀의 세포/핵형에서 염색체 조성(예: XXY, 21번 3개)을 확정한 뒤 부모 중 누구의 어느 분열 비분리인지 염색체 구성 조각으로 추적합니다. 부모 감수 1분열 때 상동 염색체가 함께 이동하면 생식세포에 서로 다른 염색체 하나씩이 함께 들어 있습니다.
