생태계와 상호 작용

Part 8 · Ⅴ. 생태계와 상호 작용

생태계 구성 · 개체군 · 군집 · 에너지 흐름과 물질 순환 · 생물 다양성

3.1회당 문항 수
7.8점회당 배점
3~4회차별 범위
50최근 16회 누적

수능 2022~2026학년도 + 6·9월 모의평가 16회(320문항) 기준. 문항 본문 키워드로 분류한 값이라 ±1문항 오차가 있을 수 있습니다.

회당 3문항 정도로, 절반은 개념 문장 판별이고 절반은 그래프·표 해석(생존 곡선, 개체군 생장, 천이, 방형구 조사, 영양 단계별 에너지)입니다. 서로 다른 용어를 정확히 구별하는 것이 관건입니다. 1번(생물의 특성)과 3번에 이 단원 자료가 자주 등장합니다.

1. 생태계의 구성

  • 생물적 요인: 생산자(광합성), 소비자(1차·2차·3차), 분해자(사체·배설물 분해).
  • 비생물적 요인: 빛, 온도, 물, 공기, 토양.
  • 작용: 비생물 → 생물(빛의 세기가 식물 광합성에 영향). 반작용: 생물 → 비생물(지렁이가 토양을 기름지게 함). 상호 작용: 생물 사이.
개체 → 개체군(같은 종) → 군집(여러 종의 개체군) → 생태계(군집 + 비생물적 환경)

2. 개체군

  • 밀도 = 개체 수 / 면적(또는 부피). 출생·사망, 이입·이출로 변합니다.
  • 생장 곡선: 이론적으로는 J자형(환경 저항 없음), 실제는 S자형 — 환경 저항이 커지며 환경 수용력(K)에서 안정.
생존 곡선특징예
Ⅰ형초기 사망률 낮고 노년기에 급증 (적게 낳고 잘 돌봄)사람, 대형 포유류
Ⅱ형나이와 무관하게 사망률 일정히드라, 일부 조류
Ⅲ형초기 사망률 매우 높음 (많이 낳음)굴, 어류
  • 개체군 내 상호 작용: 텃세(먹이·번식 영역 확보), 순위제, 리더제, 사회생활(분업: 벌·개미), 가족생활.
  • 개체군 조사: 방형구법(식물 등 정착 생물), 표지 재포획법(N = (처음 표지 수 × 재포획 수) / 재포획된 표지 수).

3. 군집

  • 군집의 구조: 수직 분포(산림의 교목층·아교목층·관목층·초본층) · 수평 분포(위도·고도에 따라 다름).
  • 우점종: 군집에서 중요치(상대 밀도 + 상대 빈도 + 상대 피도)가 가장 큰 종. 핵심종: 개체 수는 적어도 군집 구조에 큰 영향. 지표종: 특정 환경을 알려주는 종.

군집 내 상호 작용 (종간)

종류A / B의 이익예
종간 경쟁− / −먹이·서식지가 같은 두 종(초기에 경쟁, 심하면 한 종 도태 = 경쟁 배타)
분서경쟁 회피서식 장소·먹이·활동 시기를 나눔
포식과 피식+ / −사자와 얼룩말 (개체 수가 주기적으로 변동: 피식자 증가 → 포식자 증가)
기생+ / −촌충, 기생충(숙주에 피해)
상리 공생+ / +콩과 식물–뿌리혹박테리아, 말미잘–흰동가리
편리 공생+ / 0빨판상어–상어

군집의 천이

  • 1차 천이(토양 없는 곳에서 시작): 건성 천이 용암 대지·암석 → 지의류(개척자) → 이끼 → 초원 → 관목림 → 양수림 → 혼합림 → 음수림(극상), 습성 천이 호수 → 습원 → 초원 → 관목림 → 양수림 → ….
  • 2차 천이(산불·경작지 방치 등 토양·종자가 남아 있음): 초원부터 시작해 1차보다 빠름.
  • 극상(안정된 상태)은 음수림(어린 나무가 그늘에서도 자라 세대 교체).

4. 에너지 흐름과 물질 순환

  • 에너지 흐름: 생산자가 빛에너지를 화학 에너지로 고정 → 먹이 사슬을 따라 한 방향으로 이동하며 각 단계에서 호흡(열)·배설물·사체로 빠져나가 재활용되지 않고 결국 열로 방출됩니다.
에너지 효율 (%) = (현 영양 단계의 에너지양 / 전 영양 단계의 에너지양) × 100
일반적으로 약 10 % 전후 → 상위 단계로 갈수록 에너지량 감소 → 먹이 피라미드
  • 물질 순환: 물질은 생물과 환경 사이를 순환합니다.
    • 탄소: 대기 CO2 → 광합성으로 유기물 → 먹이 사슬 → 호흡·분해로 CO2 방출(화석 연료 연소도 CO2 방출).
    • 질소: 대기 N2 → 질소 고정(뿌리혹박테리아 등) → NH4+ → 질산화(질산화 세균) → NO3− → 식물이 흡수해 단백질·핵산 합성(질소 동화) → 소비자 → 분해자가 다시 NH4+ → 탈질산화(탈질산화 세균) → N2.

5. 생물 다양성

  • 유전적 다양성(같은 종 안의 유전자 차이), 종 다양성(종의 수 + 각 종 개체의 고른 정도), 생태계 다양성(서식지·생태계의 종류).
  • 위협 요인: 서식지 파괴·분할, 외래종 도입, 남획, 환경 오염, 기후 변화. 보전: 서식지 보호, 멸종 위기 종 복원, 국제 협약.

자주 나오는 함정

  • 에너지도 생태계에서 순환한다 — 에너지는 한 방향으로 흐르다 열로 방출됩니다(물질만 순환).
  • 에너지 효율을 생산자 대비로만 계산 — 문제에서 “전 단계 대비”면 바로 아래 단계로 나눕니다.
  • 텃세·순위제는 군집 내 상호 작용 — 같은 종 안의 일이므로 개체군 내입니다. 종간 상호 작용은 군집입니다.
  • 지렁이가 토양을 바꾸는 것은 작용 — 생물이 환경에 영향을 주는 것이므로 반작용.
  • 분서는 경쟁의 결과 한 종이 사라지는 것 — 분서는 경쟁을 피하려 생태적 지위를 나눈 것입니다(경쟁 배타는 도태).
  • Ⅱ형 생존 곡선은 나이가 들수록 사망률이 증가 — 나이와 무관하게 일정합니다.
  • 종 다양성 = 종의 수 — 각 종의 개체 수 비율(균등도)도 포함합니다.
  • 극상은 양수림 — 음수림입니다.

대표 예제

눌러서 풀이를 펼치세요.

생산자가 고정한 에너지가 10000 kcal, 1차 소비자가 1500 kcal, 2차 소비자가 200 kcal일 때 각 단계의 에너지 효율은?

1차 소비자: 1500 / 10000 × 100 = 15 %.

2차 소비자: 200 / 1500 × 100 ≈ 13.3 %(전 단계 대비). 생산자 대비로 보면 2 %입니다.

어떤 호수의 물고기를 50마리 잡아 표지를 붙여 놓아주고, 며칠 뒤 40마리를 잡았더니 8마리에 표지가 있었다. 개체군 크기 추정은?

전체 N 중 표지 개체 비율 = 재포획에서의 표지 비율: 50 / N = 8 / 40 → N = 50 × 40 / 8 = 250마리.

방형구 조사에서 종 A의 개체 수 30, 전체 개체 수 100이라면 종 A의 상대 밀도는? 방형구 10개 중 A가 나타난 방형구가 6개이고, 모든 종의 빈도를 합하면 2.0이라면 상대 빈도는?

상대 밀도 = 30 / 100 × 100 = 30 %.

A의 빈도 = 6/10 = 0.6, 모든 종의 빈도 합 = 2.0 → 상대 빈도 = 0.6 / 2.0 × 100 = 30 %. (중요치 = 상대 밀도 + 상대 빈도 + 상대 피도)

생태계에서 에너지는 한 번 쓰고 열로 사라지고, 물질은 계속 돌고 돕니다. 같은 종끼리 다투면 개체군의 일, 다른 종끼리 얽히면 군집의 일입니다.

  • 먹이 사슬을 올라갈수록 에너지는 대략 10%씩만 전달됩니다.
  • 산불 이후 다시 자라는 2차 천이가 1차 천이보다 빠릅니다.
고급

그래프 문항은 세 가지가 자주 나옵니다. (1) 개체군 생장 곡선에서 변곡점 근처가 증가율 최대, K 근처에서 밀도 안정, (2) 생존 곡선에서 초기 사망률·분포 유형 판별, (3) 영양 단계별 에너지량 표에서 효율 계산. 방형구 조사 표는 상대 밀도·상대 빈도·상대 피도를 각각 계산해 합한 중요치가 큰 종 = 우점종이라는 절차로 풉니다.
