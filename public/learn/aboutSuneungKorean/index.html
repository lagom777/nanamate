이 노트가 다루는 것

수능 국어의 출제 과목은 화법과 언어 · 독서와 작문 · 문학이고 선택과목이 없습니다. 이 노트는 독서와 문학을 갈래별로, 화법·작문과 언어(문법)를 한 파트씩 나눠 지문을 읽는 절차와 선지를 가르는 기준을 정리했습니다. 국어는 외워서 푸는 과목이 아니라 읽는 순서와 판단 기준을 익히는 과목이라, 각 파트는 개념 → 읽는 절차 → 오답 패턴 → 직접 만든 예제 → 짝짓기·퀴즈로 구성했습니다. 실제 시험지로 풀어 보는 수능 풀어보기는 시험지 전체를 그대로 보여 주고 답안지로 채점합니다.

시험 구조

80분 · 45문항 · 100점. 모든 수험생이 같은 문제를 풉니다. 모두 5지 선다이며 점수는 2점·3점 문항으로 나뉩니다.

기출 데이터

평가원 수능 예시문항(45문항)과 2018~2027학년도 수능·6월·9월 모의평가 30회 시험지의 지문·문항 이미지와 정답·배점이 들어 있습니다. 2022~2027학년도 시험지는 1~34번 뒤에 화법과 작문 구역과 언어와 매체 구역(각 35~45번)이 따로 있어, 풀어보기에서 하나를 골라 풉니다. 지문은 단(段) 단위 이미지로 이어 붙여 보여 줍니다.
