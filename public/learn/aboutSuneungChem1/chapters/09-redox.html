산화 환원 반응

Part 9 · 역동적인 화학 반응

산화수·산화 환원 반응·반응식 완성·화학 전지

2.0회당 문항 수
4.9점회당 배점
1~4회차별 범위
59최근 29회 누적

수능 2018~2026학년도 + 6·9월 모의평가 29회(2018~2021학년도는 구 교육과정)(580문항) 기준. 문항 본문 키워드로 분류한 값이라 ±1문항 오차가 있을 수 있습니다.

산화 환원은 전자가 어느 원자에서 어느 원자로 이동했는지를 산화수로 읽어 내는 파트입니다. 수능에서는 반응식의 산화수 변화로 산화제와 환원제를 고르고, 전자 수를 맞춰 계수를 완성하며, 반응 전후 이온 모형에서 사라진 이온과 생긴 금속의 개수를 대조합니다. 화학 전지는 그 전자가 도선으로 빠져나가는 구조로, 어느 금속이 녹고 어느 극이 무거운지를 묻습니다.

1. 산화와 환원의 정의

산화와 환원은 항상 함께 일어납니다. 한 물질이 전자를 잃으면 다른 물질이 그 전자를 받습니다. 역사적으로는 산소·수소의 이동으로 먼저 정의했고, 지금은 전자와 산화수까지 같은 현상의 다른 표현으로 묶습니다.

기준산화환원
산소산소와 결합한다산소를 잃는다
수소수소를 잃는다수소와 결합한다
전자전자를 잃는다전자를 얻는다
산화수산화수가 증가한다산화수가 감소한다

네 줄은 같은 반응에서 동시에 맞아야 합니다. 구리가 산소와 결합해 산화 구리(Ⅱ)가 되면 구리는 전자를 잃고 산화수가 0에서 +2로 커집니다. 산소는 산화수가 0에서 −2로 작아지므로 환원됩니다.

2Cu + O2 → 2CuO
Cu: 0 → +2 (산화),   O: 0 → −2 (환원)

수소와 염소가 만나 염화 수소가 되는 반응은 산소가 없어도 산화 환원입니다. 수소는 0에서 +1로 산화되고, 염소는 0에서 −1로 환원됩니다. 전자는 수소에서 염소로 이동합니다.

H2 + Cl2 → 2HCl

연소도 산화 환원입니다. 메테인에서 탄소의 산화수는 −4이고, 이산화 탄소에서 탄소의 산화수는 +4입니다. 탄소 하나당 전자 8개를 잃습니다. 산소 분자 2개, 산소 원자 4개는 0에서 −2가 되며 원자 하나당 전자 2개, 합이 8개입니다.

CH4 + 2O2 → CO2 + 2H2O

전자를 잃는 물질이 상대를 환원시키므로 환원제입니다. 전자를 얻는 물질이 상대를 산화시키므로 산화제입니다. 산화제는 자신은 환원되고, 환원제는 자신은 산화됩니다. 이름은 상대에게 하는 일에 붙입니다.

함정: 산화되는 물질을 산화제라고 부르면 방향이 뒤집힙니다. 산화수가 증가한 물질이 환원제이고, 산화수가 감소한 물질이 산화제입니다.

2. 산화수 규칙과 변화 판정

산화수는 전자가 어느 쪽으로 치우쳤는지를 원자에 정수로 매긴 값입니다. 실제 전하와 항상 같지는 않으며, 결합한 전자를 일정한 규칙으로 나누어 가진 것입니다. 다음 순서로 매깁니다.

  1. 홑원소 물질의 산화수는 0입니다. H2, O2, Cl2, Na, Fe, P4가 모두 0입니다. 원자 개수를 산화수로 쓰지 않습니다.
  2. 단원자 이온의 산화수는 이온의 전하와 같습니다. Na+는 +1, Cl−는 −1, Mg2+는 +2, Al3+은 +3입니다.
  3. 화합물에서 플루오린은 −1, 1족 금속은 +1, 2족 금속은 +2입니다. 수소는 보통 +1이고, NaH처럼 금속과 결합한 수소화물은 −1입니다. 산소는 보통 −2이고, H2O2 같은 과산화물에서는 −1, OF2에서는 +2입니다.
  4. 중성 물질에서 산화수의 합은 0입니다. 다원자 이온에서 산화수의 합은 이온의 전하와 같습니다. 규칙을 적용하고 남은 원자가 미지수입니다.
물질계산결과
H2O2×(+1) + O = 0O는 −2
H2O22×(+1) + 2O = 0O는 −1
OF2O + 2×(−1) = 0O는 +2
NaH(+1) + H = 0H는 −1
H2SO42×(+1) + S + 4×(−2) = 0S는 +6
SO42−S + 4×(−2) = −2S는 +6
NO3−N + 3×(−2) = −1N는 +5
NH3N + 3×(+1) = 0N는 −3
CO2 / COC + 2×(−2) = 0, C + (−2) = 0C는 +4 / +2
KMnO4(+1) + Mn + 4×(−2) = 0Mn는 +7
MnO2Mn + 2×(−2) = 0Mn는 +4
Cr2O72−2Cr + 7×(−2) = −2Cr는 +6
Fe2O32Fe + 3×(−2) = 0Fe는 +3
CH4C + 4×(+1) = 0C는 −4

황산의 검산은 2 + 6 − 8 = 0입니다. 중크롬산 이온은 2Cr − 14 = −2에서 2Cr = 12, Cr = +6입니다. 과망가니즈산 칼륨은 1 + Mn − 8 = 0에서 Mn = +7입니다. 이온 전체의 전하 −2를 황의 산화수와 혼동하면 SO42−에서 황을 −2로 두게 됩니다. 황은 +6이고, −2는 산소 네 개와 황을 합친 이온의 전하입니다.

같은 원소라도 물질마다 산화수가 다릅니다. 황은 홑원소 S에서 0, 황화 수소에서 −2, 이산화 황에서 +4, 황산과 황산 이온에서 +6입니다. 반응이 어느 물질에서 어느 물질로 가는지를 봐야 증가인지 감소인지가 정해집니다.

산화수 증가 → 산화, 그 물질을 포함한 반응물이 환원제
산화수 감소 → 환원, 그 물질을 포함한 반응물이 산화제

과산화 수소가 물과 산소로 나뉠 때는 산소의 산화수가 한 방향으로만 움직이지 않습니다.

2H2O2 → 2H2O + O2

H2O2의 산소는 −1입니다. 물 속의 산소는 −2가 되어 환원되고, 산소 분자의 산소는 0이 되어 산화됩니다. 원자 개수는 왼쪽 산소 4개, 오른쪽 물 2개와 산소 분자 2개로 보존됩니다. 같은 원소가 일부는 산화되고 일부는 환원되는 반응입니다.

TIP: 미지 산화수는 플루오린, 1족·2족, 수소, 산소 순으로 알려진 값을 먼저 넣고, 합이 0 또는 이온 전하가 되도록 나머지를 구합니다. 구한 뒤에는 합을 다시 더해 검산합니다.

3. 산화제·환원제와 반응식 완성

반응식을 완성할 때는 원자 개수만 맞추면 전자가 어긋날 수 있으므로, 산화수가 변한 원자부터 전자 수를 맞춥니다.

  1. 모든 원자의 산화수를 반응 전후에 적고, 변한 원자만 동그라미를 칩니다.
  2. 산화된 원자 하나가 잃은 전자 수, 환원된 원자 하나가 얻은 전자 수를 적습니다.
  3. 잃은 전자의 총합과 얻은 전자의 총합이 같도록 계수를 곱합니다.
  4. 반쪽 반응을 더해 전자를 지웁니다. 구경꾼 이온은 개수가 맞도록 양쪽에 더합니다.
  5. 원소별 원자 수와 좌우의 전하 합을 검산합니다.

산화 구리(Ⅱ)와 수소의 반응은 이미 계수가 맞습니다. 구리의 산화수는 +2에서 0으로 감소하므로 CuO가 산화제입니다. 수소의 산화수는 0에서 +1로 증가하므로 H2가 환원제입니다. 산소는 −2 그대로입니다. 수소 분자 1개가 전자 2개를 잃고, 구리 하나가 전자 2개를 얻습니다.

CuO + H2 → Cu + H2O

아연과 구리(Ⅱ) 이온은 반쪽으로 나누면 다음과 같습니다.

산화 반쪽(환원제): Zn → Zn2+ + 2e−
환원 반쪽(산화제): Cu2+ + 2e− → Cu
알짜: Zn + Cu2+ → Zn2+ + Cu

황산 이온이 있는 전체 식은 Zn + CuSO4 → ZnSO4 + Cu입니다. SO42−의 황 산화수는 +6 그대로라 구경꾼입니다. 전하도 왼쪽 Cu2+의 +2와 오른쪽 Zn2+의 +2가 같습니다.

알루미늄과 구리(Ⅱ) 이온은 전자 수가 다릅니다. 알루미늄은 전자 3개를 잃고, 구리(Ⅱ) 이온은 전자 2개를 얻습니다. 최소공배수는 6입니다.

Al → Al3+ + 3e−   (×2)
Cu2+ + 2e− → Cu   (×3)
2Al + 3Cu2+ → 2Al3+ + 3Cu

전하의 합은 왼쪽 3 × (+2) = +6, 오른쪽 2 × (+3) = +6입니다. 황산 구리(Ⅱ)로 쓰면 2Al + 3CuSO4 → Al2(SO4)3 + 3Cu이고, 황산 이온 3개가 양쪽에서 같습니다.

산화 철(Ⅲ)과 일산화 탄소의 반응은 제련의 모형으로 자주 나옵니다. Fe2O3에서 철은 +3, CO에서 탄소는 +2, CO2에서 탄소는 +4입니다.

Fe2O3 + 3CO → 2Fe + 3CO2

철 원자 2개가 각각 전자 3개, 합 6개를 얻습니다. 탄소 3개가 각각 전자 2개, 합 6개를 잃습니다. 산화제는 Fe2O3, 환원제는 CO입니다. 철 원자량은 56, 산소는 16로 두면 Fe2O3의 화학식량은 160입니다. 0.10 mol이면 질량 16 g이고, CO 0.30 mol은 8.4 g입니다. 생성되는 Fe 0.20 mol은 11.2 g, CO2 0.30 mol은 13.2 g입니다. 16 + 8.4 = 24.4, 11.2 + 13.2 = 24.4로 질량이 보존됩니다. 전자는 0.20 × 3 = 0.60 mol입니다.

이산화 망가니즈와 염산의 반응에서는 염소가 모두 산화되지는 않습니다. 망가니즈 원자량은 55로 둡니다.

MnO2 + 4HCl → MnCl2 + Cl2 + 2H2O

망가니즈는 +4에서 +2로 환원되어 전자 2개를 얻습니다. 염소 4개 중 2개만 −1에서 0이 되어 Cl2가 되고, 나머지 2개는 MnCl2에서 −1 그대로입니다. 전자 2개와 맞습니다. 산화제는 MnO2, 환원제는 HCl입니다. 원자 개수는 Mn 1, O 2, H 4, Cl 4로 양쪽이 같습니다.

구리는 묽은 질산과 진한 질산에서 서로 다른 기체를 만듭니다. 질산의 질소는 +5입니다. 묽은 질산에서는 질소의 일부가 +2인 NO로, 진한 질산에서는 +4인 NO2로 환원됩니다. 질산 이온으로 구리 이온과 짝지어 남는 질소는 +5 그대로입니다.

3Cu + 8HNO3(묽은) → 3Cu(NO3)2 + 2NO + 4H2O
Cu + 4HNO3(진한) → Cu(NO3)2 + 2NO2 + 2H2O

묽은 쪽 검산은 구리 3, 수소 8, 질소 8 = 6 + 2, 산소 24 = 18 + 2 + 4입니다. 구리 3개가 전자 6개를 잃고, NO로 가는 질소 2개가 각각 전자 3개를 얻어 6개입니다. 진한 쪽은 구리 1개가 전자 2개를 잃고, NO2로 가는 질소 2개가 각각 전자 1개를 얻습니다. 산소 12 = 6 + 4 + 2, 질소 4 = 2 + 2입니다.

계수가 맞은 반응식

변한 원자의 전자 수가 같고, 원소마다 원자 수가 같으며, 이온 반응이면 전하의 합이 같습니다. 셋 중 하나라도 다르면 계수를 다시 곱합니다.

4. 금속의 반응성과 화학 전지

금속이 전자를 잃고 양이온이 되려는 경향을 이온화 경향이라고 합니다. 화학Ⅰ에서 비교에 쓰는 순서는 다음과 같습니다. 왼쪽으로 갈수록 전자를 잃기 쉽고, 그 이온은 환원되기 어렵습니다.

K > Ca > Na > Mg > Al > Zn > Fe > Ni > Sn > Pb > H > Cu > Hg > Ag > Pt > Au

왼쪽에 있는 금속은 오른쪽 금속의 이온에게 전자를 줄 수 있습니다. 금속 자체는 산화되어 녹고, 상대 이온은 환원되어 고체로 석출됩니다. 반대 방향은 일어나지 않습니다.

조합일어나는 반응일어나지 않는 방향
아연과 구리(Ⅱ) 이온Zn + Cu2+ → Zn2+ + CuCu + Zn2+
구리와 은 이온Cu + 2Ag+ → Cu2+ + 2AgAg + Cu2+
아연과 묽은 염산Zn + 2H+ → Zn2+ + H2수소보다 오른쪽인 Cu와 묽은 염산
철과 구리(Ⅱ) 이온Fe + Cu2+ → Fe2+ + CuCu + Fe2+

수소보다 왼쪽 금속만 묽은 산의 H+를 환원해 수소 기체를 만듭니다. 구리를 묽은 염산에 넣어도 수소가 발생하지 않습니다. 용액에 반응성이 다른 금속 이온이 함께 있으면, 반응성이 작은 금속의 이온이 먼저 전자를 받습니다. 은 이온이 구리(Ⅱ) 이온보다 먼저 환원됩니다.

실험으로 순서를 정할 때는 금속판을 다른 금속의 이온 수용액에 넣고 석출 여부를 표로 만듭니다. X를 Y2+ 수용액에 넣었더니 Y가 석출되면 X가 Y보다 반응성이 큽니다. 변화가 없으면 X는 Y보다 반응성이 작습니다. 묽은 염산에서 기체가 나오면 그 금속은 수소보다 왼쪽입니다.

볼타 전지

화학 전지는 산화 환원으로 전자가 도선을 따라 흐르게 만든 장치입니다. 볼타 전지는 아연판과 구리판을 묽은 황산에 함께 넣습니다.

위치반응전자와 질량
아연판, 음극(−)Zn → Zn2+ + 2e− 산화전자가 도선으로 나감. 아연판은 녹아 가벼워짐
구리판, 양극(+)2H+ + 2e− → H2 환원전자가 도선으로 들어옴. 구리판 질량은 늘지 않고 수소 기체가 붙음
볼타 전지의 전체 반응: Zn + 2H+ → Zn2+ + H2

전자는 도선을 따라 아연에서 구리로 이동합니다. 용액 속을 전자가 지나가는 것이 아닙니다. 용액에서는 이온이 움직입니다. 구리판에 수소 기체가 붙으면 전류가 약해지는데, 이것을 분극이라고 합니다.

아연 원자량을 65, 수소 원자량을 1로 두면, 전자 0.20 mol이 이동할 때 녹는 아연은 0.10 mol, 질량 6.5 g입니다. 발생하는 수소는 0.10 mol, 질량 0.20 g이고, 0°C·1기압에서 부피는 2.24 L입니다. 구리판의 질량은 이 전자 이동만으로 증가하지 않습니다.

다니엘 전지

다니엘 전지는 두 용액을 나눠 분극을 피한 화학 전지입니다. 아연판은 황산 아연 수용액에, 구리판은 황산 구리(Ⅱ) 수용액에 넣고 염다리로 연결합니다.

음극(−), 산화: Zn → Zn2+ + 2e−
양극(+), 환원: Cu2+ + 2e− → Cu
전체: Zn + Cu2+ → Zn2+ + Cu

전자는 역시 도선을 따라 아연에서 구리로 갑니다. 아연판은 녹아 질량이 줄고, 구리판에는 구리가 붙어 질량이 늘어납니다. 아연 이온은 늘어나고 구리(Ⅱ) 이온은 줄어듭니다. 황산 이온에서 황의 산화수는 +6 그대로입니다.

염다리에서는 음이온이 산화가 일어나는 아연 쪽으로, 양이온이 환원이 일어나는 구리 쪽으로 이동합니다. 아연 쪽이 양이온이 늘어 양전하가 넘치고, 구리 쪽이 양이온이 줄어 양전하가 모자라기 때문입니다. 전자는 염다리를 통과하지 않습니다.

구리 원자량을 64로 두면 전자 0.20 mol이 이동할 때 구리 0.10 mol, 6.4 g이 석출됩니다. 아연은 볼타 전지와 같이 6.5 g이 줄어듭니다. 반응성이 큰 금속이 음극입니다. 두 금속의 반응성 차이가 전지의 방향과 전압의 대소를 정하는 기준이 됩니다. 표준 환원 전위를 숫자로 계산하는 것은 화학Ⅰ의 이 단원에서 요구하지 않습니다.

함정: 화학 전지에서 산화 전극은 음극(−)입니다. 전자가 나가는 극이 음극이고, 반응성이 큰 금속이 그 자리에 옵니다. 전자의 통로는 도선이고, 이온의 통로는 용액과 염다리입니다.

5. 자료를 이렇게 읽는다

산화 환원 자료는 반응 전후 이온 모형, 금속을 담근 결과 표, 전지의 전극 그림입니다. 모형은 다음 순서로 읽습니다.

  1. 반응 전과 후의 양이온, 음이온, 고체 금속을 종류별로 셉니다. 범례의 모양을 먼저 적습니다.
  2. 음이온 개수가 그대로이면 구경꾼 후보입니다. 황의 산화수가 +6에서 변했는지 따로 확인합니다. 변하지 않았으면 전자 계산에서 뺍니다.
  3. 줄어든 금속 이온과 늘어난 금속 이온의 개수 비가 반응식 계수와 같은지 봅니다. 1:1이 아닌 반응은 전자 수로 계수가 달라집니다.
  4. 2가 이온은 개수에 2를 곱해 전하를 셉니다. 전후 모두 양전하 합과 음전하 합이 같아야 합니다.
  5. 이동한 전자 수 = (환원된 이온 개수) × (이온 1개가 받은 전자 수)입니다. 산화된 금속이 내놓은 전자 수와 같은지 확인합니다.
  6. 이온화 경향으로 그 방향이 실제로 일어나는지 확인합니다. 모형이 역반응처럼 보여도, 반응성이 작은 금속이 큰 금속의 이온을 환원하지는 못합니다.
  7. 용액에 이온이 둘 있으면 반응성이 작은 금속의 이온부터 환원됩니다. 넣어 준 금속의 전자가 부족하면 뒤의 이온은 남습니다.

예를 들어 반응 전 Cu2+ 5개, SO42− 5개이던 용액에 아연을 넣었더니 Cu2+ 2개, Zn2+ 3개, SO42− 5개가 되었습니다. 황산 이온은 그대로라 구경꾼입니다. Cu2+가 3개 줄고 Zn2+가 3개 늘었으므로 계수 비 1:1과 맞습니다. 전하는 2×2 + 3×2 = 10, 황산 이온 5×2 = 10으로 같습니다. 전자는 구리 이온 3개가 각각 2개씩 받아 6개이고, 아연 3개가 각각 2개씩 내놓은 것과 같습니다. 석출된 구리 고체도 3개입니다.

금속 반응 표는 행에 담근 금속, 열에 용액의 이온을 두고, 석출되면 담근 금속이 더 반응성이 크다고 화살표를 긋습니다. 모순이 없도록 한 줄로 세운 뒤 수소의 자리를 산과의 반응으로 끼웁니다.

TIP: 전지 그림은 두 금속의 이온화 경향을 먼저 비교합니다. 큰 쪽이 음극, 전자는 큰 쪽에서 작은 쪽으로 도선을 따라 갑니다. 질량은 음극이 줄고, 환원 생성물이 금속이면 양극이 늘어납니다. 볼타 전지의 양극 생성물은 수소 기체라 구리판 질량이 늘지 않습니다.

6. 수능형 문항이 묻는 방식

문항은 반응식 하나와 모형 하나를 주고 보기를 겹칩니다. 다음 네 가지가 한 세트로 나옵니다.

  • 산화수 변화. 규칙을 적용해 변한 원자만 표시합니다. 증가하면 산화, 감소하면 환원입니다. 합이 이온의 전하와 같은지 검산합니다.
  • 산화제와 환원제. 산화수가 감소한 원자를 포함한 반응물이 산화제, 증가한 원자를 포함한 반응물이 환원제입니다. 생성물은 그 역할의 답이 아닙니다.
  • 전자 수와 계수. 반쪽 반응의 전자를 최소공배수로 맞춥니다. 질산이나 염산처럼 일부 원자만 산화수가 변하는 반응은, 변한 개수와 구경꾼으로 남은 개수를 따로 셉니다.
  • 모형과 전지. 이온 개수 변화로 전자 수를 구하고, 전하가 맞는지 2가 이온을 반영해 확인합니다. 전지에서는 전자의 방향, 전극의 질량 변화, 염다리의 이온 방향을 반쪽 반응과 짝짓습니다.

반응성이 주어진 세 금속은 석출 실험의 참·거짓으로 순서를 완성한 뒤, 수소보다 왼쪽인지만 산과의 반응에 사용합니다. 순서가 Zn > H > Cu이면 아연은 묽은 염산과 반응하고 구리는 반응하지 않으며, 아연은 구리(Ⅱ) 이온과 반응합니다.

자주 나오는 함정

  • 산화되는 물질을 산화제라고 보기. 산화수가 증가해 산화되는 물질은 환원제입니다. 산화제는 자신은 환원됩니다.
  • 산소의 산화수를 항상 −2로 보기. 과산화 수소의 산소는 −1, OF2의 산소는 +2입니다. 홑원소 산소 분자는 0입니다.
  • 다원자 이온의 전하를 가운데 원자의 산화수로 보기. SO42−의 전하 −2와 황의 산화수 +6은 다릅니다. 합이 전하가 되도록 황을 구합니다.
  • 반응성이 큰 금속을 화학 전지의 양극으로 보기. 반응성이 큰 금속이 산화되는 음극(−)입니다. 전자는 그 극에서 도선으로 나갑니다.
  • 전자가 염다리나 용액으로 이동한다고 보기. 전자는 도선으로, 이온은 용액과 염다리로 이동합니다.
  • 볼타 전지에서 구리판 질량이 는다고 보기. 구리판에서는 수소 기체가 발생합니다. 구리 금속이 석출되는 것은 다니엘 전지의 양극입니다.
  • 구리가 묽은 염산과 반응해 수소를 만든다고 보기. 구리는 수소보다 이온화 경향이 작아 이 반응이 일어나지 않습니다. 아연은 일어납니다.
  • MnO2와 HCl의 반응에서 염소가 모두 산화된다고 보기. Cl2가 되는 염소만 산화수가 −1에서 0으로 변하고, MnCl2로 남는 염소는 −1입니다.

대표 예제

눌러서 풀이를 펼치세요.

CuO + H2 → Cu + H2O에서 각 원자의 산화수 변화를 적고, 산화제와 환원제를 고르시오. H2O2에서 산소의 산화수도 구하시오.

CuO에서 산소는 −2, 구리는 +2입니다. H2는 홑원소라 0입니다. Cu는 홑원소라 0이고, H2O에서 수소는 +1, 산소는 −2입니다.

구리는 +2 → 0으로 감소하므로 환원됩니다. CuO가 산화제입니다. 수소는 0 → +1로 증가하므로 산화됩니다. H2가 환원제입니다. 산소는 −2로 유지됩니다. 이동한 전자는 수소 분자 1개당 2개이고 구리 1개가 2개를 받아 맞습니다.

H2O2는 2×(+1) + 2O = 0이므로 산소의 산화수는 −1입니다. 물의 산소 −2와 다릅니다.

알루미늄 5.4 g(0.20 mol)과 구리(Ⅱ) 이온 0.15 mol이 반응한다. 반응식을 완성하고, 한계가 되는 쪽, 석출되는 구리의 질량, 이동한 전자의 몰수를 구하시오. 원자량은 Al 27, Cu 64이다.

반쪽 반응은 Al → Al3+ + 3e−, Cu2+ + 2e− → Cu입니다. 전자를 6개로 맞추면 2Al + 3Cu2+ → 2Al3+ + 3Cu입니다. 전하는 양쪽 모두 +6입니다.

비교값은 알루미늄 0.20/2 = 0.10, 구리(Ⅱ) 이온 0.15/3 = 0.050입니다. 작은 쪽이 한계이므로 구리(Ⅱ) 이온이 한계입니다.

석출되는 구리는 0.15 mol, 질량은 0.15 × 64 = 9.6 g입니다. 반응하는 알루미늄은 0.15 × (2/3) = 0.10 mol, 질량 2.7 g이고 2.7 g이 남습니다. 전자는 0.15 × 2 = 0.30 mol입니다. 알루미늄 0.10 mol × 3으로 검산해도 0.30 mol입니다.

MnO2 0.10 mol이 충분한 염산과 반응한다. 반응식을 쓰고, 산화제와 환원제, 발생하는 Cl2의 질량과 0°C·1기압 부피, 산화수가 변하지 않는 염소의 몰수를 구하시오. 원자량은 Mn 55, O 16, Cl 35.5, H 1이다.

반응식은 MnO2 + 4HCl → MnCl2 + Cl2 + 2H2O입니다. Mn은 +4 → +2로 환원되므로 MnO2가 산화제입니다. Cl의 일부가 −1 → 0으로 산화되므로 HCl이 환원제입니다.

Cl2는 0.10 mol입니다. 분자량 71이므로 질량은 7.1 g이고, 0°C·1기압 부피는 0.10 × 22.4 = 2.24 L입니다. 전자는 0.20 mol입니다.

HCl 0.40 mol 중 Cl2가 되는 염소는 0.20 mol이고, MnCl2에 남는 염소도 0.20 mol입니다. 이 0.20 mol의 산화수는 −1 그대로입니다.

질량 검산은 MnO2 8.7 g + HCl 14.6 g = 23.3 g, MnCl2 12.6 g + Cl2 7.1 g + H2O 3.6 g = 23.3 g입니다.

황산 구리(Ⅱ) 수용액의 모형이 반응 전 Cu2+ 6개, SO42− 6개였다. 아연판을 넣었더니 Cu2+ 1개, Zn2+ 5개, SO42− 6개가 되었다. 입자 1개 = 0.020 mol일 때 이동한 전자의 몰수와, 같은 전자가 다니엘 전지의 도선으로 흐를 때 구리판과 아연판의 질량 변화를 구하시오. 원자량은 Cu 64, Zn 65이다.

Cu2+는 5개 줄고 Zn2+는 5개 늘었습니다. SO42−는 6개 그대로라 구경꾼입니다. 전하는 1×2 + 5×2 = 12, 황산 이온 6×2 = 12로 같습니다.

구리(Ⅱ) 이온 1개는 전자 2개를 받습니다. 5개 × 2 × 0.020 mol = 0.20 mol의 전자가 이동합니다. 아연 5개 × 2 × 0.020으로 검산해도 0.20 mol입니다.

다니엘 전지에서 이 전자는 아연 음극에서 구리 양극으로 도선을 따라 갑니다. 석출되는 구리는 0.10 mol, 질량 6.4 g 증가입니다. 녹는 아연은 0.10 mol, 질량 6.5 g 감소입니다. 염다리로 전자가 이동하는 것은 아닙니다.

난이도별 한 줄 정리

쉬움

한 줄

산화 환원은 전자라는 공을 주고받는 일입니다. 공을 넘긴 원자는 산화수가 올라가고 환원제가 됩니다. 공을 받은 원자는 산화수가 내려가고 산화제가 됩니다. 준 개수와 받은 개수는 같습니다.

  • 홑원소는 산화수 0, 산소는 대개 −2, 과산화 수소의 산소만 −1로 기억하면 대부분의 값이 나옵니다.
  • 반응성이 큰 금속이 작은 금속의 이온에게 전자를 건넵니다. 그 금속이 전지의 음극입니다.
  • 전자는 도선으로, 이온은 용액으로 움직입니다.
고급

풀이 순서는 (1) 알려진 산화수를 먼저 넣고 미지 원자를 합 규칙으로 구하기 (2) 증가한 원자와 감소한 원자에 전자 수를 적기 (3) 최소공배수로 반쪽 반응의 계수를 맞추기 (4) 원자 수와 전하를 검산하기 (5) 이온화 경향으로 실제 방향인지 확인하기입니다.

모형 문항은 구경꾼 음이온으로 전하 합을 먼저 맞춘 뒤, 환원된 이온 개수에 받은 전자 수를 곱해 전자 몰수를 구합니다. 전지 문항은 반응성이 큰 금속을 음극으로 두고, 질량 감소는 산화 반쪽, 질량 증가 또는 기체 발생은 환원 반쪽에 연결합니다. 볼타 전지의 환원 생성물은 수소이고, 다니엘 전지의 환원 생성물은 구리 금속입니다.
