성향별 공부법

수능 한국사 · 논리형 · 암기형 · 시각형 · 실전형

고른 성향은 이 사이트의 모든 과목에서 기억되고, 각 파트 첫머리의 ‘내 성향으로 이 파트 공부하기’ 상자도 같은 성향으로 바뀝니다.

한국사는 외울 것이 많은 과목처럼 보이지만, 문항이 실제로 묻는 것은 “이 자료는 어느 시대인가”와 “무엇이 먼저인가”입니다. 제도와 사건을 문제 → 해결책, 원인 → 결과로 이어 두면 순서는 외우지 않아도 나오고, 남는 것은 이름과 몇 개의 연도뿐입니다. 논리형은 이 사슬부터 세우고, 사슬에 걸리지 않는 이름만 따로 외우면 됩니다.

나는 어떤 성향일까?

아래 중 가장 많이 “맞다” 싶은 줄이 내 성향입니다. 두 가지가 비슷하면 약한 과목에서 더 맞는 쪽을 고르세요.

논리형“왜 그런데?”가 풀려야 외워진다 · 공식이나 규칙을 스스로 유도해 보고 싶다 · 이유 없이 외우라고 하면 집중이 안 된다
암기형표·목록으로 정리해 반복하면 확실히 남는다 · 카드나 빈칸 채우기가 편하다 · 정해진 분량을 꾸준히 하는 게 잘 맞는다
시각형그림·지도·도식으로 보면 한 번에 기억난다 · 노트에 화살표와 색을 많이 쓴다 · 글로만 된 설명은 잘 안 들어온다
실전형설명보다 문제를 먼저 풀어야 감이 온다 · 틀리면서 배우는 게 빠르다 · 시간을 재고 푸는 게 재미있다
내 성향 고르기

논리형

논리형 — 원리·인과로 납득해야 기억한다. 인과 사슬로 순서를 유도할 수 있어 생각보다 잘 맞습니다. 다만 사료 속 키워드·이름은 이유 없이 외워야 하는 부분이 있습니다.

이 과목의 기본 원칙

  • 모든 제도와 개혁을 “어떤 문제를 풀려고 나왔나”로 읽습니다. 광종의 노비안검법은 ‘호족의 힘(노비)을 줄이려고’, 대동법은 ‘방납의 폐단을 없애려고’ 나왔습니다. 목적을 알면 왕과 정책의 짝이 저절로 맞춰집니다.
  • 사건은 앞 사건의 결과가 다음 사건의 원인이 되도록 사슬로 잇습니다(임오군란 → 청의 간섭 강화 → 갑신정변). 순서 문항은 사슬만 있으면 연도를 몰라도 풀립니다.
  • 연도는 사슬을 고정하는 앵커 10여 개만 외웁니다(676, 918, 1392, 1592, 1876, 1894, 1910, 1919, 1945, 1950, 1960, 1987 등). 나머지는 앵커 사이의 인과 위치로 정합니다.

공부 순서

  1. 파트를 읽으며 ‘문제 → 해결책’ 쌍과 ‘원인 → 결과’ 화살표를 표시
  2. 빈 종이에 파트의 사슬을 처음부터 끝까지 다시 써 보기(막히는 고리가 공부할 곳)
  3. 사슬에 안 걸리는 이름·풍습·기구는 ‘이유 없는 이름’ 목록으로 분리해 짧게 반복
  4. 기출은 자료 → 시대 판정 근거 단어 → 선지 시대를 한 줄씩 쓰며 풀기

한 주 배치평일: 파트 1~2개 사슬 세우기와 기출 10문항. 주말: 시대를 가로지르는 주제 사슬(토지 제도, 수취 제도, 통치 기구)을 한 장에 정리.

논리형 함정인과가 그럴듯하면 실제와 다른 순서도 맞는 것처럼 느껴집니다. 사슬의 고리마다 교과서 근거(사료 단어 하나)를 붙여 두세요. 또 사료 문항은 시대 판정 단어를 알아야 시작할 수 있어, 단어 목록 암기를 건너뛰면 안 됩니다.

파트별 공략

1. 선사 시대와 고조선, 여러 나라 →

  1. 도구가 생활을 정한다: 뗀석기(구석기) → 사냥·채집 → 먹을 것을 따라 이동 → 동굴·막집
  2. 간석기·토기(신석기) → 농경 시작 → 한곳에 정착(움집) → 곡식을 저장할 토기가 필요
  3. 청동기 → 농경 확대 → 남는 생산물 → 사유 재산과 계급 → 지배자 무덤(고인돌) → 국가(고조선)
  4. 고조선의 8조법은 사회 모습의 증거: 살인 처벌(생명 중시), 상해는 곡식으로 배상(농경·사유 재산), 도둑은 노비로(신분 제도)
  5. 여러 나라의 풍습은 정치 구조와 연결: 부여·고구려는 왕 아래 여러 가(加)가 따로 다스리는 연맹(사출도·제가 회의), 삼한은 제사장(천군)과 소도가 따로 있는 제정 분리

외울 것은 이것뿐나라별 풍습 이름(영고·동맹·무천·서옥제·민며느리제·책화·소도)과 나라 짝

나머지는 유도시대별 도구–생활–주거 표, 8조법 조항에서 사회 성격

논리형 함정풍습 이름은 대부분 이유로 유도되지 않는 ‘이름’입니다. 사슬로 맞히려 하지 말고 이유 없는 이름 목록에 넣으세요.

2. 삼국의 성립과 발전, 가야 →

  1. 중앙 집권 국가가 되는 조건 세 가지: 율령(제도), 불교 수용(사상 통일), 왕권 강화·영토 확장 → 나라마다 이 세 칸을 채운 왕을 찾는다
  2. 고구려 소수림왕(율령·불교·태학) / 백제 고이왕(율령·관등)·침류왕(불교) / 신라 법흥왕(율령·불교 공인)
  3. 한강 유역 = 넓은 농토 + 중국과 통하는 바닷길 → 한강을 차지한 나라가 전성기
  4. 그래서 전성기 순서 = 한강 차지 순서: 백제 4세기(근초고왕) → 고구려 5세기(광개토 대왕·장수왕, 평양 천도와 남진) → 신라 6세기(진흥왕)
  5. 고구려 남진에 맞서 나제 동맹 → 신라가 한강 하류까지 차지하며 동맹이 깨짐 → 관산성 전투(백제 성왕 전사)

외울 것은 이것뿐왕–업적 짝(근초고왕, 광개토 대왕, 장수왕, 진흥왕 순수비), 가야의 특징(철·해상 교역·연맹)

나머지는 유도삼국 전성기 순서, 나제 동맹의 성립과 결렬, 율령·불교 수용 왕의 표

논리형 함정‘율령 반포’처럼 같은 업적을 나라마다 다른 왕이 했습니다. 왕 이름이 아니라 ‘나라 × 조건’ 표의 칸으로 기억하세요.

3. 남북국 시대: 통일 신라와 발해, 후삼국 →

  1. 나당 동맹 → 백제 멸망(660)·고구려 멸망(668) → 당이 한반도 전체를 지배하려 함 → 나당 전쟁(매소성·기벌포) → 통일(676)
  2. 통일 후 문제: 진골 귀족의 힘 → 신문왕이 견제: 김흠돌의 난 진압, 관료전 지급·녹읍 폐지(귀족이 백성의 노동력을 거두던 근거를 없앰), 국학 설치
  3. 하대: 왕위 다툼 → 중앙이 지방을 통제 못 함 → 호족 성장 → 이들을 뒷받침한 새 사상(선종, 풍수지리설)과 6두품의 불만 → 후삼국
  4. 발해(698, 대조영)는 고구려를 이었다: 지배층에 고구려 유민, 일본에 보낸 국서에서 ‘고려’라 칭함, 온돌 등 고구려 문화

외울 것은 이것뿐연도 앵커 660·668·676·698, 신문왕 정책 묶음, 발해 왕별 업적(무왕·문왕·선왕)

나머지는 유도하대 사회 변화의 인과, 녹읍 폐지(신문왕) → 부활(경덕왕)의 의미

논리형 함정녹읍 폐지와 부활의 순서를 헷갈립니다. ‘왕권이 강할 때 폐지, 약해지면서 부활’로 왕권의 흐름과 묶으세요.

4. 고려의 성립과 발전 →

  1. 건국 초 문제 = 지방 호족이 강하다 → 태조는 끌어안고(혼인·사성 정책) 동시에 견제(사심관·기인 제도)
  2. 광종은 호족의 힘을 직접 줄인다: 노비안검법(호족의 노비 = 경제력·군사력 축소), 과거제(호족 대신 시험으로 뽑은 관료)
  3. 성종은 나라의 틀을 세운다: 최승로의 시무 28조 → 유교 정치, 12목에 지방관 파견
  4. 문신 중심 귀족 사회 → 무신 차별 → 무신 정변(1170) → 무신 정권 → 통제가 약해져 하층민 봉기(망이·망소이, 만적)
  5. 외적 순서: 거란(서희 담판, 강감찬 귀주 대첩) → 여진(윤관 별무반) → 몽골(강화 천도, 삼별초) → 원 간섭기 → 공민왕이 원이 약해진 틈에 반원 개혁(쌍성총관부 수복, 정동행성 이문소 폐지) → 신진 사대부·신흥 무인 성장 → 조선 건국

외울 것은 이것뿐왕–정책 짝(태조·광종·성종·공민왕), 고려 독자 기구(도병마사·식목도감), 연도 앵커 918·1170

나머지는 유도개혁의 목적(누구를 견제하려 했나), 대외 항쟁 순서

논리형 함정광종과 성종의 정책을 섞기 쉽습니다. 광종은 ‘호족을 누르는 왕’, 성종은 ‘유교로 제도를 짜는 왕’이라는 목적으로 구분하세요.

5. 조선 전기: 건국·체제 정비와 사림, 양난 →

  1. 고려 말 문제(권문세족의 대토지, 불교의 폐단) → 신진 사대부가 과전법(1391)으로 관리의 경제 기반을 새로 짜고 → 조선 건국(1392), 성리학 국가
  2. 왕권을 어떻게 볼 것인가로 정치 형태가 바뀐다: 태종·세조는 6조 직계제(왕이 직접), 세종은 의정부 서사제(재상과 협의)
  3. 나눠 줄 토지가 줄어든다 → 과전법 → 직전법(세조, 현직 관리에게만) → 관수 관급제(성종, 국가가 대신 거둠) → 결국 녹봉만
  4. 성종 때 사림이 등용되어 훈구와 충돌 → 사화 → 사림은 지방(서원·향약)에 기반을 쌓고 → 선조 때 정권을 잡은 뒤 붕당(동인·서인)
  5. 임진왜란(1592) → 의병과 수군의 활약, 훈련도감 → 호란(정묘 1627·병자 1636) → 북벌론

외울 것은 이것뿐연도 앵커 1392·1592·1636, 4대 사화 이름과 순서(무오·갑자·기묘·을사), 경국대전 완성(성종)

나머지는 유도6조 직계제와 의정부 서사제가 쓰인 왕, 토지 제도 변화 순서

논리형 함정세종과 세조의 정치 형태를 바꿔 기억하기 쉽습니다. 세조는 계유정난으로 즉위해 왕권을 세워야 했으므로 6조 직계제라는 이유와 함께 묶으세요.

6. 조선 후기: 정치·경제·사회·문화의 변화 →

  1. 양난 뒤 문제 = 무너진 국가 재정과 농민 부담 → 세금 세 가지를 차례로 고친다
  2. 공납(특산물)을 대신 내주며 폭리를 취한 방납의 폐단 → 대동법(쌀·토지 기준, 광해군 때 경기도부터) / 군포 2필 부담 → 균역법(1필, 영조) / 전세 → 영정법(1결당 4~6두로 고정, 인조)
  3. 대동법 → 관청에 물건을 대는 공인 등장 → 상품 화폐 경제 발달(장시, 상평통보) → 돈을 번 농민·상인과 몰락 양반 → 신분제 동요(공명첩, 납속, 족보 매입)
  4. 정치: 붕당이 서로 견제하다가 숙종의 환국으로 한쪽이 독점 → 영조·정조의 탕평 → 정조 사후 견제 세력이 없어져 세도 정치 → 삼정의 문란 → 홍경래의 난(1811), 임술 농민 봉기(1862)
  5. 실학은 ‘현실 문제를 어떻게 풀 것인가’의 학문 → 농촌 문제로 본 쪽(유형원·이익·정약용: 토지 개혁) / 상공업 부진으로 본 쪽(박지원·박제가: 수레·선박, 청 문물 수용)

외울 것은 이것뿐수취 개편 법–왕 짝(대동법·균역법·영정법), 균역법의 재정 보충책(결작·선무군관포·어염세), 실학자 대표 저서

나머지는 유도경제 변화 → 사회 변화의 사슬, 실학 두 갈래의 구분

논리형 함정균역법으로 줄어든 군포를 메우는 방법은 ‘1필로 줄인 만큼 다른 데서 걷는다’는 이유로 떠올릴 수는 있지만 세 이름은 외워야 합니다.

7. 근대: 개항에서 국권 피탈까지 →

  1. 흥선 대원군: 안으로 왕권 강화(비변사 축소, 서원 정리, 경복궁 중건), 밖으로 통상 거부(병인양요·신미양요 → 척화비)
  2. 강화도 조약(1876)으로 개항 → 불평등 조항(해안 측량, 치외 법권) → 개화 정책을 둘러싼 갈등(개화파 vs 위정척사)
  3. 임오군란(1882, 구식 군인 차별) → 청의 간섭 강화 → 이에 반발한 급진 개화파의 갑신정변(1884) → 실패
  4. 동학 농민 운동(1894, 반봉건·반외세) → 청·일 군대 출병 → 청일 전쟁 → 일본 주도의 갑오개혁 → 을미사변(1895) → 아관파천(1896) → 대한 제국(1897, 광무개혁)
  5. 러일 전쟁 → 을사늑약(1905, 외교권) → 고종 강제 퇴위·군대 해산(1907) → 국권 피탈(1910). 이에 맞선 의병(을미·을사·정미)과 애국 계몽 운동

외울 것은 이것뿐연도 앵커 1876·1882·1884·1894·1897·1905·1910, 조약별 핵심 조항

나머지는 유도사건 순서(각 사건의 결과가 다음 사건의 원인), 의병 세 시기의 계기

논리형 함정비슷한 개혁안(갑신정변 14개조, 폐정 개혁안, 홍범 14조)을 섞습니다. 먼저 주체(급진 개화파 / 농민 / 정부)를 확인하면 내용이 정해집니다.

8. 일제 강점기와 민족 운동 →

  1. 통치 방식은 일제의 필요에 따라 바뀐다: 1910년대 무단 통치(헌병 경찰) + 토지 조사 사업(식민지 세금 기반 마련)
  2. 3·1 운동(1919)으로 무력만으로는 통치가 어렵다는 것이 드러남 → 1920년대 ‘문화 통치’(보통 경찰, 친일파를 키워 민족 분열) + 산미 증식 계획(일본의 쌀 부족)
  3. 대륙 침략(1931 만주 사변, 1937 중일 전쟁) → 조선을 병참 기지로 → 민족 말살 통치(황국 신민화, 창씨개명, 국가 총동원법 1938)
  4. 민족 운동도 그에 맞춰 대응: 3·1 운동 → 대한민국 임시 정부(1919) → 무장 독립 전쟁(봉오동·청산리 1920) / 실력 양성 운동 / 사회주의 → 좌우 합작 신간회(1927)
  5. 1930년대 이후: 한중 연합 작전, 한인 애국단(1931) → 한국광복군(1940) → 광복

외울 것은 이것뿐시기 구분 연도(1910·1919·1931·1937), 시기 판정 단어(헌병 경찰·보통 경찰·창씨개명), 단체와 인물

나머지는 유도통치 정책 ↔ 민족 운동의 대응 짝, 경제 수탈 정책의 순서

논리형 함정문화 통치를 ‘완화’로만 읽으면 선지에서 틀립니다. 목적은 친일파를 키워 민족을 분열시키는 것이었다는 이유까지 함께 기억하세요.

9. 현대: 광복 이후 대한민국의 발전 →

  1. 광복(1945) → 모스크바 3국 외상 회의(신탁 통치 논의) → 찬탁·반탁으로 좌우 대립 → 미소 공동 위원회 결렬 → 유엔 → 5·10 총선거(1948) → 정부 수립
  2. 6·25 전쟁(1950~1953): 북한 남침 → 낙동강 방어선 → 인천 상륙 작전 → 중국군 개입 → 정전 협정
  3. 민주주의는 ‘장기 집권·억압 → 저항 → 개헌’이 되풀이된다: 3·15 부정 선거 → 4·19 혁명(1960) / 유신 헌법(1972, 대통령 간선) → 부마 항쟁·10·26 / 5·18 민주화 운동(1980) / 6월 민주 항쟁(1987) → 대통령 직선제 개헌
  4. 경제: 원조 경제(1950년대) → 경제 개발 5개년 계획(1960년대 경공업 → 1970년대 중화학 공업) → 외환 위기(1997)
  5. 통일 정책은 정부와 짝: 7·4 남북 공동 성명(1972) → 남북 기본 합의서(1991) → 6·15 남북 공동 선언(2000)

외울 것은 이것뿐연도 앵커 1945·1948·1950·1960·1972·1980·1987, 통일 문서 이름

나머지는 유도민주화 운동 순서, 헌법 개정의 방향(간선 ↔ 직선)

논리형 함정통일 정책 문서를 정부와 떼어 외우면 순서가 섞입니다. 문서마다 그때의 정부를 붙이세요.

10. 한국사 재밌게 외우는 법 →

  1. 이유 없는 이름도 ‘뜻’을 풀면 이유가 생긴다: 녹읍(祿 녹봉 + 邑 고을 → 녹봉 대신 받는 고을), 사심관(事審 일을 살핌 → 출신 지역을 살피는 관리)
  2. 뜻으로도 안 풀리는 이름은 인과 사슬의 고리에 걸어 둔다(‘호족 견제’ 고리에 사심관·기인 제도)
  3. 두음 암기는 사슬의 순서를 확인하는 보조로만 쓴다 — 사슬을 대신하면 응용 문항에서 막힌다

외울 것은 이것뿐이 파트의 두음·이야기 중 내가 사슬로 못 만든 것만

나머지는 유도나머지는 각 시대 파트의 사슬에서

논리형 함정재미있는 암기법을 다 외우려 하면 양이 늘어납니다. 논리형은 사슬이 안 되는 구멍에만 골라 쓰세요.

11. 수능 한국사 실전 전략 →

  1. 모든 문항은 같은 순서로 푼다: 자료에서 시대 판정 단어 찾기 → 시대 확정 → 선지마다 시대 붙이기 → 같은 시대 선지 고르기
  2. 판정 단어가 없으면 인과 사슬에서 앞뒤를 정한다(순서 문항)
  3. 절대평가(40점 이상 1등급)이므로 3점 문항을 확실히 맞히는 것이 시간보다 중요하다

외울 것은 이것뿐시대 판정 단어 목록

나머지는 유도선지의 시대는 사슬에서

논리형 함정익숙한 단어 하나로 성급하게 시대를 정합니다. 자료 속 단어 두 개 이상이 같은 시대를 가리킬 때 확정하세요.
