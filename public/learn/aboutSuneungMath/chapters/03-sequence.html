수열

Part 3 · 수학Ⅰ

등차·등비수열, 시그마, 수열의 합, 귀납적 정의, 수학적 귀납법

4.1회당 문항 수
13.9점회당 배점
4~5회차별 범위
69최근 17회 누적

수능 2018~2026학년도 + 6·9월 모의평가 17회(2018~2020학년도는 2009 개정 교육과정)(510문항) 기준. 문항 본문 키워드로 분류한 값이라 ±1문항 오차가 있을 수 있습니다.

수열은 일반항과 합의 계산, 그리고 합 Sn에서 항 an을 복원하는 추론이 함께 나옵니다. 등차수열과 등비수열은 공식을 조건에 맞게 쓰고, 그 밖의 수열은 부분분수·분모의 유리화·계차로 합을 상쇄합니다. 점화식은 항을 몇 개 구해 규칙을 찾은 뒤, 수학적 귀납법으로 그 규칙이 모든 자연수에서 성립하는지 확인합니다.

하나만 고른다면수열은 이웃한 항 사이의 규칙이다 — 차가 일정하면 등차, 비가 일정하면 등비, 이웃한 합의 차는 항(an = Sn − Sn−1)이다.

왜 사슬

다음 단계를 먼저 머릿속으로 떠올린 뒤, 가려진 단계를 눌러 맞았는지 확인하세요.

  1. 이웃한 항의 차가 일정하면 등차 → an = a + (n − 1)d, 합은 처음과 끝의 평균 × 항의 개수(Sn = n(a + l)/2)
  2. 이웃한 항의 비가 일정하면 등비 → an = arn−1, 합은 Sn − rSn에서 가운데가 지워져 a(rn − 1)/(r − 1)(r = 1이면 na)
  3. ∑는 나눠 더하고 상수를 밖으로 뺄 수 있다 → ∑k, ∑k2, ∑k3 공식과 이웃끼리 지워지는 꼴(부분분수, 분모의 유리화, 계차)로 합을 닫는다
  4. Sn은 n번째까지의 총합 → 이웃한 두 합의 차가 항이므로 an = Sn − Sn−1(n ≥ 2), 첫째항은 a1 = S1로 따로 확인
  5. 첫째항과 점화식만 있으면 수열이 정해진다 → 항을 몇 개 써서 규칙을 찾고, ‘1에서 참, k에서 참이면 k + 1에서 참’(수학적 귀납법)으로 모든 자연수에서 확인

등차수열 — 같은 수를 더해 가는 수열

첫째항 a에 공차 d를 계속 더하면 제n항은 첫째항에서 n − 1칸 떨어져 있으므로 an = a + (n − 1)d입니다. 두 항이 주어지면 빼서 d부터 구합니다. 제3항이 7, 제7항이 19이면 a + 2d = 7, a + 6d = 19에서 4d = 12, d = 3, a = 1입니다.

합은 처음과 끝을 짝지어 구합니다. S = a1 + a2 + … + an을 거꾸로 적어 위아래로 더하면 각 쌍의 합이 모두 a1 + an이고 쌍이 n개이므로 2S = n(a1 + an), 곧 Sn = n(a + l)/2입니다(l은 끝항). 위 수열의 제10항은 28이라 S10 = 10 × 29/2 = 145이고, 1부터 n까지의 합 n(n + 1)/2도 같은 짝짓기에서 나옵니다.

a, b, c가 등차이면 b − a = c − b에서 2b = a + c, 곧 등차중항은 두 수의 평균이고, 2와 14 사이에 3개를 넣으면 간격이 4칸이라 공차는 3입니다. 공차가 0이 아니면 Sn은 상수항이 없는 n의 이차식이므로, 거꾸로 Sn에 상수항이 있으면 첫째항에서 규칙이 어긋납니다. Sn = n² + 1이면 항이 2, 3, 5, 7이라 차가 일정하지 않습니다.

등비수열 — 같은 수를 곱해 가는 수열과 S − rS

첫째항 a에 공비 r을 계속 곱하면 제n항은 r을 n − 1번 곱한 an = arn−1입니다. 합은 짝짓기가 통하지 않아 다른 방법을 씁니다. S = a + ar + … + arn−1에 r을 곱하면 rS = ar + … + arn으로 한 칸씩 밀리므로, 빼면 가운데가 모두 지워져 S − rS = a − arn이 남습니다.

따라서 r ≠ 1이면 Sn = a(rn − 1)/(r − 1)이고, r = 1이면 0으로 나눌 수 없으니 모든 항이 a인 Sn = na를 따로 씁니다. 첫째항 2, 공비 3이면 S5 = 2(35 − 1)/2 = 242로 2 + 6 + 18 + 54 + 162와 같고, 공비가 음수여도 같은 공식이라 5, −10, 20, …의 S6 = 5(64 − 1)/(−3) = −105입니다.

a, b, c가 등비이면 b/a = c/b에서 b² = ac이고, ac > 0이면 b = ±√(ac)로 두 개입니다. 4와 16의 등비중항은 8과 −8이며, 4, −8, 16은 공비가 −2인 등비수열입니다. ac < 0이면 제곱해서 음수가 되는 실수가 없어 등비중항이 없습니다.

시그마와 합의 공식 — 이웃한 차를 더해 만든다

∑k=1n ak는 a1부터 an까지 차례로 더하라는 약속일 뿐이라, 성질도 덧셈을 다시 묶는 데서만 나옵니다. 그래서 ∑(ak + bk) = ∑ak + ∑bk, ∑cak = c∑ak, ∑c = cn은 성립하지만 곱의 합은 합의 곱이 아니어서, ∑k²과 (∑k)²은 n = 3에서 14와 36으로 다릅니다.

제곱의 합 공식은 이웃한 항의 차를 더해 만듭니다. (k + 1)³ − k³ = 3k² + 3k + 1을 k = 1부터 n까지 더하면 왼쪽은 가운데가 지워져 (n + 1)³ − 1만 남으므로, (n + 1)³ − 1 = 3∑k² + 3·n(n + 1)/2 + n을 정리해 ∑k² = n(n + 1)(2n + 1)/6을 얻습니다. 세제곱의 합은 {n(n + 1)/2}²이고, 공식은 n = 3을 넣어 6, 14, 36이 나오는지로 검산합니다.

Sₙ에서 aₙ 되찾기 — 첫째항은 따로 확인

Sn은 제n항까지 쌓인 합이므로 맨 위 한 층을 걷어 내면 항이 나옵니다. 즉 n ≥ 2이면 an = Sn − Sn−1이고, n = 1이면 S0이 없으므로 a1 = S1로 따로 구합니다. Sn = n² + n이면 n ≥ 2에서 an = 2n이고 n = 1에서도 2로 맞아 한 식으로 합칩니다.

맞지 않는 경우가 함정입니다. Sn = 2n이면 n ≥ 2에서 an = 2n − 2n−1 = 2n−1이지만, n = 1을 넣은 1은 실제 첫째항 S1 = 2와 다릅니다. 항은 2, 2, 4, 8, …이고, 일부 구간의 합은 Sn − Sm−1이라 홀수 수열 2n − 1의 제3항부터 제6항까지의 합은 S6 − S2 = 36 − 4 = 32입니다.

상쇄되는 합 — 부분분수, 유리화, 계차

등차도 등비도 아닌 합은 각 항을 이웃한 두 수의 차로 바꿔 더할 때 가운데가 지워지게 합니다. 1/{k(k + 1)} = 1/k − 1/(k + 1)이므로 ∑k=1n 1/{k(k + 1)} = 1 − 1/(n + 1) = n/(n + 1)이고, n = 10이면 10/11입니다. 간격이 2이면 1/k − 1/(k + 2) = 2/{k(k + 2)}라서 앞에 1/2을 붙여야 하고, 처음 두 항과 마지막 두 항이 남습니다.

근호가 있으면 분모를 유리화해 차를 만듭니다. 1/(√k + √(k + 1))에 √(k + 1) − √k를 위아래로 곱하면 분모가 (k + 1) − k = 1이 되므로 합은 √(n + 1) − 1이고, n = 99이면 9입니다. 계차수열 bn = an+1 − an도 같은 원리라 an = a1 + ∑k=1n−1 bk이고, a1 = 3, bk = 2k이면 an = 3 + n(n − 1), 곧 3, 5, 9, 15, …입니다.

점화식 — 이웃한 항의 규칙으로 수열을 정한다

첫째항과 이웃한 항 사이의 규칙(점화식)으로 수열을 정하는 것이 귀납적 정의입니다. an+1 = an + d는 등차, an+1 = ran은 등비이고, an+1 = pan + q(p ≠ 1)는 α = pα + q인 α를 빼서 등비로 바꿉니다. 두 식을 빼면 an+1 − α = p(an − α)가 되어 {an − α}가 공비 p인 등비수열이기 때문입니다.

a1 = 1, an+1 = 2an + 3이면 α = −3이라 an + 3 = 4·2n−1, 곧 an = 2n+1 − 3이고 1, 5, 13, 29로 확인됩니다. p = 1이면 α를 구하는 나눗셈이 안 되므로 등차로 따로 풉니다. 홀짝에 따라 규칙이 갈리면 항을 직접 몇 개 적은 뒤 홀수 항만 다시 모읍니다. a1 = 1이고 n이 홀수이면 an+1 = 2an, 짝수이면 an+1 = an + 3인 수열은 1, 2, 5, 10, 13, 26, …이고, 홀수 항 bm = a2m−1만 보면 bm+1 = 2bm + 3이라 바로 앞의 수열과 같습니다.

수학적 귀납법 — 시작과 이어짐, 두 조건

모든 자연수를 하나씩 확인할 수는 없으므로 두 가지만 보입니다. n = 1에서 참이고, n = k에서 참이라고 가정하면 n = k + 1에서도 참이면, 1에서 2로, 2에서 3으로 사슬이 끝없이 이어집니다. 시작이 없으면 사슬이 출발하지 않고 이어짐이 없으면 1에서 멈추므로, 둘 중 하나라도 빠지면 증명이 아닙니다.

1 + 3 + … + (2n − 1) = n²은 n = 1에서 1 = 1²이고, n = k일 때의 합 k²에 다음 홀수 2k + 1을 더하면 (k + 1)²이라 n = k + 1에서도 성립합니다. 핵심은 n = k + 1의 식 안에서 가정한 식을 찾아 바꿔 넣는 한 줄이고, 증명의 빈칸을 채우는 문항이 나오면 대개 이 자리를 묻습니다. 직전 두 항을 쓰는 점화식이면 처음 두 항을 확인하고 n = k, k + 1을 함께 가정합니다.

외울 것은 이것뿐등차·등비의 일반항과 합(공비가 1이면 na), ∑k·∑k2·∑k3 공식, a1 = S1과 an = Sn − Sn−1(n ≥ 2)

나머지는 유도등차중항·등비중항, 부분분수·유리화로 지워지는 합, 계차수열의 일반항, an+1 = pan + q의 일반항(α = q/(1 − p)를 빼서 등비로), 홀짝으로 갈리는 점화식

논리형 함정규칙이 보이면 바로 일반항으로 넘어가 n = 1에서 맞는지 확인을 건너뛰기 쉽습니다. Sn = 2n이면 차이 식 2n−1은 n = 1에서 1이지만 실제 첫째항은 S1 = 2입니다.

문제부터 부딪치고 싶다면 대표 예제를 먼저 풀고, 막힌 고리만 사슬에서 찾아 채우세요.

1. 등차수열과 등차중항

첫째항이 a, 공차가 d인 등차수열은 이웃한 항의 차가 항상 d입니다. 제n항과 첫째항부터 제n항까지의 합은 다음과 같습니다. 여기서 l = an은 끝항입니다.

an = a + (n − 1)d
Sn = n(a + l) / 2 = n{2a + (n − 1)d} / 2

합은 첫째항과 끝항의 평균에 항의 개수를 곱한 것입니다. 1부터 n까지의 자연수의 합이 n(n + 1)/2인 것도 평균 (1 + n)/2에 n을 곱한 결과입니다. n = 5이면 (1 + 5) × 5 / 2 = 15이고, 1 + 2 + 3 + 4 + 5 = 15입니다.

제3항이 7, 제7항이 19이면 a + 2d = 7, a + 6d = 19입니다. 두 식을 빼면 4d = 12, d = 3, a = 1입니다. 수열은 1, 4, 7, 10, …입니다. 제10항은 1 + 9 · 3 = 28이고, S10 = 10 × (1 + 28) / 2 = 145입니다. 공차 3인 열 항의 합으로 다시 보면 10 × (2 · 1 + 9 · 3) / 2 = 10 × 29 / 2 = 145입니다.

세 수 a, b, c가 이 순서대로 등차수열을 이루면 2b = a + c입니다. b를 a와 c의 등차중항이라고 하며 b = (a + c) / 2입니다. 3과 11의 등차중항은 7이고, 수열 3, 7, 11의 공차는 4입니다.

두 수 사이에 항을 여러 개 넣을 때도 전체는 한 등차수열입니다. 2와 14 사이에 3개를 넣으면 항이 5개, 간격은 4칸이므로 공차 (14 − 2) / 4 = 3입니다. 수열은 2, 5, 8, 11, 14입니다. 일반적으로 양 끝 사이에 m개를 넣으면 공차는 (끝 − 처음) / (m + 1)입니다.

TIP: 공차가 0이 아니면 등차수열의 합 Sn은 n에 대한 이차식입니다. 반대로 Sn = pn2 + qn처럼 상수항이 0인 이차식이면 an = Sn − Sn−1이 n의 일차식이 되어 등차수열이 됩니다. 상수항이 남아 있으면 첫째항만 공차에서 어긋날 수 있습니다. 예를 들어 Sn = n2 + 1이면 a1 = 2, a2 = 3, a3 = 5, a4 = 7이라 차가 1, 2, 2로 일정하지 않습니다.

2. 등비수열과 등비중항

첫째항이 a, 공비가 r인 등비수열은 각 항에 r을 곱하면 다음 항이 됩니다. a ≠ 0, r ≠ 0으로 둡니다.

an = a · rn−1
r ≠ 1일 때 Sn = a(rn − 1) / (r − 1)
r = 1일 때 Sn = na

r = 1이면 모든 항이 a이고 합은 na입니다. 이 경우를 일반 공식의 분모에 넣으면 0으로 나누게 되므로 반드시 따로 둡니다. 첫째항 2, 공비 3이면 제5항은 2 · 34 = 162이고, S5 = 2(35 − 1) / (3 − 1) = 2 × 242 / 2 = 242입니다. 2 + 6 + 18 + 54 + 162 = 242입니다.

공비가 음수이면 부호가 번갈아 나타납니다. 첫째항 5, 공비 −2, 제6항까지의 합은

S6 = 5{(−2)6 − 1} / (−2 − 1) = 5(64 − 1) / (−3) = −105

항은 5, −10, 20, −40, 80, −160입니다. 앞에서부터 더하면 −5, 15, −25, 55, −105로 공식과 맞습니다.

0이 아닌 세 수 a, b, c가 이 순서대로 등비수열을 이루면 b2 = ac입니다. b를 a와 c의 등비중항이라고 합니다. ac > 0이면 실수인 등비중항은 √(ac)와 −√(ac) 두 개입니다. 4와 16의 등비중항은 8과 −8입니다. 4, 8, 16은 공비 2이고, 4, −8, 16은 공비 −2입니다. −2와 −8의 등비중항도 4와 −4 두 개입니다. −2, 4, −8은 공비 −2, −2, −4, −8은 공비 2입니다. ac < 0이면 제곱해서 음수가 되는 실수 b가 없으므로 등비중항은 없습니다.

두 양수 사이에 m개의 양수 항을 등비로 넣으면, 처음에서 끝까지의 곱하는 횟수가 m + 1번이므로 공비는 (끝/처음)의 (m + 1)제곱근입니다. 부호가 번갈아 나타나는 공비는 그 제곱근의 부호를 따로 확인해야 합니다.

함정: r = 1을 합 공식의 분모에 넣지 마세요. 또 등비중항을 양의 제곱근 하나만 답하면, 공비가 음수인 수열이 빠집니다. 문제에서 양수라고 한정한 경우에만 양의 중항만 취합니다.

3. 시그마와 자주 쓰는 합, Sn과 an

∑k=1n ak는 a1 + a2 + … + an이라는 뜻입니다. k는 더하는 동안만 쓰는 문자라, 다른 문자로 바꿔도 합은 같습니다.

∑(ak + bk) = ∑ ak + ∑ bk
∑ c ak = c ∑ ak
∑k=1n c = cn
∑k=1n k = n(n + 1) / 2
∑k=1n k2 = n(n + 1)(2n + 1) / 6
∑k=1n k3 = {n(n + 1) / 2}2

n = 3으로 확인하면 1 + 2 + 3 = 6, 1 + 4 + 9 = 14, 1 + 8 + 27 = 36입니다. 공식은 3 · 4 / 2 = 6, 3 · 4 · 7 / 6 = 14, (3 · 4 / 2)2 = 36입니다. k2의 합과 (k의 합)2은 다릅니다. n = 3에서 (∑ k)2 = 36이지만 ∑ k2 = 14입니다. 세제곱의 합이 (자연수 합)2과 같다는 공식과 헷갈리기 쉽습니다.

∑k=1n k(k + 1) = ∑(k2 + k) = n(n + 1)(2n + 1)/6 + n(n + 1)/2입니다. 통분하면 n(n + 1)(n + 2) / 3입니다. n = 2이면 1 · 2 + 2 · 3 = 8이고, 2 · 3 · 4 / 3 = 8입니다.

합의 시작 번호가 1이 아니면 전체를 구한 뒤 앞부분을 빼거나, 번호를 치환합니다. ∑k=1n (k + 1) = ∑ k + ∑ 1 = n(n + 1)/2 + n = n(n + 3)/2입니다. 번호를 한 칸 밀면 ∑k=2n+1 k = {1부터 n + 1까지의 합} − 1 = (n + 1)(n + 2)/2 − 1 = n(n + 3)/2로 같습니다. n = 2이면 2 + 3 = 5이고 공식은 2 · 5 / 2 = 5입니다.

Sn으로 an 복원하기

Sn이 첫째항부터 제n항까지의 합이면 항은 합의 차이로 되돌아옵니다.

a1 = S1
n ≥ 2일 때 an = Sn − Sn−1

Sn = n2 + n이면 a1 = 2입니다. n ≥ 2이면 an = (n2 + n) − {(n − 1)2 + (n − 1)} = n2 + n − (n2 − n) = 2n입니다. n = 1에도 2 · 1 = 2로 맞으므로 모든 자연수 n에 대해 an = 2n입니다. 검산하면 ∑k=1n 2k = 2 · n(n + 1)/2 = n2 + n입니다.

같은 차가 n = 1에서 깨지는 예가 Sn = 2n입니다. a1 = 2, n ≥ 2이면 an = 2n − 2n−1 = 2n−1입니다. n = 1에 2n−1을 넣으면 1이 되어 a1 = 2와 다릅니다. 항은 2, 2, 4, 8, 16, …이고 합은 2, 4, 8, 16, …으로 2n이 됩니다. 차이 공식을 n = 1에 그대로 쓰지 않고 S1을 따로 확인해야 합니다.

일부 구간만의 합은 Sn − Sm−1 (m ≥ 2)입니다. 홀수 수열 an = 2n − 1의 첫째항부터의 합은 n2입니다. 제3항부터 제6항까지는 5 + 7 + 9 + 11 = 32이고, S6 − S2 = 36 − 4 = 32입니다. 항의 개수 4, 처음 5, 끝 11로 계산해도 4 × (5 + 11) / 2 = 32입니다.

함정: an = Sn − Sn−1은 n ≥ 2일 때의 식입니다. n = 1에 넣으면 S0이 생겨 첫째항이 틀어질 수 있습니다. 차이로 구한 식에 n = 1을 대입해 S1과 같은지 꼭 비교하세요.

4. 부분분수, 분모의 유리화, 계차수열

등차도 등비도 아닌 합은 각 항을 이웃끼리 빼는 모양으로 바꿉니다. 가운데가 사라지고 처음과 끝만 남습니다.

부분분수

1 / {k(k + 1)} = 1/k − 1/(k + 1)
∑k=1n 1/{k(k + 1)} = 1 − 1/(n + 1) = n/(n + 1)

n = 2이면 1/2 + 1/6 = 2/3이고, 2/3과 같습니다. 간격이 2이면 계수가 생깁니다.

1/k − 1/(k + 2) = 2 / {k(k + 2)}
1/{k(k + 2)} = (1/2){1/k − 1/(k + 2)}

따라서 ∑k=1n 1/{k(k + 2)} = (1/2){1 + 1/2 − 1/(n + 1) − 1/(n + 2)}입니다. n = 1이면 (1/2)(1 − 1/3) = 1/3이고, 실제 1/(1 · 3) = 1/3입니다. n = 2이면 (1/2)(1 + 1/2 − 1/3 − 1/4) = (1/2)(11/12) = 11/24입니다. 직접 더하면 1/3 + 1/8 = 11/24입니다. 앞의 1/2을 빠뜨리면 합이 두 배가 됩니다.

분모의 유리화

1 / (√k + √(k + 1))에 √(k + 1) − √k를 분자·분모에 곱하면 분모는 (k + 1) − k = 1이 되어 √(k + 1) − √k가 됩니다.

∑k=1n 1 / {√k + √(k + 1)} = ∑(√(k + 1) − √k) = √(n + 1) − 1

가운데 항이 차례로 지워집니다. n = 1이면 √2 − 1이고, 1/(1 + √2)를 유리화한 값과 같습니다. n = 99이면 √100 − 1 = 9입니다. n = 8이면 √9 − 1 = 2입니다.

계차수열

bn = an+1 − an을 계차수열이라고 합니다. 계차의 합은 원래 수열의 끝과 처음의 차입니다.

∑k=1n−1 bk = an − a1
an = a1 + ∑k=1n−1 bk

n = 1일 때의 합은 더할 항이 없는 빈 합이라 0으로 두면, 이 식은 n = 1에도 a1 = a1로 맞습니다. a1 = 3이고 an+1 − an = 2n이면 bk = 2k입니다.

an = 3 + ∑k=1n−1 2k = 3 + (n − 1)n

a2 = 3 + 2 = 5, a3 = 5 + 4 = 9, a4 = 9 + 6 = 15입니다. 식 3 + n(n − 1)에 넣으면 5, 9, 15로 같습니다. 계차가 등차나 등비이면 그 합 공식으로 an이 닫힌 식이 됩니다.

5. 귀납적 정의와 조건이 갈리는 점화식

첫째항과, 이웃한 항 사이의 규칙으로 수열을 정하는 것을 귀납적 정의라고 합니다. 그 규칙을 점화식이라고 합니다.

점화식수열일반항
a1 = a, an+1 = an + d등차an = a + (n − 1)d
a1 = a, an+1 = r an등비an = a rn−1
an+1 = p an + q (p ≠ 1)등비로 환원an − α = pn−1(a1 − α)

셋째 경우의 α는 α = pα + q를 만족하는 수, 곧 α = q / (1 − p)입니다. an+1 − α = p(an − α)가 되어 {an − α}가 공비 p인 등비가 됩니다. p = 1이면 이 나눗셈을 쓸 수 없고, an+1 = an + q인 등차로 따로 풉니다.

a1 = 1, an+1 = 2an + 3이면 α = 2α + 3에서 α = −3입니다. an+1 + 3 = 2(an + 3)이므로 an + 3 = (1 + 3) · 2n−1 = 2n+1입니다. 따라서 an = 2n+1 − 3입니다. 항은 1, 5, 13, 29, 61입니다. a2 = 2 · 1 + 3 = 5 = 23 − 3, a3 = 13 = 24 − 3, a5 = 26 − 3 = 61로 맞습니다.

조건이 갈리는 점화식

홀수 번째와 짝수 번째에서 규칙이 다르면, 항을 직접 몇 개 적은 뒤 홀수 항만, 짝수 항만 다시 모읍니다.

a1 = 1이고, n이 홀수일 때 an+1 = 2an, n이 짝수일 때 an+1 = an + 3이라고 하면

a1 = 1, a2 = 2, a3 = 5, a4 = 10, a5 = 13, a6 = 26, a7 = 29

홀수 항 bm = a2m−1은 b1 = 1, bm+1 = 2bm + 3입니다. 바로 앞의 점화식과 같으므로 bm = 2m+1 − 3입니다. a1 = 1, a3 = 5, a5 = 13, a7 = 29가 맞습니다. 짝수 항은 그 직전 홀수 항에 2를 곱한 값이므로 a2m = 2(2m+1 − 3) = 2m+2 − 6입니다. a2 = 2, a4 = 10, a6 = 26입니다.

규칙 찾기 문제는 차분을 한 번 보고, 비가 일정한지도 본 다음, 홀짝으로 갈리는지 확인하는 순서가 안전합니다. 차분 an+1 − an이 상수가 아니면 등차가 아니고, 비 an+1 / an이 상수가 아니면 등비가 아닙니다. 둘 다 아니면 계차의 합이나 홀짝 분리로 넘어갑니다.

항 번호는 자연수입니다.

이 교육과정에서 자연수는 1부터 시작합니다. 일반항에 n = 1을 넣어 첫째항이 나오는지, 점화식에 그 첫째항을 넣어 둘째항이 나오는지가 가장 빠른 검산입니다.

6. 수학적 귀납법

자연수 n에 대한 명제 P(n)이 모든 자연수에서 참임을 보이는 방법입니다. 절차는 두 단계입니다.

  1. 가장 작은 자연수에서 참임을 확인합니다. 보통 n = 1입니다. 명제가 n ≥ m에서만 말하면 m에서 확인합니다.
  2. n = k일 때 참이라고 가정하고, 그 가정만으로 n = k + 1일 때도 참임을 보입니다.

두 단계가 끝나면, 1에서 참이니 2에 의해 2에서도 참이고, 다시 3에서도 참입니다. 이렇게 모든 자연수로 이어집니다. 두 번째만 보이고 첫 단계를 빼먹으면 증명이 되지 않습니다. 가정은 n = k이지, 보여야 할 n = k + 1이 아닙니다.

1 + 3 + 5 + … + (2n − 1) = n2을 이 절차로 증명해 봅니다.

n = 1이면 왼쪽은 1, 오른쪽은 12이라 참입니다. n = k일 때 1 + 3 + … + (2k − 1) = k2이라고 가정합니다. n = k + 1의 왼쪽은 가정한 합에 다음 홀수 2(k + 1) − 1 = 2k + 1을 더한 것입니다. k2 + 2k + 1 = (k + 1)2이므로 참입니다. 따라서 모든 자연수 n에 대해 성립합니다. n = 4이면 1 + 3 + 5 + 7 = 16 = 42입니다.

∑k=1n k = n(n + 1)/2도 같은 방법입니다. n = 1이면 1 = 1입니다. n = k를 가정하면 n = k + 1의 합은 k(k + 1)/2 + (k + 1) = (k + 1)(k/2 + 1) = (k + 1)(k + 2)/2입니다.

제곱의 합 공식도 귀납법으로 확인할 수 있습니다. n = k를 가정하고 (k + 1)2을 더하면

k(k + 1)(2k + 1) / 6 + (k + 1)2
= (k + 1){k(2k + 1)/6 + (k + 1)}
= (k + 1)(2k2 + 7k + 6) / 6
= (k + 1)(k + 2)(2k + 3) / 6

2k2 + 7k + 6 = (2k + 3)(k + 2)이므로 마지막 등식이 성립합니다. 이것은 n = k + 1일 때의 공식입니다.

직전 한 항이 아니라 두 항을 사용하는 점화식이면, 처음 두 항을 확인하고 n = k와 n = k + 1을 함께 가정해 n = k + 2를 보입니다. 기본 절차의 첫 단계를 두 개로 늘린 것입니다.

TIP: 수능형 계산은 Sn이 주어지면 a1 = S1과 n ≥ 2의 차이를 따로 쓰고, 점화식은 네다섯 항을 적어 등차·등비·홀짝 중 어디에 속하는지 본 뒤 일반항을 구합니다. 구한 일반항은 n = 1과 n = 2를 점화식에 넣어 확인합니다. 모든 자연수에서 성립한다는 문장은 귀납법의 두 단계를 빠뜨리지 않고 씁니다.
③ 확인하기조건이 바뀐 문제로 확인 — 막히면 가장 쉬운 문제부터

자주 나오는 함정

  • 공비가 1인데도 Sn = a(rn − 1)/(r − 1)에 대입하는 경우. 분모가 0입니다. 합은 na입니다.
  • an = Sn − Sn−1을 n = 1에도 검사 없이 쓰는 경우. Sn = 2n이면 차이 식은 2n−1이지만 첫째항은 2입니다.
  • ∑ k2과 (∑ k)2을 같은 공식으로 쓰는 경우. 세제곱의 합이 (자연수 합)의 제곱입니다.
  • 등차중항과 등비중항을 바꿈. 등차중항은 평균 (a + c)/2, 등비중항은 ±√(ac)입니다.
  • 귀납법에서 n = k + 1만 변형하고 n = 1 확인을 빼먹는 경우. 시작 항이 없으면 사슬이 이어지지 않습니다.
  • 1/{k(k + 2)}의 부분분수에서 1/2을 빼먹음. 분자 1/k − 1/(k + 2)의 차는 2입니다.
  • 등비중항을 항상 하나로 쓰는 경우. 두 수의 곱이 양수이면 실수 중항은 두 개일 수 있습니다.
  • an+1 = an + q인데도 α = q/(1 − p)를 쓰는 경우. p = 1이면 등차수열로 따로 풉니다.

a + 2d = 7, a + 6d = 19입니다. 빼면 4d = 12, d = 3.

a1 = S1 = 21 = 2입니다.

n ≥ 2이면 an = 2n − 2n−1 = 2n−1입니다.

이 식을 n = 1에 넣으면 20 = 1이라 첫째항 2와 다릅니다. 그래서 a1 = 2, n ≥ 2일 때 an = 2n−1으로 나누어 적습니다.

항은 2, 2, 4, 8, …이고 S2 = 4 = 22, S3 = 8 = 23입니다.

∑k=110 1/{k(k + 1)}의 값을 구하시오.

1/{k(k + 1)} = 1/k − 1/(k + 1)입니다.

합은 (1 − 1/2) + (1/2 − 1/3) + … + (1/10 − 1/11)입니다.

가운데가 지워져 1 − 1/11 = 10/11입니다.

공식 n/(n + 1)에 n = 10을 넣어도 10/11입니다.

a1 = 1이다. n이 홀수이면 an+1 = 2an, n이 짝수이면 an+1 = an + 3이다. a6을 구하고, 홀수 항의 일반항을 구하시오.

차례로 계산합니다. a2 = 2 · 1 = 2, a3 = 2 + 3 = 5, a4 = 2 · 5 = 10, a5 = 10 + 3 = 13, a6 = 2 · 13 = 26.

홀수 항 bm = a2m−1은 b1 = 1, bm+1 = 2bm + 3입니다.

α = 2α + 3에서 α = −3. bm + 3 = 4 · 2m−1 = 2m+1이므로 bm = 2m+1 − 3입니다.

따라서 a2m−1 = 2m+1 − 3입니다. m = 3이면 a5 = 24 − 3 = 13, 그 다음 a6 = 26과 맞습니다.

한 줄

등차는 더하고, 등비는 곱합니다. 합 Sn은 쌓인 총량이고, 항 an은 새로 얹힌 한 층이라 이웃한 합의 차이입니다. 귀납법은 “1번이 참이고, 앞 번호가 참이면 다음 번호도 참”이라는 사슬입니다.

  • 공비가 1이면 합은 첫째항에 항의 개수를 곱합니다.
  • 부분분수와 유리화는 가운데 항을 지워 처음과 끝만 남깁니다.
  • 점화식은 네댓 항을 직접 써 보고 규칙을 찾습니다.
고급

Sn 문항은 a1 = S1을 먼저 적고, n ≥ 2에서만 차이를 전개한 뒤 그 식이 n = 1에서도 맞는지 비교합니다. 맞으면 한 식으로 합치고, 틀리면 첫째항을 분리해 적습니다.

점화식 an+1 = pan + q는 p = 1인지 먼저 갈라, 1이면 등차, 아니면 고정점 α를 빼서 등비로 바꿉니다. 홀짝으로 조건이 갈리면 홀수 항만 모아 다시 점화식을 만듭니다. 일반항을 모든 자연수에 대해 증명하라는 문장은 귀납법으로 n = 1 확인과 k에서 k + 1로의 이행을 둘 다 씁니다.

  1. 등비수열의 합 공식 a(rn − 1)/(r − 1)이 어떻게 나오는지, 그리고 왜 r = 1을 따로 두는지 설명해 보세요.
    내 설명과 비교하기

    Sn = a + ar + … + arn−1에 r을 곱하면 rSn = ar + ar2 + … + arn으로 한 칸씩 밀린 같은 항들이 생깁니다. 두 식을 빼면 가운데 항이 모두 지워져 rSn − Sn = arn − a, 즉 (r − 1)Sn = a(rn − 1)만 남습니다. 공식은 여기서 양변을 r − 1로 나눈 것이라 r = 1이면 0으로 나누게 되어 쓸 수 없습니다. r = 1이면 모든 항이 a이므로 합은 그냥 na입니다.

  2. 수학적 귀납법에서 첫 단계(n = 1 확인)를 빼면 왜 증명이 되지 않는지 말해 보세요.
    내 설명과 비교하기

    귀납법의 둘째 단계는 ‘n = k에서 참이면 n = k + 1에서도 참’이라는 연결 고리일 뿐, 어느 n에서 실제로 참인지는 말해 주지 않습니다. 예를 들어 ‘n2 + n은 홀수이다’는 k2 + k가 홀수라고 가정하면 (k + 1)2 + (k + 1) = (k2 + k) + 2(k + 1)도 홀수가 되어 둘째 단계를 통과하지만, n = 1에서 값이 2이고 실제로는 늘 짝수입니다. 첫 단계로 출발점이 참임을 확인해야 그 고리를 타고 2, 3, 4, …로 참이 전달되므로, 시작점과 연결 고리가 둘 다 있어야 증명이 됩니다.

책을 덮고 모르는 사람에게 설명하듯 소리 내어 먼저 답해 본 뒤 비교하세요. 막히는 곳이 아직 내 것이 아닌 곳이니, 그 고리만 위 사슬에서 다시 보면 됩니다.
