1. 네 가지 세기 — 순서와 중복으로 가릅니다

경우의 수는 두 법칙에서 출발합니다. 동시에 일어나지 않는 두 사건은 경우의 수를 더하고(합의 법칙), 잇달아 일어나는 두 사건은 곱합니다(곱의 법칙). 이 장의 공식은 모두 곱의 법칙을 상황에 맞게 정리한 것입니다.

서로 다른 n개에서 r개를 뽑는 방법은 두 질문으로 넷으로 나뉩니다. 뽑은 순서를 구별하는가, 그리고 같은 것을 다시 뽑을 수 있는가입니다.

중복 없음중복 허락
순서 있음(나열)순열 nPr = n! / (n − r)!중복순열 nΠr = nr
순서 없음(선택)조합 nCr = n! / {r! (n − r)!}중복조합 nHr = n+r−1Cr

왼쪽 열의 순열과 조합은 공통수학1에서 배운 내용입니다. 이 과목에서는 오른쪽 열의 두 가지와 ‘같은 것이 있는 순열’, 이항정리를 새로 다룹니다. 서로 다른 5개에서 2개를 뽑는 수로 네 칸을 채워 보면 차이가 보입니다.

5P2 = 5 × 4 = 20,   5Π2 = 52 = 25
5C2 = 10,   5H2 = 6C2 = 15

25 − 20 = 5는 같은 것을 두 번 뽑은 다섯 가지입니다. 15 − 10 = 5도 같은 다섯 가지입니다. 중복을 허락하면 ‘같은 것끼리 뽑은 경우’만큼 늘어납니다. 20 = 10 × 2!인 것은 뽑은 2개를 줄 세우는 방법이 2!가지이기 때문입니다. 순서를 구별하면 조합의 수에 줄 세우는 수가 곱해집니다.

TIP: 문제를 읽으면 식을 쓰기 전에 두 가지를 여백에 적습니다. ‘순서: 있다/없다’, ‘중복: 된다/안 된다’. 이 두 줄이 정해지지 않은 채 공식을 고르면 맞아도 우연입니다.

2. 중복순열

서로 다른 n개에서 중복을 허락하여 r개를 택해 일렬로 나열하는 것을 중복순열이라 하고, 그 수를 nΠr로 적습니다.

nΠr = nr

이유는 곱의 법칙입니다. 첫째 자리에 올 수 있는 것이 n가지입니다. 같은 것을 또 쓸 수 있으므로 둘째 자리도 n가지이고, r째 자리까지 모두 n가지입니다. 그래서 n을 r번 곱합니다. 순열과 달리 r이 n보다 커도 됩니다.

숫자 1, 2, 3으로 만드는 네 자리 수는 3Π4 = 34 = 81개입니다. 자리가 4개이고 자리마다 3가지입니다. ‘고르는 쪽’의 개수가 지수, ‘골라지는 후보’의 개수가 밑입니다.

함수의 개수

집합 X = {1, 2, 3}에서 Y = {a, b, c, d}로 가는 함수는 X의 원소마다 함숫값을 하나씩 정하면 만들어집니다. 1의 함숫값이 4가지, 2도 4가지, 3도 4가지이므로 43 = 64개입니다. 서로 다른 편지 5통을 우체통 3개에 넣는 방법도 같은 구조입니다. 편지마다 우체통을 하나 고르므로 35 = 243가지입니다.

함정: 함수의 개수를 34 = 81로 쓰는 실수가 많습니다. 고르는 주체는 정의역의 원소입니다. 정의역의 원소가 3개이므로 3번 고르고, 고를 때마다 공역의 4가지가 후보입니다. (공역의 크기)(정의역의 크기)입니다.

자리에 조건이 붙을 때

자리마다 후보의 수가 다르면 nr 대신 곱의 법칙을 그대로 씁니다. 숫자 0, 1, 2, 3에서 중복을 허락해 세 자리 자연수를 만들면, 백의 자리는 0을 뺀 3가지이고 십의 자리와 일의 자리는 4가지씩이므로 3 × 4 × 4 = 48개입니다. 이 가운데 짝수는 일의 자리가 0 또는 2이므로 3 × 4 × 2 = 24개입니다.

‘적어도 하나’는 전체에서 ‘하나도 없는 경우’를 뺍니다. 1, 2, 3으로 만든 네 자리 수 81개 가운데 1이 적어도 한 번 나오는 수는, 2와 3만으로 만든 24 = 16개를 뺀 65개입니다.

3. 같은 것이 있는 순열

n개 가운데 같은 것이 각각 p개, q개, …, r개 있을 때(p + q + … + r = n), 이들을 모두 일렬로 나열하는 경우의 수는 다음과 같습니다.

n! / (p! × q! × … × r!)

이유는 ‘구별해서 센 뒤 겹친 만큼 나누기’입니다. a, a, b, b, b를 a1, a2, b1, b2, b3으로 구별하면 5! = 120가지로 나열됩니다. 번호를 지우면 a끼리 자리를 바꾼 2!가지, b끼리 자리를 바꾼 3!가지가 모두 같은 배열이 됩니다. 한 배열이 2! × 3! = 12번씩 세어졌으므로 120 / 12 = 10가지입니다.

같은 답을 조합으로도 얻습니다. 다섯 자리 가운데 a가 들어갈 두 자리를 고르면 나머지는 b로 정해지므로 5C2 = 10입니다. 같은 것이 두 종류뿐이면 ‘자리 고르기’로 읽어도 됩니다.

BANANA의 여섯 글자는 A가 3개, N이 2개, B가 1개입니다. 나열하는 방법은 6! / (3! × 2! × 1!) = 720 / 12 = 60가지입니다. 두 N이 이웃하는 배열은 NN을 한 덩어리로 보아 B, A, A, A, (NN)의 다섯 개를 나열하므로 5! / 3! = 20가지입니다.

최단 경로

가로 4칸, 세로 3칸인 바둑판 모양 도로의 왼쪽 아래 A에서 오른쪽 위 B까지 최단 거리로 가려면 오른쪽으로 4번, 위로 3번 움직여야 합니다. 오른쪽을 →, 위쪽을 ↑로 적으면 → 4개와 ↑ 3개를 나열하는 것과 같습니다.

7! / (4! × 3!) = 35

A에서 오른쪽으로 2칸, 위로 1칸 떨어진 지점 P를 반드시 지나는 길은 A→P와 P→B를 따로 세어 곱합니다. A→P는 3! / (2! × 1!) = 3가지입니다. P→B는 남은 오른쪽 2칸, 위 2칸이므로 4! / (2! × 2!) = 6가지입니다. 합쳐 3 × 6 = 18가지입니다. P를 지나지 않는 길은 35 − 18 = 17가지입니다.

순서가 정해진 것은 같은 것으로 봅니다

a, b, c, d, e를 나열할 때 a가 b보다 앞에 오는 경우를 셉니다. a와 b가 들어갈 두 자리가 정해지면 앞자리에 a, 뒷자리에 b를 넣는 방법은 하나뿐입니다. 따라서 a, b를 같은 문자 ○, ○로 보고 ○, ○, c, d, e를 나열한 수 5! / 2! = 60과 같습니다. 전체 120가지의 절반이라는 사실과도 맞습니다.

함정: 같은 것이 있는데 n!로 세면 답이 몇 배로 커집니다. 반대로 ‘서로 다른 공’, ‘번호가 적힌 카드’처럼 구별되는 것을 같은 것으로 보고 나누어도 안 됩니다. 문제에서 ‘같은 종류’, ‘구별하지 않는’이라는 말을 먼저 찾습니다.

4. 중복조합

서로 다른 n개에서 중복을 허락하여 r개를 택하는 조합을 중복조합이라 하고, 그 수를 nHr로 적습니다. 순서는 구별하지 않고 ‘각각을 몇 개씩 택했는가’만 봅니다.

nHr = n+r−1Cr

이유는 칸막이입니다. 세 종류 a, b, c에서 5개를 택하는 한 방법, 예를 들어 a 2개·b 0개·c 3개를 ○○||○○○로 적습니다. ○는 택한 물건, |는 종류를 가르는 칸막이입니다. 종류가 3개이면 칸막이는 2개입니다. 택하는 방법 하나가 ○ 5개와 | 2개를 나열한 것 하나에 정확히 대응합니다. 같은 것이 있는 순열로 세면 7! / (5! × 2!) = 7C5 = 21가지입니다. 일반적으로 ○ r개와 칸막이 (n − 1)개를 나열하므로 n+r−1Cr입니다.

3H5 = 7C5 = 7C2 = 21

방정식의 정수해

방정식 x + y + z = 5를 만족하는 음이 아닌 정수 x, y, z의 순서쌍은, 세 문자 x, y, z에서 중복을 허락해 5개를 택하는 것과 같습니다. x를 택한 횟수가 x의 값입니다. 따라서 3H5 = 21개입니다.

양의 정수해는 각 문자에 1씩 먼저 나누어 줍니다. x = x′ + 1, y = y′ + 1, z = z′ + 1로 두면 x′ + y′ + z′ = 2이고 x′, y′, z′은 음이 아닌 정수입니다. 3H2 = 4C2 = 6개입니다. 직접 적어 보면 (3, 1, 1) 꼴 3개와 (2, 2, 1) 꼴 3개로 6개가 맞습니다.

‘x는 2 이상’ 같은 조건도 같은 방법입니다. x + y + z = 7에서 x ≥ 2이면 x = x′ + 2로 두어 x′ + y + z = 5가 되고, 다시 21개입니다.

같은 물건 나누어 담기, 크기 순서

같은 종류의 공 6개를 서로 다른 상자 3개에 넣는 방법은 상자 3개에서 중복을 허락해 6번 택하는 것이므로 3H6 = 8C6 = 8C2 = 28가지입니다. 빈 상자가 없게 하려면 상자마다 1개씩 먼저 넣고 남은 3개를 나누므로 3H3 = 5C3 = 10가지입니다.

1부터 5까지의 자연수에서 a ≤ b ≤ c를 만족하는 순서쌍 (a, b, c)는, 다섯 수에서 중복을 허락해 3개를 택한 뒤 작은 것부터 놓으면 하나로 정해집니다. 5H3 = 7C3 = 35개입니다. 등호가 없는 a < b < c이면 중복이 없으므로 5C3 = 10개입니다.

함정: nHr의 n과 r을 바꿔 넣는 실수가 많습니다. n은 ‘서로 다른 종류의 수’(상자, 문자, 사람)이고 r은 ‘택하는 횟수’(같은 공의 개수, 우변의 값)입니다. 3H5 = 7C5 = 21이고 5H3 = 7C3 = 35로 값이 다릅니다.

5. 이항정리와 파스칼의 삼각형

자연수 n에 대하여 (a + b)n을 전개하면 다음과 같습니다. 이것이 이항정리입니다.

(a + b)n = nC0 an + nC1 an−1b + … + nCr an−rbr + … + nCn bn

이유는 조합입니다. (a + b)n은 (a + b)를 n개 곱한 것이고, 전개식의 각 항은 n개의 괄호에서 a나 b를 하나씩 골라 곱한 것입니다. an−rbr은 n개의 괄호 가운데 b를 꺼낼 r개를 고를 때마다 하나씩 생기므로 모두 nCr개입니다. 이 nCr을 이항계수, nCr an−rbr을 일반항이라고 합니다.

(a + b)4 = a4 + 4a3b + 6a2b2 + 4ab3 + b4입니다. 계수 1, 4, 6, 4, 1이 4C0부터 4C4까지입니다.

특정한 항의 계수

계수 문제는 일반항을 쓰고 지수를 맞추는 한 가지 방법으로 풉니다. (x + 2)5의 일반항은 5Cr x5−r 2r입니다. x3의 계수는 r = 2일 때이므로 5C2 × 22 = 10 × 4 = 40입니다.

(2x − 1/x)6의 일반항은 6Cr (2x)6−r (−1/x)r = 6Cr × 26−r × (−1)r × x6−2r입니다. 상수항은 6 − 2r = 0, 곧 r = 3일 때이고 값은 20 × 8 × (−1) = −160입니다. x 앞의 수 2와 부호 −도 함께 거듭제곱된다는 점이 핵심입니다.

파스칼의 삼각형

이항계수를 n = 1, 2, 3, … 순서로 한 줄씩 늘어놓아 삼각형 모양으로 쌓은 것이 파스칼의 삼각형입니다.

n이항계수합
11   12
21   2   14
31   3   3   18
41   4   6   4   116
51   5   10   10   5   132

각 수는 바로 윗줄의 이웃한 두 수의 합이고, 줄마다 좌우 대칭입니다. 식으로는 다음과 같습니다.

nCr = n−1Cr−1 + n−1Cr
nCr = nCn−r

이유도 조합으로 읽습니다. n개에서 r개를 뽑을 때 특정한 하나를 포함하면 나머지 n − 1개에서 r − 1개를 뽑고, 포함하지 않으면 n − 1개에서 r개를 뽑습니다. 예를 들어 5C2 = 4C1 + 4C2 = 4 + 6 = 10입니다. 좌우 대칭인 것은 ‘뽑을 r개를 정하는 일’과 ‘남길 n − r개를 정하는 일’이 같기 때문입니다.

이항계수의 합

(1 + x)n = nC0 + nC1 x + nC2 x2 + … + nCn xn에 수를 대입하면 계수끼리의 관계가 나옵니다.

x = 1을 대입: nC0 + nC1 + nC2 + … + nCn = 2n
x = −1을 대입: nC0 − nC1 + nC2 − … + (−1)n nCn = 0

두 식을 더하고 빼면 nC0 + nC2 + nC4 + …와 nC1 + nC3 + nC5 + …가 각각 2n−1로 같습니다. n = 5에서 1 + 10 + 5 = 16, 5 + 10 + 1 = 16이고 전체는 32 = 25입니다. 2n은 원소가 n개인 집합의 부분집합의 개수와도 같습니다. 원소를 0개, 1개, …, n개 뽑는 방법을 모두 더한 것이기 때문입니다.

범위

이 과목의 이항정리는 항이 두 개인 식의 거듭제곱만 다룹니다. 항이 세 개 이상인 식의 전개 공식(다항정리)이나 허수단위가 들어간 전개는 다루지 않습니다.

6. 수능에서 묻는 방식

문항은 공식의 이름을 말해 주지 않습니다. 상황을 읽고 네 가지 세기 가운데 하나로 옮기는 것이 풀이의 대부분입니다. 아래 순서로 읽습니다.

  1. 대상이 서로 다른지 같은지 표시합니다. ‘같은 종류의 공’, ‘서로 다른 상자’처럼 문제에 적혀 있습니다.
  2. 순서를 구별하는지 봅니다. 나열·자리·함숫값은 순서가 있고, 묶음·선택·개수는 순서가 없습니다.
  3. 같은 것을 다시 고를 수 있는지 봅니다. 고를 수 있으면 중복순열이나 중복조합입니다.
  4. 조건을 처리합니다. ‘이웃한다’는 묶기, ‘적어도’는 전체에서 빼기, ‘1개 이상’은 먼저 나누어 주기, ‘순서가 정해졌다’는 같은 것으로 보기입니다.
  5. 수를 줄인 작은 예로 식을 검산합니다. 2~3개짜리로 직접 적어 보면 n과 r이 바뀐 것을 잡을 수 있습니다.

함수의 개수로 묻는 네 가지

X = {1, 2, 3}에서 Y = {1, 2, 3, 4}로 가는 함수 f를 조건별로 세면 네 공식이 한 번에 나옵니다.

조건세는 법개수
조건 없음함숫값을 중복을 허락해 나열4Π3 = 64
서로 다른 원소의 함숫값이 서로 다르다서로 다른 함숫값을 나열4P3 = 24
f(1) < f(2) < f(3)함숫값 3개를 고르면 순서는 하나4C3 = 4
f(1) ≤ f(2) ≤ f(3)중복을 허락해 3개를 고르면 순서는 하나4H3 = 6C3 = 20

조건이 섞이면 경우를 나눕니다. f(1) ≤ f(2) ≤ f(3)이면서 f(3) = 4인 함수는 f(1) ≤ f(2) ≤ 4만 남으므로 4H2 = 5C2 = 10개입니다. 나눈 경우끼리 겹치지 않는지, 빠진 경우가 없는지를 마지막에 확인합니다.

전개식 문제는 두 식의 곱으로도 나옵니다. (x + 1)(x + 2)4의 x2의 계수를 구할 때, 앞 괄호에서 x를 고르면 뒤에서 x의 계수가, 1을 고르면 뒤에서 x2의 계수가 필요합니다. (x + 2)4에서 x의 계수는 4C3 × 23 = 32, x2의 계수는 4C2 × 22 = 24이므로 답은 32 + 24 = 56입니다.

TIP: 세는 대상을 한 문장으로 바꿔 말해 봅니다. ‘공마다 상자를 고른다’, ‘상자를 다섯 번 택한다’, ‘→ 4개와 ↑ 3개를 나열한다’처럼 말이 정해지면 공식은 따라옵니다.

자주 나오는 함정

  • 함수의 개수에서 밑과 지수를 바꾸는 경우. 정의역의 원소가 고르는 쪽이므로 (공역의 크기)(정의역의 크기)입니다. 원소 3개에서 4개로 가는 함수는 43 = 64개입니다.
  • nHr의 n과 r을 바꾸는 경우. n은 서로 다른 종류의 수, r은 택하는 횟수입니다. 3H5 = 21, 5H3 = 35입니다.
  • 양의 정수해를 음이 아닌 정수해의 식으로 세는 경우. 양의 정수이면 1씩 먼저 나누어 주고 남은 수로 셉니다. x + y + z = 5는 음이 아닌 정수해 21개, 양의 정수해 6개입니다.
  • 같은 것이 있는데 n!로 세는 경우. 같은 것끼리 자리를 바꾼 수만큼 나눕니다. a, a, b, b, b는 120이 아니라 10가지입니다.
  • ‘서로 다른 공’과 ‘같은 공’을 구별하지 않는 경우. 상자 3개에 서로 다른 공 5개를 넣으면 35 = 243, 같은 공 5개를 넣으면 3H5 = 21입니다.
  • 맨 앞자리에 0을 넣어 세는 경우. 자연수를 만들 때는 맨 앞자리의 후보에서 0을 뺍니다.
  • 일반항에서 계수와 부호를 빠뜨리는 경우. (2x − 1/x)6의 일반항에는 26−r과 (−1)r이 함께 붙습니다.
  • ‘적어도’를 직접 세다가 겹치게 세는 경우. 전체에서 ‘하나도 없는 경우’를 빼는 쪽이 안전합니다.

대표 예제

눌러서 풀이를 펼치세요.

숫자 0, 1, 2, 3에서 중복을 허락하여 세 개를 택해 만든 세 자리 자연수 가운데 짝수의 개수를 구하시오.

자리마다 후보를 셉니다. 백의 자리는 0이 올 수 없으므로 1, 2, 3의 3가지입니다.

십의 자리는 조건이 없으므로 4가지입니다. 일의 자리는 짝수가 되도록 0 또는 2의 2가지입니다.

곱의 법칙으로 3 × 4 × 2 = 24개입니다. 중복이 허락되므로 앞자리에 쓴 숫자를 뒤에서 다시 써도 됩니다.

문자 a, a, b, b, c를 일렬로 나열할 때, 두 a가 서로 이웃하지 않는 경우의 수를 구하시오.

전체는 같은 것이 있는 순열로 5! / (2! × 2!) = 30가지입니다.

두 a가 이웃하는 경우는 (aa)를 한 덩어리로 보아 (aa), b, b, c를 나열하므로 4! / 2! = 12가지입니다.

따라서 30 − 12 = 18가지입니다.

검산: b, b, c를 먼저 나열하면 3! / 2! = 3가지이고, 그 사이와 양 끝의 네 자리 가운데 a가 들어갈 두 자리를 고르면 4C2 = 6가지입니다. 3 × 6 = 18로 같습니다.

방정식 x + y + z + w = 8을 만족하는 양의 정수 x, y, z, w의 순서쌍 (x, y, z, w)의 개수를 구하시오.

양의 정수이므로 네 문자에 1씩 먼저 나누어 줍니다. x = x′ + 1처럼 두면 x′ + y′ + z′ + w′ = 4이고 네 수는 음이 아닌 정수입니다.

네 문자에서 중복을 허락해 4개를 택하는 수이므로 4H4 = 7C4 = 7C3 = 35개입니다.

음이 아닌 정수해로 잘못 세면 4H8 = 11C8 = 165가 되어 크게 달라집니다.

(x + a/x)6의 전개식에서 x2의 계수가 60일 때, 양수 a의 값을 구하시오.

일반항은 6Cr x6−r (a/x)r = 6Cr ar x6−2r입니다.

x2의 항은 6 − 2r = 2에서 r = 2입니다. 계수는 6C2 a2 = 15a2입니다.

15a2 = 60에서 a2 = 4이고, a가 양수이므로 a = 2입니다.

한 줄

경우의 수는 “순서를 따지나, 또 뽑아도 되나”를 정하는 일입니다. 줄을 세우면 순열, 고르기만 하면 조합이고, 같은 것을 또 써도 되면 앞에 ‘중복’이 붙습니다.

  • 중복순열은 자리마다 n가지라서 n을 r번 곱합니다.
  • 같은 것이 있으면 다르다고 보고 센 뒤, 같은 것끼리 자리를 바꾼 수만큼 나눕니다.
  • 중복조합은 ○와 칸막이를 한 줄로 늘어놓는 수입니다.
  • 이항정리의 계수는 ‘괄호 n개 가운데 b를 꺼낼 r개를 고르는 수’입니다.
고급

풀이 순서는 (1) 대상이 서로 다른지 같은지 (2) 순서를 구별하는지 (3) 중복이 되는지를 정한 뒤 (4) 조건을 묶기·빼기·먼저 나누어 주기로 처리하고 (5) 작은 수로 검산하는 것입니다. 조건이 둘 이상이면 가장 제한이 강한 자리나 값부터 정하고, 경우를 나누었다면 서로 겹치지 않는지 확인합니다.

정수해 문제는 모든 조건을 ‘음이 아닌 정수’로 바꾸는 치환이 핵심입니다. x ≥ k이면 x = x′ + k로 두고 우변에서 k를 뺍니다. 전개식 문제는 일반항을 x의 거듭제곱 하나로 정리한 다음 지수의 방정식을 풉니다. 두 식의 곱이면 필요한 차수의 짝을 모두 찾아 더합니다.
