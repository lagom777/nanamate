수능 수학 실전 전략

Part 10 · 전략

시간 배분·풀이 순서·실수 방지·오답 관리

수능 수학은 100분, 30문항, 100점입니다. 공통 1~22번은 수학Ⅰ·수학Ⅱ이고, 선택 23~30번은 확률과 통계·미적분·기하 중 하나인데 이 노트는 미적분을 다룹니다. 앞의 쉬운 문항을 실수 없이 확보하고, 막힌 문항은 표시한 뒤 넘어가며, 마지막에는 단답형 자릿수와 계산의 부호를 다시 보는 운영이 점수를 지킵니다. 이 페이지는 공식집이 아니라 시험장에서 쓰는 순서와 점검 목록입니다.

1. 시험 구조와 점수 구조

시험 시간은 100분이고 문항은 30개이며 만점은 100점입니다. 각 문항의 배점은 2점, 3점, 4점 중 하나입니다. 문제지에 그 배점이 보이면, 그 숫자를 보고 이 문항에 계산을 얼마나 더 쓸지 정합니다.

구분번호답안범위
공통1~22번선다와 단답이 섞임수학Ⅰ·수학Ⅱ
선택23~30번선다와 단답이 섞임확률과 통계·미적분·기하 중 택1. 이 노트는 미적분
5지 선다1~15번, 23~28번다섯 보기 중 하나21문항
단답형16~22번, 29~30번OMR에 숫자9문항. 답은 0 이상 999 이하의 정수

공통 22문항은 선다 15개(1~15번)와 단답 7개(16~22번)입니다. 선택 8문항은 선다 6개(23~28번)와 단답 2개(29~30번)입니다. 15+7+6+2=30입니다. 단답 9개는 마지막에 자릿수를 한 번씩 더 볼 목록으로 쓰면 됩니다.

단답형 답 n : 정수이고 0 ≤ n ≤ 999

앞번호는 대체로 계산이 짧습니다. 여기서 틀리면 문항이 어려워서가 아니라 부호나 조건을 놓쳐서 점수가 빠지는 일이 많습니다. 공통 13~15번, 20~22번, 선택 27~30번은 대체로 어렵고 4점이 많습니다. 이 구간이 맞는 사람과 틀린 사람을 가릅니다. 앞의 2점·3점은 확보하는 점수이고, 뒤의 4점은 변별 점수입니다.

배점만 놓고 보면 2점 하나와 3점 하나를 계산 실수로 잃으면 5점이고, 4점 하나를 못 풀면 4점입니다. 5가 4보다 큽니다. 맞힐 수 있던 문항 둘의 실수가, 어려운 4점 하나를 비운 것보다 클 수 있습니다. 시험 운영의 첫 목표는 변별 문항을 모두 맞히는 일이 아닙니다. 맞힐 수 있는 문항을 답안지에 실수 없이 남기는 일입니다. 시간이 모자라면 손대지 못한 4점보다, 이미 푼 2점·3점의 부호와 단답 자릿수를 먼저 봅니다.

단답 범위 밖은 신호입니다

음수, 분수, 1000 이상의 수는 단답란에 적을 수 없습니다. 그 수가 나오면 반올림하거나 부호를 지우지 않습니다. 문제가 기약분수 a/b의 a+b를 물었는지, 절댓값을 물었는지, 경우를 하나 빠뜨렸는지를 다시 읽습니다.

2. 시간 배분의 예시 틀

100분을 네 덩어리로 나누는 틀입니다. 각 덩어리를 몇 분으로 고정하지 않습니다. 사람마다 계산 속도와 실수 위치가 다르므로, 모의평가를 푼 뒤에 자신의 기록으로만 길이를 옮깁니다. 남의 시각표를 그대로 가져오지 않습니다.

덩어리주로 보는 문항시간 감각 (예시)하는 일
첫째공통 선다 앞쪽. 대체로 계산이 짧은 번호네 덩어리 중 가장 짧게. 계산은 서두르되 부호는 멈춤점수 확보. 선다를 답안지에 옮긴 뒤 번호를 대조
둘째공통에서 아직 풀리는 문항, 선택 23~26번 근처중간단답은 답이 나오는 즉시 표기
셋째공통 20~22번, 선택 27~30번가장 길게변별 구간. 막히면 표시하고 다음으로
넷째표시해 둔 문항, 단답 9개끝에 반드시 한 덩어리새 고난도를 시작하지 않음. 자릿수·부호·조건

공통은 22문항, 선택은 8문항입니다. 개수만 보면 선택 몫은 8/30입니다. 다만 27~30번은 시간이 긴 편이므로, 선택 시간을 그 비율만큼으로만 짧게 끊지는 않습니다. 공통이 빨리 끝나면 남은 시간을 셋째 덩어리로 보냅니다. 앞부분에서 부호 실수가 잦으면 넷째 덩어리를 더 남깁니다. 이 이동이 조정입니다.

함정: 시계의 어떤 분까지 한 덩어리를 끝내겠다고 못 박아 두고, 그 시각이 되면 거의 다 푼 계산까지 버리는 운영은 이 틀이 아닙니다. 경계는 문항 번호로 두고, 걸린 시간은 시험이 끝난 뒤에 적어 다음 모의평가에서만 바꿉니다.
TIP: 문제지를 받으면 15번, 22번, 28번 옆에 덩어리 경계만 작게 표시해 둘 수 있습니다. 분 숫자는 적지 않습니다. 풀이는 문제지에 하고, 답안지에는 검은색 컴퓨터용 사인펜으로 최종 답만 표기합니다.

첫째 덩어리를 건너뛰고 30번부터 여는 순서는 이 틀과 다릅니다. 앞의 쉬운 점수를 나중에 몰아서 쓰면, 마킹이 밀리거나 넷째 덩어리가 사라지기 쉽습니다. 1번부터 들어가되, 셋째 덩어리 한 문항에서 손이 멈추면 그 문항만 표시하고 선택 앞번호의 점수를 먼저 챙긴 뒤 돌아옵니다.

3. 풀이 순서

순서는 한 줄로 고정합니다. 쉬운 문항으로 점수를 확보하고, 막힌 문항은 표시한 뒤 넘어가며, 끝 덩어리에서 검산합니다.

  1. 1번부터 차례로 봅니다. 앞번호를 건너뛰고 4점이 많은 뒷번호부터 열지 않습니다. 선택도 23번부터 차례입니다. 30번부터 풀지 않습니다.
  2. 손이 멈추면 표시하고 다음 문항으로 갑니다. 같은 식을 반복해서 고치고 있거나, 조건을 읽어도 실마리가 없으면 그 번호에 표시를 남깁니다. 그 문항에 머무는 동안 뒤의 2점·3점은 비어 있습니다.
  3. 공통 20~22번에서 오래 멈추면 선택 23번을 엽니다. 23~26번 근처는 27~30번보다 수월한 편이 많으므로 그 점수를 먼저 답안지에 남기고, 표시해 둔 공통 문항으로 돌아옵니다.
  4. 단답은 구한 즉시 표기합니다. 16~22번과 29~30번을 문제지에만 적어 두고 종료 직전에 한꺼번에 옮기면 자릿수가 밀립니다.
  5. 넷째 덩어리의 순서를 지킵니다. 단답 9개의 자릿수, 계산만 남은 표시, 앞부분의 부호와 부등호, 그다음에야 실마리가 없었던 문항입니다.
표시뜻돌아올 때
점 하나식은 세웠고 계산만 꼬임넷째 덩어리의 앞쪽. 식을 지우지 말고 부호부터 다시 봄
물음표실마리가 안 보임자릿수와 쉬운 문항 점검이 끝난 뒤에만. 시간이 없으면 비워 둠

선다 답을 답안지에 옮길 때 한 칸만 밀려도 그 아래 번호가 같이 밀립니다. 여러 문항을 넘길 때마다 문제 번호와 답안 번호가 같은지 봅니다. 단답은 백의 자리·십의 자리·일의 자리가 한 세트이므로, 옆 문항의 자리로 넘어가지 않았는지도 같이 봅니다.

넷째 덩어리에서 하지 않는 일

손대지 못한 30번을 처음부터 새로 설계하지 않습니다. 이미 구한 답의 자릿수, 등호, 진수 조건이 먼저입니다. 종료령이 나면 답안 작성을 멈춥니다. 그래서 넷째 덩어리는 종료령 전에 끝냅니다.

검산은 처음부터 30문항을 다시 푸는 일이 아닙니다. 배점이 낮은 문항일수록 실수가 아깝다는 점 때문에, 앞번호의 부호·부등호와 단답 9개를 변별 문항보다 먼저 봅니다. 물음표 문항은 그 점검이 끝난 시간에만 엽니다.

4. 계산 실수 체크리스트

답을 답안지에 옮기기 전에 아래 다섯 줄을 순서대로 묻습니다. 해당이 없는 줄은 넘어갑니다. 다섯 줄을 매번 길게 쓰지 않아도 되고, 오답 노트에서 반복된 줄만 시험 전에 따로 표시해 둡니다.

점검물을 것자주 어긋나는 장면
부호이항, 제곱, 절댓값 구간, 정적분의 부호가 맞는가(−a)²과 −a²을 같게 둠. 축 아래 정적분을 넓이로 그대로 씀
부등호 방향음수를 곱·나눌 때, 로그의 밑이 0과 1 사이일 때 방향이 바뀌었는가밑이 1/2인데 부등호를 그대로 둠
진수·정의역로그의 진수가 양수인가, 밑은 양수이고 1이 아닌가, 분모와 근호는 되는가해를 구한 뒤 진수 조건을 안 교집합함
구간 끝점등호가 포함되는가, 열린 끝의 함숫값이 존재하는가최댓값을 구간에 없는 끝값으로 씀
단위각이 도인지 라디안인지, 정적분인지 넓이인지, 단답이 값인지 a+b인지30°를 30으로 미분. 기약분수가 아닌 채로 a+b를 구함

부호

(−3)² = 9이고, −3² = −(3²) = −9입니다. 괄호가 없으면 제곱이 먼저입니다. 식을 이항할 때는 옮기는 항의 부호를 바꿉니다. 절댓값은 식이 0이 되는 지점으로 구간을 나눈 뒤에, 구간마다 부호를 정합니다.

정적분 값과 넓이는 다릅니다. y = x − 1을 0부터 2까지 적분하면

∫02 (x − 1) dx = [(1/2)x² − x]02 = (2 − 2) − 0 = 0

그래프와 x축 사이의 넓이는 0부터 1까지, 1부터 2까지를 각각 절댓값으로 적분한 합입니다.

∫01 (1 − x) dx = [x − (1/2)x²]01 = 1 − 1/2 = 1/2
∫12 (x − 1) dx = [(1/2)x² − x]12 = 0 − (1/2 − 1) = 1/2
넓이 = 1/2 + 1/2 = 1

1/2 − 1 = −1/2이고, 0에서 이 값을 빼면 1/2입니다. 정적분 0을 넓이로 제출하면 틀린 답이 됩니다. 발문에 넓이, 거리, 속력처럼 음이 아닌 양이 적혀 있으면 부호를 한 번 더 봅니다.

부등호 방향과 진수

밑 a > 1이면 로그 부등식의 방향은 유지
0 < a < 1이면 방향은 반전
어느 쪽이든 진수 > 0, 밑은 양수이고 1이 아님

양변에 음수를 곱하거나 나누면 부등호가 반대로 갑니다. 양변이 0 이상일 때만 제곱해도 방향이 유지됩니다. 한쪽이 음수일 수 있으면 제곱하기 전에 경우를 나눕니다. 로그는 방향보다 먼저 진수 조건으로 범위를 잘라 두고, 구한 해와 그 범위를 교집합합니다.

구간 끝점

|x − 2| ≥ 1은 x − 2 ≥ 1 또는 x − 2 ≤ −1이므로 x ≥ 3 또는 x ≤ 1입니다. 등호가 있으므로 끝 x = 1, x = 3을 대입합니다. |1 − 2| = 1, |3 − 2| = 1이라 둘 다 참입니다. x = 2는 |0| = 0이라 거짓이고 범위 밖입니다. 열린 끝은 다릅니다. f(x) = x를 [0, 3)에서 보면 함숫값은 3에 한없이 가까워지지만 x = 3이 구간에 없으므로 최댓값이 없습니다. 최솟값은 f(0) = 0입니다.

단위

미분·적분에서 각의 단위는 라디안입니다. 180° = π이므로 30° = π/6, 45° = π/4, 60° = π/3, 90° = π/2입니다. 도 그대로 30을 넣어 삼각함수를 미분하지 않습니다. 단답이 기약분수 a/b에 대해 a+b를 물으면 먼저 약분합니다. 2/4는 1/2이므로 a + b = 1 + 2 = 3입니다. 약분 전 2 + 4 = 6은 다른 수입니다.

TIP: 다섯 줄 가운데 자신이 오답 노트에 두 번 이상 적은 줄만, 답안지에 옮기기 직전의 질문으로 남깁니다. 다섯 줄을 모든 문항에 길게 쓰면 넷째 덩어리가 없어집니다.

5. 어려운 문항 접근과 단답형 표기

변별 문항 네 가지

공통 13~15번, 20~22번, 선택 27~30번처럼 조건이 긴 문항은 계산을 시작하기 전에 접근을 하나 고릅니다. 네 가지는 서로 대체되는 공식이 아니라, 앞의 것이 막히면 다음을 꺼내는 순서입니다.

순서접근하는 일
1조건 표문장마다 한 칸. 확정된 값부터 채우고 빈칸은 남김
2그래프축이 무엇인지 먼저 읽고, 교점·극값·끝점을 스케치
3경우 나누기절댓값, 경계의 등호, 정수 조건, 도형의 위치로 경우를 적음
4특수한 값x = 0, x = 1 또는 쉬운 상수로 식을 검산하거나 선다 보기를 지움

조건 표의 예입니다. 이차함수 f가 f(0) = 1, f′(1) = 0, f(1) = 3을 만족할 때 f(2)를 구합니다. f(x) = ax² + bx + c로 두면 표는 세 칸입니다.

조건식
f(0) = 1c = 1
f′(1) = 0f′(x) = 2ax + b이므로 2a + b = 0
f(1) = 3a + b + c = 3. c = 1이므로 a + b = 2

(2a + b) − (a + b) = 0 − 2 = −2이므로 a = −2입니다. a + b = 2에서 b = 4입니다. f(x) = −2x² + 4x + 1이고 f(2) = −8 + 8 + 1 = 1입니다. 그래프로 검산하면 a = −2 < 0이므로 위로 볼록하고, 꼭짓점의 x좌표는 −b/(2a) = −4/(−4) = 1, 함숫값은 3입니다. 조건 f(1) = 3과 같습니다. 축이 x이고 세로는 f(x)입니다. 꼭짓점과 한 점 (2, 1)만 있어도 개형이 맞는지 보입니다.

경우는 빠짐없이 적은 뒤, 각 경우의 답을 조건에 넣어 지웁니다. 경계가 두 경우에 모두 들어가면 개수를 셀 때 한 번만 셉니다. 특수한 값은 오답을 지우거나 전개가 맞는지 확인할 때 씁니다. x = 1에서 성립해도 모든 실수 x에서 성립하는 것은 아닙니다. 명제를 버리려면 반례 하나면 되고, 명제를 받아들이려면 일반 계산이 필요합니다.

함정: 특수한 값으로 선다 보기를 지운 뒤, 남은 보기가 둘 이상이면 그 값만으로 답을 고르지 않습니다. 남은 보기를 가르는 조건으로 돌아갑니다.

답이 나온 뒤

수가 하나 나왔다고 표기하지 않습니다. 아래를 통과한 뒤에 답안지로 갑니다.

  1. 로그의 진수, 분모, 근호, 문제의 범위 안에 들어가는가.
  2. 등호를 포함한 끝값을 대입하면 참인가. 열린 끝은 빠져 있는가.
  3. 경우가 여러 개면, 문제가 물은 것이 한 경우인지 합인지 개수인지.
  4. 선다이면 그 값이 보기 중 하나와 맞는가. 둘과 맞으면 계산을 의심합니다.
  5. 단답이면 0 이상 999 이하의 정수인가. 분수라면 약분한 a+b인가.

단답형 OMR

단답은 십진법으로, 백의 자리·십의 자리·일의 자리에 맞추어 표기합니다. 답안지는 검은색 컴퓨터용 사인펜으로만 작성합니다. 감독관이 지급하고, 개인이 지참한 검은색 컴퓨터용 사인펜도 쓸 수 있습니다. 연필이나 샤프로 답안지에 예비 표시를 남기면 중복 답안으로 읽혀 불이익이 생길 수 있습니다. 예비 표시는 문제지에만 합니다.

한 문항에 답을 두 곳 이상 표기하거나 불완전하게 표기해 판독되지 않으면 그 문항은 0점입니다. 고칠 때는 흰색 수정테이프만 사용합니다. 수정액이나 스티커는 쓰지 않습니다. 테이프는 감독관에게 요청해 받을 수 있고, 떨어진 테이프나 남은 흔적의 책임은 수험생에게 있습니다. 답안지를 바꾸는 것도 희망하면 가능합니다.

과목 순서

학습 순서는 수학Ⅱ → 수학Ⅰ → 미적분입니다. 수학Ⅱ는 함수의 극한과 연속, 미분, 적분의 순서로 읽습니다. 미분계수의 정의가 극한이고, 정적분은 그 미분과 이어지기 때문입니다. 이 셋이 공통 해석 문항의 뼈대입니다.

수학Ⅰ은 지수와 로그를 먼저 둡니다. 삼각함수와 수열은 서로 순서를 바꿔도 됩니다. 둘 다 미적분으로 넘어가기 전에 끝냅니다. 미적분은 수열의 극한, 여러 가지 미분법, 여러 가지 적분법의 순서입니다. 미분법에 지수함수·삼각함수 미분이 나오고, 적분법은 그 미분을 되돌립니다. 미적분을 수학Ⅱ보다 먼저 열면 밑의 문장이 비어 있습니다.

기출 회독

회독은 두 가지로 나눕니다. 실전 회독은 한 회차 30문항을 100분에 푸는 일입니다. 이때 표시하고 넘어가는 규칙과 네 덩어리를 시험과 같이 씁니다. 오답 회독은 틀린 문항과 물음표를 남긴 문항만 다시 푸는 일입니다. 맞은 문항을 매번 처음부터 다시 푸는 데 시간을 다 쓰지 않습니다.

  1. 처음에는 수학Ⅱ 파트 기출, 이어서 수학Ⅰ, 그다음 미적분 순으로 문항을 고릅니다. 과목 순서를 회독에서도 유지합니다.
  2. 막히면 해설을 바로 베끼지 않습니다. 조건 표의 어느 칸에서 멈췄는지만 표시합니다.
  3. 해설을 읽은 뒤에는 덮고, 백지에 조건을 다시 적어 답을 처음부터 구합니다. 손이 따라가지 않으면 그 파트 노트로 돌아갑니다.
  4. 같은 실수가 두 번 나오면 체크리스트의 해당 줄에 표시해 직전 점검으로 올립니다.
함정: 해설의 마지막 줄만 따라 쓰고 회독했다고 세지 않습니다. 덮은 뒤 첫 줄부터 다시 구해서 같은 정수에 도착해야 그 문항은 넘어갑니다.

  • 막힌 문항을 맞힐 때까지 머문다 같은 계산이 반복되면 점 또는 물음표를 남기고 다음 번호로 갑니다. 그 시간에 뒤의 쉬운 점수가 비어 있습니다.
  • 검산 때 못 푼 최고난도만 다시 연다 넷째 덩어리는 단답 자릿수와 이미 푼 문항의 부호가 먼저입니다.
  • 40을 십의 자리 4만 표기한다 일의 자리 0을 함께 표기합니다. 4를 백의 자리에 쓰는 것도 자릿수가 틀린 표기입니다. 102는 십의 자리 0을 비우면 오답입니다.

  • 밑이 1/2인 로그 부등식에서 방향을 유지한다 밑이 0과 1 사이면 부등호가 반대입니다. 진수가 양수인지는 그 전에 확인합니다.
  • 열린 구간의 끝값을 최댓값으로 적는다 구간에 포함되지 않은 끝은 함숫값이 없습니다. 등호가 있는 부등식만 경계값을 답에 넣습니다.
  • 음수나 분수가 나오면 부호를 지우거나 반올림해 단답란에 적는다 0 이상 999 이하의 정수가 아니면 표기하지 않고, 문제가 물은 식과 조건을 다시 봅니다.

대표 예제

눌러서 풀이를 펼치세요.

2점 하나와 3점 하나를 실수로 틀리고 4점 하나를 맞힌 경우와, 2점·3점을 맞히고 4점을 틀린 경우를 비교하시오. 이어서 14번 계산이 반복해서 꼬이고 선택 27번은 아직 보지 않았다면 순서를 어떻게 바꾸는지 적으시오.

점수. 2 + 3 = 5이므로 쉬운 문항 둘을 잃으면 5점입니다. 4점 하나를 못 풀면 4점입니다. 5 − 4 = 1이라, 나머지 문항이 같으면 쉬운 둘을 지킨 쪽이 1점 높습니다. 변별 문항 하나를 맞히려고 앞의 계산을 서두르다 틀리는 쪽이 손해입니다.

순서. 14번에 점 표시를 하고 식을 지우지 않은 채 15번으로 갑니다. 14번이 4점이어도, 같은 계산이 반복 중이면 머무르지 않습니다.

16번부터의 단답 가운데 풀리는 것은 답을 구하는 즉시 자릿수를 표기합니다. 20~22번에서 실마리가 없으면 물음표만 남기고 선택 23번을 엽니다. 23~26번 근처의 선다를 먼저 확보한 뒤, 점이 남은 14번의 부호부터 돌아봅니다.

남은 시간이 넷째 덩어리에 들어가면 27번을 새로 설계하지 않습니다. 단답 자릿수와 14번의 계산이 먼저이고, 그다음에 시간이 남을 때만 27번을 엽니다.

log1/2(x − 1) > 1 을 풀고, 체크리스트의 어느 줄을 어느 단계에서 봤는지 적으시오.

1. 진수. x − 1 > 0이므로 x > 1입니다. 밑 1/2는 양수이고 1이 아니므로 로그가 정의되는 밑입니다.

2. 방향. 0 < 1/2 < 1이므로 지수로 올릴 때 부등호가 반대로 갑니다. x − 1 < (1/2)1 = 1/2입니다.

3. 범위. x < 1 + 1/2 = 3/2입니다. 진수 조건과의 교집합은 1 < x < 3/2입니다. 끝 x = 1은 진수가 0이라 빠지고, x = 3/2는 로그 값이 1이라 엄격한 부등호에서 빠집니다.

4. 대입 검산. x = 5/4이면 x − 1 = 1/4 = (1/2)2이므로 로그 값은 2이고 2 > 1입니다. 1 < 5/4 < 3/2도 맞습니다. x = 2이면 진수가 1이고 로그 값은 0이라 2는 해가 아닙니다. 방향을 반대로 하지 않으면 x > 3/2가 되어 x = 2를 해로 넣게 됩니다.

방정식 |x − 1| + |x − a| = 3 의 실근이 정확히 2개일 때 a의 범위를 구하시오. 조건 표, 경우, 특수한 값으로 검산하시오.

두 점 1과 a 사이의 거리 |a − 1|이 가운데 구간에서 거리의 합과 같습니다. 합이 3보다 크면 근이 없고, 3과 같으면 그 선분 전체가 근이라 2개를 넘으며, 3보다 작으면 바깥쪽에 근이 하나씩입니다.

a ≥ 1일 때. 가운데 1 ≤ x ≤ a에서 합은 a − 1입니다.

  • a − 1 > 3, 즉 a > 4이면 근이 없습니다.
  • a = 4이면 [1, 4] 전체가 근이라 정확히 2개가 아닙니다.
  • 1 ≤ a < 4이면 왼쪽 근 x = (a − 2)/2가 1보다 작고, 오른쪽 근 x = (a + 4)/2가 a보다 큽니다. 근은 2개입니다. a < 4일 때 (a − 2)/2 < 1이고 (a + 4)/2 > a인 것은 각각 a − 2 < 2, a + 4 > 2a로 확인됩니다.

a < 1일 때. 가운데 합은 1 − a입니다. a < −2이면 근이 없고, a = −2이면 선분 전체이며, −2 < a < 1이면 근이 2개입니다.

합치면 −2 < a < 4입니다.

특수한 값. a = 1이면 x = −1/2, 5/2이고 2|x − 1| = 3이라 근이 2개입니다. 범위 안입니다. a = 0이면 x = −1, 2입니다. |−1 − 1| + |−1| = 3, |2 − 1| + |2| = 3이라 근이 2개입니다. a = 4이면 x = 1, 2, 4만 봐도 |2 − 1| + |2 − 4| = 3이고 사이 점이 더 있어 2개를 넘습니다. a = 5이면 거리의 최솟값이 4 > 3이라 근이 없습니다.

f(x) = x³ − 3x 의 닫힌 구간 [0, 3]에서 최댓값과 최솟값의 합을 단답으로 낸다면, 계산과 OMR 표기를 적으시오.

1. 도함수. f′(x) = 3x² − 3 = 3(x² − 1) = 3(x − 1)(x + 1)입니다. f′(x) = 0인 점은 x = 1, x = −1이고, [0, 3] 안은 x = 1뿐입니다.

2. 끝점과 임계점. f(0) = 0, f(1) = 1 − 3 = −2, f(3) = 27 − 9 = 18입니다. 최댓값은 18, 최솟값은 −2, 합은 18 + (−2) = 16입니다.

끝만 보면 f(0) = 0과 f(3) = 18이라 최솟값을 0으로 두고 합을 18로 잘못 낼 수 있습니다. x = 1의 함숫값 −2가 끝값보다 작습니다.

3. 표기. 16은 두 자릿수입니다. 백의 자리는 비우고 십의 자리 1, 일의 자리 6을 표기합니다. 1을 백의 자리에, 6을 십의 자리에 쓰면 160으로 읽힙니다. 한 자릿수 8에만 08도 인정되는 예외가 있고, 16에는 그 예외를 쓰지 않습니다.

한 줄

쉬운 점수를 먼저 맞히고, 막히면 표시한 뒤 넘어가며, 끝에는 단답 자릿수와 부호를 다시 봅니다.

  • 100분, 30문항, 100점. 공통 1~22번, 선택 미적분 23~30번.
  • 2점과 3점을 하나씩 잃으면 5점이고, 4점 하나를 못 풀면 4점입니다.
  • 단답은 0부터 999까지의 정수입니다. 40은 십의 자리 4와 일의 자리 0입니다.
  • 학습은 수학Ⅱ, 수학Ⅰ, 미적분 순서입니다.
고급

넷째 덩어리는 단답 9개의 자릿수, 계산만 남은 표시, 앞부분의 부호와 부등호, 그다음 실마리가 없었던 문항 순입니다. 변별 문항은 조건을 표로 옮기고, 축부터 그래프를 스케치한 뒤, 경우를 나누고, 특수한 값으로는 식만 검산합니다. 한 값에서 맞았다고 그 식이 모든 실수에서 참은 아닙니다.

과목은 수학Ⅱ의 극한·미분·적분 다음에 수학Ⅰ, 그다음에 미적분의 수열의 극한·미분법·적분법입니다. 기출은 실전 회독과 오답 회독을 나누고, 노트에는 정답 번호 대신 실수의 종류와 다음에 물을 한 줄을 남깁니다.
