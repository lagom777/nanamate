왜 사슬

다음 단계를 먼저 머릿속으로 떠올린 뒤, 가려진 단계를 눌러 맞았는지 확인하세요.

  1. 100분 · 30문항 · 100점, 배점은 2·3·4점 → 2점·3점 하나씩을 실수로 잃으면 5점, 4점 하나를 못 풀면 4점이라 확보 점수가 먼저다
  2. 그래서 1번부터 차례로 풀고 손이 멈추면 표시하고 넘어간다(점 하나 = 계산만 꼬임, 물음표 = 실마리 없음)
  3. 변별 문항은 접근 하나를 골라 시작한다 → 조건 표 → 그래프 → 경우 나누기 → 특수한 값 순서로 꺼낸다
  4. 답이 나와도 바로 옮기지 않는다 → 진수·정의역, 등호와 끝점, 단답은 문제가 물은 꼴의 수인지 확인한다
  5. 시험 뒤 오답은 ‘계산 / 조건 / 경우 / 개념 / 시간’으로 나눈다 → 두 번 나온 실수만 체크리스트에 올려 시험 직전에 본다

시험 구조 — 왜 쉬운 점수를 먼저 지키나

수능 수학은 100분, 30문항, 100점이고 대수·미적분Ⅰ·확률과 통계가 과목별로 묶이지 않고 섞여 나옵니다. 예시문항 기준으로 선다 21문항(1~21번)과 단답 9문항(22~30번)이며, 단답 정답은 모두 자연수였으므로 음수나 분수가 나오면 옮기지 말고 조건을 다시 읽습니다.

2점 하나와 3점 하나를 실수로 잃으면 5점, 어려운 4점 하나를 못 풀면 4점이라 맞힐 수 있던 문항 둘의 실수가 더 큰 손해입니다. 그래서 시험 운영의 첫 목표는 변별 문항을 다 푸는 것이 아니라, 맞힐 수 있는 문항을 실수 없이 답안지에 남기는 것입니다. 예시문항 기준으로 4점 문항은 선다 14~21번과 단답 26~30번입니다.

시간 배분과 풀이 순서 — 경계는 분이 아니라 번호

100분을 예시문항 배점 기준으로 확보(1~13번) → 중간(14~21번에서 풀리는 문항과 22~25번) → 변별(14~21번에 남긴 표시와 26~30번) → 점검의 네 덩어리로 나누고, 경계는 시각이 아니라 문항 번호로 둡니다. 덩어리 길이는 남의 시간표가 아니라 자신의 모의평가 기록으로만 조정합니다. 1번부터 차례로 풀고, 같은 식을 반복해 고치거나 실마리가 없으면 표시만 하고 넘어갑니다.

표시는 두 가지입니다. 점 하나는 식은 세웠고 계산만 꼬인 문항, 물음표는 실마리가 안 보이는 문항이라 점은 넷째 덩어리 앞쪽에서, 물음표는 점검이 끝난 뒤에만 엽니다. 4점 선다(예시문항 기준 14~21번)에서 오래 멈추면 22번으로 가서 3점 단답을 먼저 챙기고, 단답은 구하는 즉시 답안지에 옮겨 번호가 밀리지 않게 합니다.

계산 실수 체크리스트 — 다섯 줄

답을 옮기기 전에 부호, 부등호 방향, 진수·정의역, 구간 끝점, 단위의 다섯 줄을 묻습니다. (−3)² = 9와 −3² = −9를 구별하고, 밑이 0과 1 사이인 로그 부등식은 방향을 바꾸며, 진수 조건과 구한 해를 교집합합니다. 각은 라디안이고, 기약분수 a/b의 a + b를 물으면 먼저 약분합니다.

정적분과 넓이의 구별이 대표적입니다. ∫02 (x − 1) dx = 0이지만 x축과의 넓이는 1/2 + 1/2 = 1이라, 발문에 넓이·거리·속력이 있으면 부호를 한 번 더 봅니다. 다섯 줄을 매번 길게 쓰지 말고, 오답 노트에 두 번 이상 나온 줄만 답을 옮기기 직전의 질문으로 남깁니다.

어려운 문항과 단답 표기

조건이 긴 문항은 조건 표 → 그래프 → 경우 나누기 → 특수한 값의 순서로, 앞의 것이 막히면 다음을 꺼냅니다. 특수한 값은 반례로 보기를 지우거나 검산할 때만 쓰는데, 한 값에서 성립해도 모든 값에서 성립하는 것은 아니기 때문입니다. 답이 나오면 범위, 끝값, 물은 것(한 경우인지 합인지 개수인지), 보기와의 일치를 확인한 뒤 옮깁니다.

단답은 답이 나오는 즉시 번호·수·물은 것 세 가지를 대조해 옮깁니다. 수를 적는 방법은 시험 당일 문제지·답안지 안내를 따릅니다.

학습 순서와 오답 노트 — 논리의 아래층부터

학습 순서는 미적분Ⅰ → 대수 → 확률과 통계입니다. 미분계수의 정의가 극한이고 정적분은 미분을 거꾸로 이은 것이라 미적분Ⅰ은 세 파트가 한 줄로 이어지며, 확률과 통계도 경우의 수로 확률을 계산하고 그 확률 위에 확률분포를 세우기 때문입니다. 아래층이 비어 있으면 위층의 이유가 보이지 않습니다.

기출은 한 회차를 100분에 푸는 실전 회독과, 틀리거나 물음표를 남긴 문항만 다시 푸는 오답 회독으로 나눕니다. 오답 노트에는 정답 대신 위치, 종류(계산·조건·경우·개념·시간), 다음에 그 자리에서 물을 한 줄, 다시 풀기 날짜를 적고, 해설을 덮고 첫 줄부터 다시 풀어 같은 답에 도착해야 넘어갑니다. 시험 전날에는 새 고난도 문항 대신 체크리스트와 단답 옮기기 순서만 확인합니다.

외울 것은 이것뿐시험 구조(예시문항 기준 선다 1~21번, 단답 22~30번), 단답 대조 세 줄(번호, 수, 물은 것), 계산 실수 체크리스트 다섯 줄(부호, 부등호 방향, 진수·정의역, 구간 끝점, 단위)

나머지는 유도덩어리 경계와 시간 배분(내 모의평가 기록에서), 표시한 문항을 다시 여는 순서, 오답 종류별 처방

논리형 함정앞번호 개념 문항에서도 원리를 끝까지 확인하려다 시간을 씁니다. 시험장에서는 이미 세운 사슬을 적용만 하고, 확인하고 싶은 의문은 문제지 여백에 적어 두었다가 시험이 끝난 뒤에 풀어 보세요.

문제부터 부딪치고 싶다면 대표 예제를 먼저 풀고, 막힌 고리만 사슬에서 찾아 채우세요.

부호

(−3)² = 9이고, −3² = −(3²) = −9입니다. 괄호가 없으면 제곱이 먼저입니다. 식을 이항할 때는 옮기는 항의 부호를 바꿉니다. 절댓값은 식이 0이 되는 지점으로 구간을 나눈 뒤에, 구간마다 부호를 정합니다.

정적분 값과 넓이는 다릅니다. y = x − 1을 0부터 2까지 적분하면

∫02 (x − 1) dx = [(1/2)x² − x]02 = (2 − 2) − 0 = 0

그래프와 x축 사이의 넓이는 0부터 1까지, 1부터 2까지를 각각 절댓값으로 적분한 합입니다.

∫01 (1 − x) dx = [x − (1/2)x²]01 = 1 − 1/2 = 1/2
∫12 (x − 1) dx = [(1/2)x² − x]12 = 0 − (1/2 − 1) = 1/2
넓이 = 1/2 + 1/2 = 1

1/2 − 1 = −1/2이고, 0에서 이 값을 빼면 1/2입니다. 정적분 0을 넓이로 제출하면 틀린 답이 됩니다. 발문에 넓이, 거리, 속력처럼 음이 아닌 양이 적혀 있으면 부호를 한 번 더 봅니다.

밑 a > 1이면 로그 부등식의 방향은 유지
0 < a < 1이면 방향은 반전
어느 쪽이든 진수 > 0, 밑은 양수이고 1이 아님

양변에 음수를 곱하거나 나누면 부등호가 반대로 갑니다. 양변이 0 이상일 때만 제곱해도 방향이 유지됩니다. 한쪽이 음수일 수 있으면 제곱하기 전에 경우를 나눕니다. 로그는 방향보다 먼저 진수 조건으로 범위를 잘라 두고, 구한 해와 그 범위를 교집합합니다.

구간 끝점

|x − 2| ≥ 1은 x − 2 ≥ 1 또는 x − 2 ≤ −1이므로 x ≥ 3 또는 x ≤ 1입니다. 등호가 있으므로 끝 x = 1, x = 3을 대입합니다. |1 − 2| = 1, |3 − 2| = 1이라 둘 다 참입니다. x = 2는 |0| = 0이라 거짓이고 범위 밖입니다. 열린 끝은 다릅니다. f(x) = x를 [0, 3)에서 보면 함숫값은 3에 한없이 가까워지지만 x = 3이 구간에 없으므로 최댓값이 없습니다. 최솟값은 f(0) = 0입니다.

확률에서도 끝점을 봅니다. 동전을 3번 던져 앞면이 나온 횟수를 X라 하면 X가 0, 1, 2, 3일 확률은 차례로 1/8, 3/8, 3/8, 1/8입니다. X가 2 이상일 확률은 3/8 + 1/8 = 1/2이고, 2 초과일 확률은 1/8입니다. 이상과 초과를 바꿔 읽으면 다른 값이 나옵니다.

단위

부채꼴의 호의 길이 l = rθ와 넓이 S = (1/2)r²θ에서 θ는 라디안입니다. 180° = π이므로 30° = π/6, 45° = π/4, 60° = π/3, 90° = π/2입니다. 반지름이 6이고 중심각이 60°이면 θ = π/3이므로 l = 6 × π/3 = 2π, S = (1/2) × 36 × π/3 = 6π입니다. 60을 그대로 넣으면 l = 360이 되어 다른 수입니다.

통계에서는 분산과 표준편차를 구별합니다. 분산이 4이면 표준편차는 √4 = 2입니다. 단답이 기약분수 a/b에 대해 a+b를 물으면 먼저 약분합니다. 2/4는 1/2이므로 a + b = 1 + 2 = 3입니다. 약분 전 2 + 4 = 6은 다른 수입니다.

조건 표의 예입니다. 이차함수 f가 f(0) = 1, f′(1) = 0, f(1) = 3을 만족할 때 f(2)를 구합니다. f(x) = ax² + bx + c로 두면 표는 세 칸입니다.

조건식
f(0) = 1c = 1
f′(1) = 0f′(x) = 2ax + b이므로 2a + b = 0
f(1) = 3a + b + c = 3. c = 1이므로 a + b = 2

(2a + b) − (a + b) = 0 − 2 = −2이므로 a = −2입니다. a + b = 2에서 b = 4입니다. f(x) = −2x² + 4x + 1이고 f(2) = −8 + 8 + 1 = 1입니다. 그래프로 검산하면 a = −2 < 0이므로 위로 볼록하고, 꼭짓점의 x좌표는 −b/(2a) = −4/(−4) = 1, 함숫값은 3입니다. 조건 f(1) = 3과 같습니다. 축이 x이고 세로는 f(x)입니다. 꼭짓점과 한 점 (2, 1)만 있어도 개형이 맞는지 보입니다.

경우는 빠짐없이 적은 뒤, 각 경우의 답을 조건에 넣어 지웁니다. 경계가 두 경우에 모두 들어가면 개수를 셀 때 한 번만 셉니다. 경우의 수와 확률 문항도 같습니다. 나눈 경우가 서로 겹치지 않는지, 빠진 경우가 없는지를 본 뒤에 더합니다. 확률은 전체 경우와 조건에 맞는 경우를 같은 기준으로 셉니다. 주사위 두 개를 던져 눈의 합이 4일 확률에서 전체를 6 × 6 = 36으로 셌다면, 맞는 경우도 순서를 구별해 (1, 3), (2, 2), (3, 1)의 3개로 셉니다. 확률은 3/36 = 1/12입니다.

특수한 값은 오답을 지우거나 전개가 맞는지 확인할 때 씁니다. x = 1에서 성립해도 모든 실수 x에서 성립하는 것은 아닙니다. 명제를 버리려면 반례 하나면 되고, 명제를 받아들이려면 일반 계산이 필요합니다.

함정: 특수한 값으로 선다 보기를 지운 뒤, 남은 보기가 둘 이상이면 그 값만으로 답을 고르지 않습니다. 남은 보기를 가르는 조건으로 돌아갑니다.

  3. 경우가 여러 개면, 문제가 물은 것이 한 경우인지 합인지 개수인지.
  4. 선다이면 그 값이 보기 중 하나와 맞는가. 둘과 맞으면 계산을 의심합니다.
  5. 단답이면 문제가 물은 꼴의 수인가. 분수라면 약분한 a+b인가.

과목 순서

학습 순서는 미적분Ⅰ → 대수 → 확률과 통계입니다. 미적분Ⅰ은 함수의 극한과 연속, 미분, 적분의 순서로 읽습니다. 미분계수의 정의가 극한이고, 정적분은 그 미분과 이어지기 때문입니다. 세 파트가 한 줄로 이어져 가운데를 건너뛸 수 없으므로 가장 먼저 세웁니다.

대수는 지수와 로그를 먼저 둡니다. 삼각함수와 수열은 서로 순서를 바꿔도 됩니다. 둘 다 확률과 통계로 넘어가기 전에 끝냅니다. 통계에서 평균과 분산의 식을 합의 기호 ∑로 쓰기 때문입니다. 확률과 통계는 경우의 수, 확률, 통계의 순서입니다. 확률은 경우의 수로 계산하고, 통계의 확률분포는 그 확률 위에 세웁니다. 통계를 경우의 수보다 먼저 열면 밑의 문장이 비어 있습니다.

기출 회독

회독은 두 가지로 나눕니다. 실전 회독은 한 회차 30문항을 100분에 푸는 일입니다. 이때 표시하고 넘어가는 규칙과 네 덩어리를 시험과 같이 씁니다. 시험지에서는 세 과목이 섞여 나오므로 실전 회독은 1번부터 차례로 풉니다. 오답 회독은 틀린 문항과 물음표를 남긴 문항만 다시 푸는 일입니다. 맞은 문항을 매번 처음부터 다시 푸는 데 시간을 다 쓰지 않습니다.

풀어보기에는 예시문항과 2022~2027학년도 수능·모의평가 18회가 있습니다. 예시문항은 이 페이지의 번호와 배점 그대로이므로 덩어리 경계를 연습할 때 씁니다. 18회는 번호 체계가 달라 1~15번·23~28번이 선다이고 16~22번·29~30번이 단답입니다. 그 회차를 풀 때는 덩어리 경계를 그 회차의 배점에 맞춰 다시 잡습니다.

  1. 파트별로 풀 때는 미적분Ⅰ 파트 기출, 이어서 대수, 그다음 확률과 통계 순으로 문항을 고릅니다. 과목 순서를 회독에서도 유지합니다.
  2. 막히면 해설을 바로 베끼지 않습니다. 조건 표의 어느 칸에서 멈췄는지만 표시합니다.
  3. 해설을 읽은 뒤에는 덮고, 백지에 조건을 다시 적어 답을 처음부터 구합니다. 손이 따라가지 않으면 그 파트 노트로 돌아갑니다.
  4. 같은 실수가 두 번 나오면 체크리스트의 해당 줄에 표시해 직전 점검으로 올립니다.
함정: 해설의 마지막 줄만 따라 쓰고 회독했다고 세지 않습니다. 덮은 뒤 첫 줄부터 다시 구해서 같은 답에 도착해야 그 문항은 넘어갑니다.

대표 예제

눌러서 풀이를 펼치세요.

2점 하나와 3점 하나를 실수로 틀리고 4점 하나를 맞힌 경우와, 2점·3점을 맞히고 4점을 틀린 경우를 비교하시오. 이어서 예시문항과 같은 배점의 시험에서 15번 계산이 반복해서 꼬이고 22번부터는 아직 보지 않았다면 순서를 어떻게 바꾸는지 적으시오.

점수. 2 + 3 = 5이므로 2점·3점 문항 둘을 잃으면 5점입니다. 4점 하나를 못 풀면 4점입니다. 5 − 4 = 1이라, 나머지 문항이 같으면 2점·3점을 지킨 쪽이 1점 높습니다. 변별 문항 하나를 맞히려고 앞의 계산을 서두르다 틀리는 쪽이 손해입니다.

순서. 15번에 점 표시를 하고 식을 지우지 않은 채 16번으로 갑니다. 15번이 4점이어도, 같은 계산이 반복 중이면 머무르지 않습니다.

16~21번 가운데 풀리는 것은 풀고, 실마리가 없으면 물음표만 남기고 22번을 엽니다. 22~25번은 3점 단답 4개라 모두 맞히면 3 × 4 = 12점입니다. 답을 구하는 즉시 옮긴 뒤, 점이 남은 15번의 부호부터 돌아봅니다.

남은 시간이 넷째 덩어리에 들어가면 30번을 새로 설계하지 않습니다. 단답 대조와 15번의 계산이 먼저이고, 그다음에 시간이 남을 때만 30번을 엽니다.

log1/2(x − 1) > 1 을 풀고, 체크리스트의 어느 줄을 어느 단계에서 봤는지 적으시오.

1. 진수. x − 1 > 0이므로 x > 1입니다. 밑 1/2는 양수이고 1이 아니므로 로그가 정의되는 밑입니다.

2. 방향. 0 < 1/2 < 1이므로 지수로 올릴 때 부등호가 반대로 갑니다. x − 1 < (1/2)1 = 1/2입니다.

3. 범위. x < 1 + 1/2 = 3/2입니다. 진수 조건과의 교집합은 1 < x < 3/2입니다. 끝 x = 1은 진수가 0이라 빠지고, x = 3/2는 로그 값이 1이라 엄격한 부등호에서 빠집니다.

4. 대입 검산. x = 5/4이면 x − 1 = 1/4 = (1/2)2이므로 로그 값은 2이고 2 > 1입니다. 1 < 5/4 < 3/2도 맞습니다. x = 2이면 진수가 1이고 로그 값은 0이라 2는 해가 아닙니다. 방향을 반대로 하지 않으면 x > 3/2가 되어 x = 2를 해로 넣게 됩니다.

방정식 |x − 1| + |x − a| = 3 의 실근이 정확히 2개일 때 a의 범위를 구하시오. 조건 표, 경우, 특수한 값으로 검산하시오.

두 점 1과 a 사이의 거리 |a − 1|이 가운데 구간에서 거리의 합과 같습니다. 합이 3보다 크면 근이 없고, 3과 같으면 그 선분 전체가 근이라 2개를 넘으며, 3보다 작으면 바깥쪽에 근이 하나씩입니다.

a ≥ 1일 때. 가운데 1 ≤ x ≤ a에서 합은 a − 1입니다.

  • a − 1 > 3, 즉 a > 4이면 근이 없습니다.
  • a = 4이면 [1, 4] 전체가 근이라 정확히 2개가 아닙니다.
  • 1 ≤ a < 4이면 왼쪽 근 x = (a − 2)/2가 1보다 작고, 오른쪽 근 x = (a + 4)/2가 a보다 큽니다. 근은 2개입니다. a < 4일 때 (a − 2)/2 < 1이고 (a + 4)/2 > a인 것은 각각 a − 2 < 2, a + 4 > 2a로 확인됩니다.

a < 1일 때. 가운데 합은 1 − a입니다. a < −2이면 근이 없고, a = −2이면 선분 전체이며, −2 < a < 1이면 근이 2개입니다.

합치면 −2 < a < 4입니다.

특수한 값. a = 1이면 x = −1/2, 5/2이고 2|x − 1| = 3이라 근이 2개입니다. 범위 안입니다. a = 0이면 x = −1, 2입니다. |−1 − 1| + |−1| = 3, |2 − 1| + |2| = 3이라 근이 2개입니다. a = 4이면 x = 1, 2, 4만 봐도 |2 − 1| + |2 − 4| = 3이고 사이 점이 더 있어 2개를 넘습니다. a = 5이면 거리의 최솟값이 4 > 3이라 근이 없습니다.

f(x) = x³ − 3x 의 닫힌 구간 [0, 3]에서 최댓값과 최솟값의 합을 단답으로 낸다면, 계산과 답을 옮길 때 대조할 것을 적으시오.

1. 도함수. f′(x) = 3x² − 3 = 3(x² − 1) = 3(x − 1)(x + 1)입니다. f′(x) = 0인 점은 x = 1, x = −1이고, [0, 3] 안은 x = 1뿐입니다.

2. 끝점과 임계점. f(0) = 0, f(1) = 1 − 3 = −2, f(3) = 27 − 9 = 18입니다. 최댓값은 18, 최솟값은 −2, 합은 18 + (−2) = 16입니다.

끝만 보면 f(0) = 0과 f(3) = 18이라 최솟값을 0으로 두고 합을 18로 잘못 낼 수 있습니다. x = 1의 함숫값 −2가 끝값보다 작습니다.

3. 옮기기. 물은 것은 최댓값도 최솟값도 아닌 합이므로 18이나 −2가 아니라 16을 옮깁니다. 16은 자연수입니다. 문제지의 16과 답안지의 수를 자리마다 대조합니다. 1과 6의 자리가 바뀌면 61이고, 한 자리가 빠지면 1 또는 6이 됩니다. 번호도 그 문항의 답란인지 봅니다.
