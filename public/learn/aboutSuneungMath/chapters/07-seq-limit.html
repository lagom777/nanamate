1. 수열의 수렴과 발산

수열은 자연수 n에 수 an을 하나씩 대응시킨 목록입니다. 그래프를 그릴 때는 점 (n, an)만 찍습니다. 점을 선으로 이어 보이는 중간 값은 수열이 아닙니다. n은 1, 2, 3, …으로만 움직입니다.

수렴의 뜻

수열 {an}이 실수 L에 수렴한다는 것은, 아무리 작은 양수 ε을 잡아도 어느 번호 N 이후로는 an이 L에서 ε보다 가깝게 머문다는 뜻입니다.

임의의 양수 ε에 대해, n ≥ N이면 |an − L| < ε인 자연수 N이 존재한다.
이때 lim an = L 이라 쓰고, L을 극한값이라고 합니다.

극한값은 하나뿐입니다. 두 수에 동시에 수렴할 수는 없습니다. 수렴하지 않으면 발산한다고 합니다. 발산은 세 가지로 나누어 읽습니다.

종류뜻예
수렴유한한 극한값 L이 있다1/n → 0, (n+1)/n → 1
양의 무한대 발산n을 키우면 an이 어떤 수보다도 커진다n, n²
음의 무한대 발산n을 키우면 an이 어떤 수보다도 작아진다−n
진동한 값으로도, 무한대로도 가지 않는다(−1)n

유계와 단조

수렴하는 수열은 유계입니다. 즉 모든 항을 집어넣는 유한한 구간이 있습니다. 유계가 아니면 반드시 발산합니다. 역은 성립하지 않습니다. (−1)n은 −1과 1 사이에 있지만 진동합니다. 증가하면서 위로 유계이거나, 감소하면서 아래로 유계이면 수렴합니다. 이것을 단조수렴정리라고 부릅니다. e의 정의가 이 정리를 사용합니다.

극한의 성질

lim an = α, lim bn = β이고 α, β가 모두 유한할 때만 다음이 성립합니다.

lim (an ± bn) = α ± β
lim (c an) = cα, lim c = c
lim (an bn) = αβ
lim (an / bn) = α/β (β ≠ 0)
함정: 한쪽이 발산하면 합·차·곱·몫의 극한을 따로 계산해 붙이지 못합니다. an = n, bn = −n이면 합은 0으로 수렴하지만, ∞와 −∞를 먼저 구한 뒤 더하는 규칙은 없습니다. ∞ − ∞, 0 × ∞, ∞/∞는 계산을 더 하기 전의 모양일 뿐입니다.

대소 관계

어느 번호 이후 항상 an ≤ bn이고 두 수열이 모두 수렴하면, 극한도 lim an ≤ lim bn입니다. 부등호가 엄격해도 극한에서는 등호가 될 수 있습니다. 0 < 1/n이지만 둘 다 0으로 수렴합니다. 극한값의 대소로 항의 대소를 역추적하는 것도 되지 않습니다.

2. 극한값의 계산

수능의 계산은 대부분 유리식의 차수 비교와, 무리식의 유리화입니다. n은 자연수이므로 n의 거듭제곱은 항상 양수입니다. 같은 식의 실수 함수 극한이 있으면 수열의 극한도 그 값과 같습니다.

최고차항 비교

분자 차수 p, 분모 차수 q, 최고차항의 계수를 각각 A, B(B ≠ 0)라고 하면 다음과 같습니다.

차수극한수능에서 쓰는 말
p < q0분모가 더 빨리 커진다
p = qA/B최고차항의 계수비
p > qA/B의 부호 쪽으로 무한대유한한 극한이 되려면 차수가 같거나 분자가 더 낮아야 한다

실무 절차는 하나입니다. 분모의 최고차항으로 분자·분모를 나눕니다.

lim (2n² − n) / (3n² + 1) = lim (2 − 1/n) / (3 + 1/n²) = 2/3
lim (n³ + 1) / (n² + n) = lim (n + 1/n²) / (1 + 1/n) → +∞
TIP: “극한이 존재하고 그 값이 유한하다”는 조건은 차수에 대한 방정식입니다. 유한하고 0이 아닌 값이면 분자·분모의 차수가 같고, 계수비가 그 값입니다. 극한이 0이면 분자의 차수가 더 낮습니다. 계수가 문자로 남아 있으면 이 조건으로 문자를 결정합니다.

한 단계 더 정밀한 극한도 같은 생각입니다. lim an = L로 계수를 맞춘 뒤, n(an − L)처럼 0이 되는 부분을 한 번 더 전개합니다. 대표 예제 첫 문제가 이 유형입니다.

유리화

√(n² + an + b) − n 꼴은 ∞ − ∞입니다. 켤레를 곱해 차를 제곱 차로 바꿉니다. n > 0이므로 √(n²) = n입니다. −n으로 꺼내면 부호가 뒤집힙니다.

√(n² + an + b) − n = (an + b) / (√(n² + an + b) + n)
분자·분모를 n으로 나누면 → a/2

확인: √(n² + n) − n = n / (√(n² + n) + n) → 1/2. √(4n² + n) − 2n = n / (√(4n² + n) + 2n) → 1/4입니다. 앞에 n이 한 번 더 곱해져 있으면, 유리화한 뒤 다시 최고차항으로 나눕니다. 대표 예제의 둘째 문제가 그 계산입니다.

그래프·식 읽는 순서

1) ∞/∞인지 ∞ − ∞인지 분류합니다. 2) 유리식이면 차수를 비교하고, 유한하면 계수비를 읽습니다. 3) 차가 있으면 켤레로 유리화합니다. 4) 문자 계수가 있으면 “유한한 극한” 조건으로 차수를 먼저 맞추고, 남는 문자에 정밀 극한 조건을 넣습니다.

3. 등비수열의 극한과 샌드위치

등비수열 rn의 극한은 공비 하나만 보면 됩니다. 수열의 극한에서 가장 자주 갈리는 경계는 r = −1과, 절댓값이 1보다 작은 음수입니다.

rlim rn읽는 그림
r > 1+∞1, r, r², … 가 위로 튀어 오른다
r = 11모든 항이 1
|r| < 10양수면 0으로 감소, 음수면 부호가 바뀌며 진폭이 0으로 줄어든다
r ≤ −1발산(진동)r = −1이면 −1, 1, −1, 1. r < −1이면 진폭이 커지며 부호가 바뀐다

0 < r < 1일 때의 근거는 다음과 같습니다. r = 1/(1+p), p > 0으로 두면 이항정리에서 (1+p)n ≥ 1 + np입니다. 따라서 0 < rn ≤ 1/(np) → 0입니다. −1 < r < 0이면 |rn| = |r|n → 0이므로 rn도 0으로 수렴합니다. r > 1이면 r = 1+p로 두어 rn ≥ 1 + np → ∞입니다.

밑이 여러 개인 지수식은 절댓값이 가장 큰 밑으로 나눕니다. |2/5| < 1이므로 (2/5)n → 0입니다.

lim (3·2n + 5n) / (2n + 3·5n)
= lim (3·(2/5)n + 1) / ((2/5)n + 3) = 1/3
함정: |r| < 1을 “r이 양수이고 1보다 작다”로만 외우면 r = −1/2를 발산으로 처리합니다. 부호가 바뀌어도 진폭이 0으로 줄어들면 수렴입니다. 발산은 절댓값이 1 이상일 때입니다.

샌드위치 정리

어느 번호 이후 an ≤ cn ≤ bn이고 lim an = lim bn = L이면 lim cn = L입니다. 위아래가 같은 값으로 모이면 가운데도 그 값입니다.

0 < n / (n² + 1) < n / n² = 1/n
1/n → 0이므로 n / (n² + 1) → 0

절댓값으로 쓰면 |cn − L| ≤ dn이고 dn → 0일 때 cn → L입니다. 등비수열에서 |an| ≤ |r|n, |r| < 1이면 an → 0인 것이 이 꼴입니다.

TIP: 샌드위치를 쓸 때는 가운데 식을 그대로 계산하지 말고, 계산되는 위·아래 식으로 바꾸어 두 극한이 같은지 먼저 확인합니다. 위아래 극한이 다르면 정리를 쓸 수 없습니다.

4. 급수의 수렴과 발산

급수 Σ an은 a1 + a2 + a3 + … 이라는 덧셈의 약속입니다. 무한 개를 한 번에 더하는 것이 아니라, 부분합의 극한으로 정의합니다.

Sn = a1 + a2 + … + an
급수가 수렴한다 ⇔ 수열 {Sn}이 수렴한다
합 S = lim Sn

발산하면 합이라는 수를 정하지 않습니다. 부분합이 양의 무한대로 가면 “무한대로 발산한다”고 말합니다.

일반항과 부분합

a1 = S1, n ≥ 2이면 an = Sn − Sn−1

S0 = 0으로 두면 n = 1에도 a1 = S1 − S0이 성립합니다. 부분합의 닫힌 식에 n = 0을 대입한 값이 0이 아닐 수 있으므로, 공식이 n ≥ 1용으로 주어졌으면 첫째항은 S1로 따로 읽습니다.

수렴하면 일반항은 0

급수가 S로 수렴하면 Sn과 Sn−1이 같은 S로 수렴하므로 an = Sn − Sn−1 → 0입니다. 이것은 필요조건입니다. 일반항이 0이 아니면 급수는 발산합니다. 예를 들어 an = (−1)n이면 부분합이 한 값에 모이지 않습니다.

함정: 역은 거짓입니다. lim an = 0이어도 급수는 발산할 수 있습니다. “일반항이 0으로 가니까 합도 수렴”은 이 단원에서 가장 많이 틀리는 문장입니다.

반례 하나. an = √(n+1) − √n = 1 / (√(n+1) + √n) → 0입니다. 부분합은 망원경처럼 중간이 사라지고 Sn = √(n+1) − 1 → ∞입니다. 일반항은 0인데 급수는 발산합니다.

교과서의 또 다른 반례는 an = 1/n입니다. 부분합을 2의 거듭제곱에서 끊으면

S2^m = 1 + [1/2] + [1/3+1/4] + [1/5+…+1/8] + … + [마지막 묶음]
1을 제외한 묶음이 m개이고, 각 묶음 ≥ 1/2 이므로 S2^m ≥ 1 + m/2

예를 들어 m = 2이면 S4 ≥ 1 + 1/2 + (1/4+1/4) = 2이고, m = 3이면 1/2 묶음이 세 개라 S8 ≥ 1 + 3/2입니다. m을 키우면 아랫한계가 한없이 커지므로 부분합은 수렴하지 않습니다. 그러나 1/n → 0입니다.

부분합을 직접 구하는 급수

판정법 이름은 이 과목의 범위가 아닙니다. 교과에서 실제로 하는 일은 세 가지입니다. 일반항이 0이 아니면 발산, 등비급수이면 공비의 절댓값으로 판정, 부분합이 닫히면 그 극한을 구합니다.

1/(n(n+1)) = 1/n − 1/(n+1)
Sn = 1 − 1/(n+1) → 1

이웃한 부분합의 차가 일반항이라는 사실을 거꾸로 쓰면, Sn의 식이 주어졌을 때 합은 lim Sn이고 일반항의 극한은 0인지 아닌지만 보면 수렴 여부가 갈립니다. lim Sn이 유한하면 급수는 그 값에 수렴하고, 자동으로 an → 0입니다.

수렴하는 급수끼리 더하거나 상수배를 하면 합도 그대로 더해지고 상수배가 됩니다. 수렴하는 급수와 발산하는 급수를 더하면 발산합니다. 수렴하는 것을 양쪽으로 옮겨 보면, 차가 발산하기 때문입니다.

5. 등비급수와 도형

첫째항 a, 공비 r인 등비급수는 a + ar + ar² + … 입니다. 부분합은 r ≠ 1일 때 다음과 같습니다.

Sn = a + ar + … + arn−1
rSn = ar + … + arn
Sn − rSn = a − arn
Sn = a(1 − rn) / (1 − r)

|r| < 1이면 rn → 0이므로 합이 남습니다. 그 밖의 공비에서는, a = 0인 자명한 경우를 빼면, 일반항이 0으로 가지 않거나 부분합이 진동하므로 발산합니다.

|r| < 1일 때 Σ arn−1 = a / (1 − r)
|r| ≥ 1이면 (a ≠ 0) 발산
공비등비급수부분합으로 확인
|r| < 1수렴, 합 a/(1−r)rn이 사라져 첫째항/(1−공비)
r = 1발산 (a ≠ 0)Sn = na
r > 1발산일반항 arn−1이 0이 아님
r ≤ −1발산(진동)r = −1이면 부분합이 a, 0, a, 0, …

교대급수도 |r| < 1이면 같은 공식입니다. 1 − 1/2 + 1/4 − 1/8 + … 은 첫째항 1, 공비 −1/2이므로 합은 1 / (1 − (−1/2)) = 2/3입니다. 부호가 바뀐다고 발산이 아닙니다.

합이 둘째 항부터이면 첫째항을 다시 잡습니다. Σn=2∞ (1/2)n = (1/4) / (1 − 1/2) = 1/2입니다. n = 1부터의 합 1에서 첫째항 1/2를 빼도 같습니다.

함정: 공식 a/(1−r)는 |r| < 1일 때만 씁니다. r = 1, r = −2 같은 값을 분모에 넣으면 분모가 0이 되거나, 발산하는 급수에 수를 붙이게 됩니다.

도형에서 첫째항과 공비 읽기

닮음비가 r이면 대응하는 길이의 비는 r, 넓이의 비는 r², 부피의 비는 r³입니다. 급수에 넣는 공비는 더하는 양이 길이인지 넓이인지로 고릅니다.

길이의 합: 첫째 길이 L, 공비 r, |r| < 1 → L / (1 − r)
넓이의 합: 첫째 넓이 A, 공비 r² → A / (1 − r²)

한 변의 길이가 6인 정사각형에서 시작해, 한 변이 직전의 1/3인 정사각형을 끝없이 잇는 상황을 보겠습니다. 길이의 공비는 1/3, 첫째 변의 합은 6 / (1 − 1/3) = 9입니다. 넓이의 첫째항은 36, 공비는 (1/3)² = 1/9이므로 넓이의 합은 36 / (1 − 1/9) = 36 · 9/8 = 81/2입니다. 길이 공비 1/3을 넓이 합에 넣으면 36 / (2/3) = 54가 되어 틀립니다.

그림 읽는 순서

1) 색칠된 조각 중 첫째 조각의 길이 또는 넓이를 수로 구합니다. 이것이 첫째항입니다. 2) 다음 조각이 앞 조각의 몇 배인지 변의 비로 구합니다. 길이 공비 r, 넓이 공비 r²입니다. 3) 공비의 절댓값이 1보다 작은지 확인합니다. 4) 첫째항/(1−공비)를 씁니다. 앞의 몇 조각이 빠져 있으면 실제 첫째항으로 다시 잡거나, 전체 합에서 빠진 항을 뺍니다.

수능에서 묻는 세 가지

  • 극한값으로 계수 결정. 유한한 극한이면 차수를 맞추고 계수비를 읽습니다. n(an − L)의 극한이 더 주어지면, L을 만든 뒤 남은 일차항의 계수까지 결정합니다.
  • 등비급수의 도형. 문장이 아니라 그림에서 첫째항과 공비를 읽습니다. 길이 합인지 넓이 합인지가 공비를 r로 둘지 r²로 둘지 가릅니다.
  • Sn과 an. 부분합의 극한이 합이고, 일반항은 이웃한 부분합의 차입니다. 합이 유한하면 일반항은 0입니다. 일반항이 0이 아니면 부분합은 수렴하지 않습니다.
TIP: 계산 전에 한 줄만 적습니다. “유한 / 무한 / 진동”, “길이 공비 / 넓이 공비”, “구하는 것이 S인지 an인지”. 이 세 단어가 맞으면 공식은 거의 자동입니다.

자주 나오는 함정

  • |r| ≥ 1인데 합 공식에 대입하기. a/(1−r)는 공비의 절댓값이 1보다 작을 때만 성립합니다. r = 1이면 분모가 0이고, 부분합은 na입니다.
  • 일반항이 0이면 급수가 수렴한다고 판단하기. 필요조건일 뿐입니다. √(n+1) − √n과 1/n은 0으로 가지만 부분합은 무한대로 갑니다.
  • 넓이 합에 길이 공비 r을 넣기. 닮음비 r인 도형의 넓이 공비는 r²입니다. 부피를 더하면 r³입니다.
  • 항이 엄격히 작으면 극한도 엄격히 작다고 생각하기. 0 < 1/n이지만 극한은 둘 다 0입니다.
  • 발산하는 수열의 극한을 사칙연산으로 쪼개기. ∞ − ∞ 꼴은 유리화나 차수 비교로 모양을 바꾼 뒤에야 극한을 말합니다.
  • −1 < r < 0인 rn을 발산으로 보기. 부호는 바뀌지만 0으로 수렴합니다. 진동 발산은 r ≤ −1일 때입니다.
  • 부분합의 극한과 일반항의 극한을 바꾸기. 수렴하는 급수에서 Sn은 합 S로, an은 0으로 갑니다. 합이 0이라는 뜻이 아닙니다.
  • 유리화할 때 √(n²)를 −n으로 꺼내기. n은 자연수이므로 √(n²) = n입니다.

대표 예제

눌러서 풀이를 펼치세요.

수열 aₙ = (p n² + q n)/(n² + 1)이 2로 수렴하고, n(aₙ − 2)도 3으로 수렴한다. p + q는?

an − 2 = (p n² + q n − 2n² − 2)/(n² + 1) = ((p−2)n² + q n − 2)/(n² + 1)입니다.

이 값이 0으로 가려면 분자의 차수가 분모보다 낮아야 하므로 p − 2 = 0, p = 2입니다. 차수가 같으면 극한은 0이 아닙니다.

이제 an − 2 = (q n − 2)/(n² + 1)입니다. n을 곱하면 n(an − 2) = (q n² − 2n)/(n² + 1) → q입니다. 조건에서 이 극한이 3이므로 q = 3입니다.

p + q = 5입니다. 검산: an = (2n² + 3n)/(n² + 1)이면 극한은 2이고, n(an − 2) = (3n² − 2n)/(n² + 1) → 3입니다.

lim n( √(n² + 6n + 1) − n − 3 )을 구하시오. n은 무한대로 갑니다.

∞ − ∞ 꼴이므로 n+3을 한 덩어리로 보고 켤레를 곱합니다.

√(n² + 6n + 1) − (n+3) = [ (n² + 6n + 1) − (n+3)² ] / [ √(n² + 6n + 1) + n + 3 ]

분자는 n² + 6n + 1 − (n² + 6n + 9) = −8입니다. 따라서 원식은

n · (−8) / (√(n² + 6n + 1) + n + 3) = −8n / (√(n² + 6n + 1) + n + 3)입니다.

분자·분모를 n으로 나눕니다. n > 0이므로 √(n² + 6n + 1)/n = √(1 + 6/n + 1/n²)입니다.

−8 / (√(1 + 6/n + 1/n²) + 1 + 3/n) → −8 / (1 + 1) = −4입니다.

한 변의 길이가 2인 정사각형에서 시작해, 각 변의 중점을 이어 정사각형을 만드는 일을 끝없이 반복한다. 이렇게 생긴 정사각형들의 넓이를 모두 더하면?

겹쳐 있는 영역의 합집합이 아니라, 각 정사각형의 넓이를 항으로 더한 급수입니다.

한 변의 길이가 a일 때, 이웃한 변의 중점을 이은 선분의 길이는 피타고라스 정리로 √((a/2)² + (a/2)²) = a/√2입니다. 넓이 비는 (a/√2)² / a² = 1/2입니다. 매 단계가 같은 조작이므로 넓이의 공비는 항상 1/2입니다.

첫째 넓이는 2² = 4입니다. |1/2| < 1이므로 합은 4 / (1 − 1/2) = 8입니다.

항으로 확인하면 4, 2, 1, 1/2, … 입니다. 둘째 변은 2/√2 = √2, 넓이 2. 셋째 변은 1, 넓이 1. 공비 1/2가 맞습니다.

부분합이 Sₙ = (n+1)/(n+2)인 급수의 합, lim aₙ, lim n² aₙ을 구하시오.

합은 부분합의 극한입니다. Sn = (n+1)/(n+2) → 1이므로 급수는 수렴하고 합은 1입니다. 수렴하므로 lim an = 0입니다.

첫째항은 a1 = S1 = 2/3입니다. n ≥ 2이면

an = Sn − Sn−1 = (n+1)/(n+2) − n/(n+1) = [ (n+1)² − n(n+2) ] / [ (n+1)(n+2) ] = 1/[(n+1)(n+2)]입니다.

따라서 n² an = n² / [(n+1)(n+2)] → 1입니다.

검산: 1/[(n+1)(n+2)] = 1/(n+1) − 1/(n+2)이므로 n = 2부터 N까지 더하면 1/3 − 1/(N+2)입니다. a1 = 2/3를 더하면 1 − 1/(N+2) = SN입니다.

한 줄

수열은 “항이 어디로 가는가”, 급수는 “더한 합이 어디로 가는가”입니다. 등비에서는 공비의 절댓값이 1보다 작으면 항도 0으로 가고, 급수도 첫째항/(1−공비)로 모입니다.

  • 유한한 극한은 최고차항의 계수비입니다.
  • ∞ − ∞는 켤레를 곱해 유리화합니다.
  • 급수가 수렴하면 일반항은 0입니다. 그 역은 아닙니다.
  • 도형에서 길이는 공비 r, 넓이는 공비 r²입니다.
고급

계수 결정 문항은 (1) 극한이 유한하도록 차수를 맞추고 (2) 계수비로 첫 문자를 구한 뒤 (3) an − L을 한 번 더 전개해 다음 문자를 구합니다. 차수를 맞추기 전에 계수비부터 쓰면, 무한대로 가는 식에 유한 극한을 대입하게 됩니다.

도형 문항은 그림에서 첫째 조각과 바로 다음 조각만 계산해 공비를 확정합니다. 세 번째 조각까지 세지 않아도, 닮음이 반복되면 공비는 같습니다. Sn이 주어지면 합은 lim Sn이고, 일반항은 n ≥ 2에서 Sn − Sn−1입니다. 더 정밀한 lim nk an은 그 차를 통분한 뒤 최고차항만 남깁니다.
