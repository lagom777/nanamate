지수와 로그

Part 1 · 수학Ⅰ

거듭제곱근·지수법칙·로그의 정의와 성질·지수함수와 로그함수

3.9회당 문항 수
12.5점회당 배점
3~4회차별 범위
67최근 17회 누적

수능 2018~2026학년도 + 6·9월 모의평가 17회(2018~2020학년도는 2009 개정 교육과정)(510문항) 기준. 문항 본문 키워드로 분류한 값이라 ±1문항 오차가 있을 수 있습니다.

지수와 로그는 식을 간단히 하는 계산과 그래프를 읽는 문제가 함께 나옵니다. 밑을 하나로 맞추거나 로그의 성질로 식을 줄이고, 부등식에서는 밑이 1보다 큰지 작은지에 따라 방향이 바뀝니다. 그래프에서는 점근선과 지나는 점을 읽고, 지수함수와 로그함수가 서로 역함수라는 사실로 교점과 직선의 관계를 묻습니다.

하나만 고른다면로그는 지수방정식의 해에 붙인 이름이다 — 지수법칙을 ax = M ⇔ x = loga M으로 옮기면 로그의 성질과 밑 변환이, x와 y를 바꾸면 y = x에 대칭인 로그함수의 그래프가 나온다.

왜 사슬

다음 단계를 먼저 머릿속으로 떠올린 뒤, 가려진 단계를 눌러 맞았는지 확인하세요.

  1. 지수를 정수에서 유리수·실수로 넓히려면 밑을 양수로 제한해야 한다 → 그래야 ax가 모든 실수 x에서 하나로 정해지고 지수법칙 다섯 개가 그대로 성립한다
  2. a > 0, a ≠ 1이면 ax = M (M > 0)의 해가 단 하나 → 그 해에 붙인 이름이 loga M(밑 조건과 진수 조건이 여기서 나온다)
  3. 지수법칙을 로그로 옮기면 곱 → 합, 몫 → 차, 거듭제곱 → 계수 → 밑 변환도 ak = b의 양변에 logc를 취해 나온다(loga b = logc b / logc a)
  4. y = ax와 y = loga x는 같은 관계를 x, y만 바꿔 쓴 것 → y = x에 대칭인 역함수, 점근선(y = 0 ↔ x = 0)과 지나는 점((0, 1) ↔ (1, 0))도 서로 바뀐다
  5. 증가·감소는 밑이 1보다 큰가 하나로 정해진다 → 부등식의 방향이 바뀌는지, 역함수와의 교점이 y = x 위에만 있는지(a > 1일 때)가 여기서 갈린다

거듭제곱근 — 짝수 번 곱하면 부호가 사라진다

xn = a를 만족하는 실수 x를 a의 n제곱근이라고 합니다. 짝수 번 곱하면 음수도 양수가 되므로, n이 짝수일 때 양수 a의 n제곱근은 양수와 음수 두 개이고 음수 a에는 실수인 n제곱근이 없습니다. 홀수 번 곱하면 부호가 그대로 남으므로 n이 홀수이면 a의 부호와 관계없이 하나뿐입니다. 짝수일 때 기호 n√는 두 근 가운데 양수 쪽을 뜻하므로 n이 짝수이면 n√(an) = |a|이고, √((−3)²) = 3이지 −3이 아니며, 홀수인 ∛((−2)³) = −2는 원래 수로 돌아옵니다.

지수를 0, 음수, 분수로 넓힐 때 기준은 하나, 지수법칙이 계속 성립하게 정의하는 것입니다. a0·an = an이어야 하므로 a0 = 1, a−n·an = a0 = 1이어야 하므로 a−n = 1/an입니다. (am)n = amn도 지키려면 (a1/n)n = a여야 하므로 a1/n = n√a, am/n = n√(am)입니다. 예를 들어 82/3 = (2³)2/3 = 2² = 4이고, ∛64 = 4로 같습니다.

유리수 지수에서 밑을 양수로 제한하는 것도 이 법칙 때문입니다. (−8)1/3 = −2인데 같은 지수를 2/6으로 쓰면 6√((−8)²) = 6√64 = 2가 되어, 밑이 음수이면 지수를 약분하는 것만으로 값이 달라집니다. 그래서 ax는 a > 0일 때만 다루고, 이 범위에서 x를 실수 전체로 넓혀 끊기지 않는 곡선을 얻습니다.

지수법칙 — 곱한 개수를 세는 규칙

am은 a를 m번 곱한 것이므로 am·an은 a를 m + n번 곱한 것이고, (am)n은 m개짜리 묶음을 n번 곱한 것이라 amn입니다. 그래서 같은 밑의 곱은 지수의 합, 거듭제곱의 거듭제곱은 지수의 곱이고, 나눗셈은 지수의 차, (ab)n = anbn과 (a/b)n = an/bn은 지수가 같을 때 밑끼리 묶는 규칙입니다. 앞 절의 정의가 이 다섯 줄을 실수 지수까지 지켜 주므로, 계산은 언제나 이 다섯 줄로 돌아옵니다.

실전에서는 모든 밑을 가장 작은 소수의 거듭제곱으로 바꾼 뒤 지수만 계산합니다. 8 = 2³, 9 = 3², 16 = 2⁴, 27 = 3³으로 보면 163/4 = 2³ = 8이고, 811/4 ÷ 91/2 = 3 ÷ 3 = 1입니다. 거듭제곱 탑은 위에서부터 읽어 232 = 29 = 512이고, (2³)² = 64와는 다른 수입니다.

로그는 지수를 거꾸로 읽은 것

2x = 8의 답은 3이지만 2x = 5의 답은 익숙한 수로 바로 쓸 수 없어서, 그 답에 붙인 이름이 log2 5입니다. 즉 ax = M ⇔ x = loga M이고, 로그는 ‘a를 몇 제곱하면 M이 되는가’의 답입니다. 밑이 양수인 것은 ax를 a > 0에서만 정의했기 때문이고, 밑이 1이면 1x이 늘 1이라 답이 하나로 정해지지 않으므로 1도 뺍니다. 또 ax는 항상 양수이므로 진수 M도 양수여야 합니다.

로그의 성질은 모두 지수법칙을 로그로 옮긴 것입니다. loga M = p, loga N = q로 두면 M = ap, N = aq이고 MN = ap+q이므로 loga MN = loga M + loga N입니다. 같은 방법으로 M/N = ap−q에서 몫의 로그는 차, Mk = akp에서 loga Mk = k loga M이 나오고, log2 12 − log2 3 = log2 4 = 2처럼 씁니다.

유도를 알면 흔한 착각이 왜 틀렸는지 보입니다. 합으로 갈라지는 것은 진수끼리 곱해져 있을 때뿐이므로 log(M + N)은 log M + log N이 아니고, (log M)²도 2 log M = log M²과 다릅니다. 로그가 보이면 성질을 쓰기 전에 진수 조건부터 여백에 적어 두어야, 나중에 범위 밖의 근을 걸러 낼 수 있습니다.

밑변환 공식 — 모든 로그를 한 밑으로

밑이 다른 로그끼리는 밑을 하나로 맞춰야 계산이 됩니다. loga b = k라 하면 ak = b이고, 양변에 밑이 c인 로그를 취하면 k logc a = logc b이므로 loga b = logc b / logc a입니다. c = b로 두면 loga b = 1/logb a로 서로 역수이고, 두 로그를 곱하면 가운데 밑이 약분되어 loga b · logb c = loga c입니다.

예를 들어 log4 8 = log2 8 / log2 4 = 3/2이고, 43/2 = 2³ = 8로 검산됩니다. 수능은 ‘log2 3 = a, log2 5 = b일 때 log6 15’처럼 주어진 로그의 밑으로 통일하는 문항을 자주 냅니다. log6 15 = log2 15 / log2 6 = (a + b)/(1 + a)처럼, 진수를 소인수로 쪼개 주어진 값의 합으로 바꾸면 끝납니다.

상용로그 — 지표는 자릿수, 가수는 숫자 배열

밑이 10인 상용로그는 십진법과 맞물립니다. 양수 N을 N = m × 10n(1 ≤ m < 10, n은 정수)으로 쓰면 log N = n + log m이고 0 ≤ log m < 1이므로, 정수 부분 n(지표)은 10의 몇 제곱 자리인지를, 소수 부분 log m(가수)은 숫자의 배열을 나타냅니다. 그래서 log 2와 log 200은 가수가 같고 지표만 2만큼 다르며, N ≥ 1이면 N의 정수 부분은 지표 + 1자리입니다.

log 2 = 0.3010, log 3 = 0.4771만 주어져도 나머지는 성질로 만듭니다. log 5 = log(10/2) = 1 − log 2 = 0.6990이므로 log 58 = 8 × 0.6990 = 5.592이고, 지표가 5라서 58은 여섯 자리이며 실제로 390625입니다. 210도 log 값이 3.010이라 네 자리(1024)입니다.

1보다 작은 수는 지표가 음수입니다. log 0.02 = log(2 × 10−2) = −2 + 0.3010 = −1.6990이므로 지표는 −2, 가수는 0.3010입니다. 이것을 −2.3010으로 쓰면 가수가 음수가 되고, 실제로 −2.3010은 log 0.005의 값입니다. 음의 로그는 그 값 이하의 가장 큰 정수를 지표로 잡아야 가수가 0 이상 1 미만으로 맞춰집니다.

그래프 — 지수함수와 로그함수는 y = x에 대칭

y = ax는 a0 = 1이라 항상 (0, 1)을 지나고, ax > 0이라 x축에 한없이 다가가기만 하므로 점근선이 y = 0입니다. a > 1이면 증가, 0 < a < 1이면 감소합니다. y = loga x는 x와 y를 바꾼 역함수라 그래프가 직선 y = x에 대하여 대칭이고, 그래서 (1, 0)을 지나며 점근선이 y축이고 정의역이 x > 0입니다.

평행이동하면 점근선과 기준점이 함께 움직여, y = ax−p + q는 점근선 y = q와 점 (p, 1 + q)를, y = loga(x − p) + q는 점근선 x = p와 점 (p + 1, q)를 가집니다. y = 3x + 1은 점근선 y = 1과 점 (0, 2), (1, 4)를 지나고, 역함수 y = log3(x − 1)은 점근선 x = 1과 점 (2, 0), (4, 1)을 지나 좌표를 서로 바꾼 점이 그대로 나옵니다. 그래프 문항은 밑의 크기(증감) → 점근선 → 쉬운 점 하나 → 문제의 점 대입 순서로 읽습니다.

방정식·부등식과 교점 — 밑의 크기가 방향을 정한다

지수방정식은 밑을 같게 만들거나 되풀이되는 ax를 한 문자로 바꿉니다. 9x = 27x−1은 32x = 33x−3이라 x = 3이고, 2·4x − 9·2x + 4 = 0은 t = 2x로 두면 (2t − 1)(t − 4) = 0이라 x = −1, 2이며, t = 2x > 0이므로 0 이하의 t는 버립니다. 로그방정식 log2(x − 1) + log2(x + 1) = 3은 합치면 x² − 1 = 8에서 x = ±3이지만, 합친 식이 원래 식보다 넓은 범위에서 정의되어 생긴 x = −3은 진수 조건 x > 1로 버립니다.

부등식의 방향은 함수의 증감에서 나옵니다. 밑이 1보다 크면 증가함수라 큰 입력이 큰 출력을 내므로 방향이 유지되고, 밑이 0과 1 사이이면 감소함수라 방향이 바뀝니다. (1/2)x+1 ≥ 4 = (1/2)−2는 x + 1 ≤ −2, 곧 x ≤ −3이고, log1/2(x − 1) ≥ −1은 진수 조건 x > 1과 x − 1 ≤ 2를 합쳐 1 < x ≤ 3입니다.

밑이 1보다 크면 y = ax와 y = loga x의 교점은 있다면 모두 y = x 위에 있습니다. 교점 (p, q)에서 q = ap, p = aq인데 p > q이면 ap > aq, 곧 q > p가 되어 모순이고 반대도 마찬가지이기 때문입니다. 이 논증은 증가함수일 때만 통하므로 밑이 1보다 작으면 y = x 밖의 교점이 생길 수 있고, 밑이 1/16이면 (1/2, 1/4)와 (1/4, 1/2)가 그 예입니다. 수학Ⅰ의 넓이 문항은 적분 없이 교점을 꼭짓점으로 한 도형으로 계산하며, y = 2x, y = 2−x, y = 2의 교점 (1, 2), (−1, 2), (0, 1)이 만드는 삼각형의 넓이는 1입니다.

외울 것은 이것뿐지수법칙 다섯 개, 로그의 정의 ax = M ⇔ x = loga M과 조건(a > 0, a ≠ 1, M > 0), 밑이 1보다 크면 증가·작으면 감소

나머지는 유도로그의 성질 세 개와 밑 변환, 짝수 제곱근의 |a|, 상용로그의 지표와 자릿수, 평행이동한 그래프의 점근선과 지나는 점, 부등식의 방향, 역함수와의 교점

논리형 함정식을 정리하는 데 집중하다가 진수 조건을 마지막까지 미루기 쉽습니다. 로그를 하나로 합치면 정의역이 넓어져 무연근이 생길 수 있으므로, log가 보이면 첫 줄에 진수 > 0부터 적으세요.

문제부터 부딪치고 싶다면 대표 예제를 먼저 풀고, 막힌 고리만 사슬에서 찾아 채우세요.

1. 거듭제곱근과 지수의 확장

n이 2 이상의 정수일 때, 방정식 xn = a를 만족하는 실수 x를 a의 n제곱근이라고 합니다. 그중에서 대표로 쓰는 값을 n√a로 적습니다. a가 0 이상이면 n√a도 0 이상이고, a가 음수이면서 n이 홀수일 때만 n√a가 음수입니다.

an이 짝수n이 홀수
a > 0실수 근 2개(양수, 음수). n√a는 양수실수 근 1개(양수)
a = 00뿐0뿐
a < 0실수 근 없음실수 근 1개(음수). n√a < 0

정의되는 범위에서 (n√a)n = a입니다. 반대로 an의 n제곱근을 도로 a로 돌릴 때는 짝수·홀수를 가릅니다.

n이 홀수: n√(an) = a
n이 짝수: n√(an) = |a|

√((−3)2) = √9 = 3 = |−3|입니다. −3이 아닙니다. 반면 ∛((−2)3) = ∛(−8) = −2처럼, 홀수 제곱근은 음수 밑에서도 원래 수로 돌아옵니다.

지수는 자연수에서 정수로, 다시 유리수로 넓혀 씁니다. a ≠ 0이고 n이 자연수일 때 a0 = 1, a−n = 1/an입니다. 유리수 지수는 밑을 양수로 제한합니다. a > 0이고 m이 정수, n이 자연수일 때

am/n = (n√a)m = n√(am)
a−m/n = 1 / am/n

82/3을 두 순서로 계산하면 같습니다. (23)2/3 = 22 = 4이고, ∛(82) = ∛64 = 4입니다. 163/4 = (24)3/4 = 23 = 8입니다. (1/27)−2/3 = 272/3 = (33)2/3 = 32 = 9입니다.

함정: 밑이 음수이면 유리수 지수를 약분하기 전과 후의 값이 달라지거나, 실수가 아닐 수 있습니다. (−8)2/6과 (−8)1/3을 같은 것으로 두지 마세요. 유리수 지수는 밑이 양수일 때만 다룹니다.

수학Ⅰ에서는 이 유리수 지수를 실수 지수까지 넓혀, a > 0이면 ax가 모든 실수 x에서 정의된다고 이해합니다. 그래프는 끊기지 않고 이어진 곡선이 됩니다. 극한으로 지수를 정의하는 과정은 이 과목에서 다루지 않습니다.

2. 지수법칙

a > 0, b > 0이고 지수 m, n이 실수일 때 다음이 성립합니다. 계산은 항상 이 다섯 개로 돌아옵니다.

am · an = am+n
am / an = am−n
(am)n = amn
(ab)n = anbn
(a/b)n = an / bn

같은 밑은 지수를 더하거나 빼고, 거듭제곱의 거듭제곱은 지수를 곱합니다. 밑이 달라도 지수가 같으면 밑끼리 곱하거나 나눕니다.

함정: (am)n과 a(mn)은 다릅니다. 232은 위쪽부터 읽어 29 = 512이고, (23)2 = 82 = 64입니다.

서로 다른 밑은 소수 거듭제곱으로 맞춘 뒤 지수를 비교합니다. 121/2 · 31/2 = (12 · 3)1/2 = 361/2 = 6입니다. 811/4 / 91/2 = (34)1/4 / (32)1/2 = 3 / 3 = 1입니다.

TIP: 복잡한 식은 모든 밑을 가장 작은 소수의 거듭제곱으로 바꾼 뒤, 지수법칙만 적용하세요. 8, 9, 16, 27, 32는 각각 23, 32, 24, 33, 25입니다.

3. 로그의 정의, 성질, 밑의 변환

a > 0, a ≠ 1, M > 0일 때 ax = M을 만족하는 실수 x를 loga M이라고 합니다. a를 밑, M을 진수라고 합니다. 밑은 양수이면서 1이 아니고, 진수는 양수입니다. 이 두 조건이 빠지면 로그는 정의되지 않습니다.

ax = M ⇔ x = loga M
loga 1 = 0,   loga a = 1
loga (ak) = k,   aloga M = M

로그는 지수 방정식의 해를 이름 붙인 것입니다. log2 8 = 3인 이유는 23 = 8이기 때문이고, log2 (1/4) = −2인 이유는 2−2 = 1/4이기 때문입니다.

성질식읽을 때
곱loga(MN) = loga M + loga N곱의 로그는 합
몫loga(M/N) = loga M − loga N몫의 로그는 차
거듭제곱loga(Mk) = k loga M진수의 지수는 앞으로

log2 12 − log2 3 = log2(12/3) = log2 4 = 2입니다. 검산하면 log2 12 = log2(4 · 3) = 2 + log2 3이므로, 여기서 log2 3을 빼면 2가 남습니다.

함정: loga(M + N)은 loga M + loga N이 아닙니다. 합은 진수가 곱해질 때만 나옵니다. (loga M)2과 2 loga M도 다릅니다. 2 loga M = loga(M2)입니다.

밑이 다를 때는 한 밑으로 옮깁니다. c > 0, c ≠ 1이면

loga b = logc b / logc a = 1 / logb a
loga b · logb c = loga c

첫 식은 이렇게 나옵니다. loga b = k라 하면 ak = b입니다. 양변에 logc를 취하면 k logc a = logc b이므로 k = logc b / logc a입니다. 여기에 b와 a를 바꾸면 logb a = 1/k이니, 서로 역수입니다.

예를 들어 log4 8 = log2 8 / log2 4 = 3/2입니다. 43/2 = (22)3/2 = 23 = 8로 맞습니다. log9 27 = log3 27 / log3 9 = 3/2이고, 93/2 = 27입니다. 또 log2 3 · log3 8 = log2 8 = 3입니다.

진수 조건은 식을 간단히 하기 전에 적습니다.

loga f(x)가 보이면 f(x) > 0을 먼저 씁니다. 로그가 여러 개면 각 진수 조건의 공통 범위가 정의역입니다. 풀이 끝에 나온 후보가 이 범위 밖이면 버립니다.

4. 상용로그의 지표와 가수

밑이 10인 로그를 상용로그라고 하고 log N으로 씁니다. 양의 실수 N을 N = m × 10n (1 ≤ m < 10, n은 정수)으로 쓰면

log N = n + log m

n을 지표, log m을 가수라고 합니다. m이 1 이상 10 미만이므로 가수는 0 이상 1 미만입니다. 가수가 같으면 유효숫자가 같습니다. log 2와 log 200은 가수가 같고 지표만 2만큼 다릅니다.

교과서에서 흔히 쓰는 근삿값은 log 2 = 0.3010, log 3 = 0.4771입니다. 그러면 log 5 = log(10/2) = 1 − 0.3010 = 0.6990이고, log 6 = 0.3010 + 0.4771 = 0.7781입니다.

log 600 = log(6 × 102) = 2 + log 6 = 2.7781입니다. 지표는 2, 가수는 0.7781입니다. 600은 세 자리 수이고, 지표에 1을 더한 값과 같습니다.

N ≥ 1이고 log N의 지표가 n이면, N의 정수 부분은 n + 1자리

확인으로 210을 보면 log(210) = 10 × 0.3010 = 3.010입니다. 지표 3이므로 자릿수는 4이고, 실제 210 = 1024도 네 자리입니다. 58은 log(58) = 8 × 0.6990 = 5.592이므로 지표 5, 가수 0.592, 자릿수 6입니다. 52 = 25, 252 = 625, 6252 = 390625로 여섯 자리가 맞습니다.

1보다 작은 양수는 지표가 음수입니다. log 0.02 = log(2 × 10−2) = 0.3010 − 2 = −1.6990입니다. 가수는 0 이상 1 미만으로 다시 맞춥니다.

−1.6990 = −2 + 0.3010
지표 −2, 가수 0.3010
함정: log 0.02를 −2.3010으로 쓰면 안 됩니다. −2.3010 = −(2 + 0.3010)이라 가수가 음수가 되고, 주어진 근삿값으로는 log 0.005에 해당합니다. 음의 로그는 그 값 이하인 정수 가운데 가장 큰 것을 지표로 둡니다. −1.6990의 지표는 −1이 아니라 −2이고, −1.6990 = −2 + 0.3010이므로 가수는 0.3010입니다.
TIP: 자릿수 문제는 log(an) = n log a를 먼저 계산해 지표 n을 읽고, 자릿수는 지표에 1을 더합니다. 로그 값이 정수로 딱 떨어지면, 예를 들어 log 1000 = 3이면 가수는 0이고 자릿수는 4입니다.

5. 지수함수와 로그함수의 그래프

a > 0, a ≠ 1일 때 y = ax를 지수함수, y = loga x를 로그함수라고 합니다. 둘은 서로 역함수이고, 그래프는 직선 y = x에 대하여 대칭입니다.

y = axy = loga x
정의역모든 실수x > 0
치역y > 0모든 실수
항상 지나는 점(0, 1)(1, 0)
점근선x축 (y = 0)y축 (x = 0)
a > 1증가증가
0 < a < 1감소감소

밑이 1보다 크면 x가 커질수록 함숫값도 커집니다. 0과 1 사이면 반대입니다. y = (1/a)x = a−x이므로, y = a−x의 그래프는 y = ax를 y축에 대하여 대칭이동한 것입니다. a > 1이면 y = a−x는 감소합니다. y = −ax는 x축 대칭이라 치역이 음수가 되고, 증가·감소도 반대가 됩니다.

평행이동은 점근선과 지나는 점을 함께 옮깁니다.

식이동점근선지나는 점
y = ax−p + qx축 방향 p, y축 방향 qy = q(p, 1+q)
y = loga(x − p) + qx축 방향 p, y축 방향 qx = p(p+1, q)

p > 0이면 오른쪽, q > 0이면 위입니다. 예를 들어 y = 3x + 1은 점근선이 y = 1이고 (0, 2)를 지납니다. y = 4가 되려면 3x = 3이므로 x = 1, 점 (1, 4)입니다. 역함수는 x = log3(y − 1)에서 변수를 바꾼 y = log3(x − 1)이고, 점근선은 x = 1, 대응점은 (2, 0)과 (4, 1)입니다.

그래프에서 읽는 순서

  1. 밑이 1보다 큰지 작은지를 보아 증가인지 감소인지 정합니다.
  2. 점근선을 긋습니다. 지수함수는 수평선, 로그함수는 수직선입니다.
  3. 함숫값이 쉽게 나오는 점 하나를 찍습니다. a0 = 1, loga 1 = 0을 이용하면 됩니다.
  4. 문제의 점이 곡선 위에 있으면 그 좌표를 식에 넣어 밑이나 평행이동량을 구합니다.
  5. 역함수 그래프가 필요하면 y = x에 대하여 점을 (x, y)에서 (y, x)로 바꿉니다.

정의역을 먼저 칠합니다.

y = log2(x − 1) + 2의 점근선은 x = 1이고 정의역은 x > 1입니다. x = 3이면 log2 2 + 2 = 3이라 점 (3, 3), x = 5이면 log2 4 + 2 = 4라 점 (5, 4)입니다. x절편은 log2(x − 1) = −2에서 x − 1 = 1/4, x = 5/4입니다. y절편은 없습니다. x = 0은 정의역 밖입니다.

6. 방정식·부등식, 역함수, 교점과 직선

지수방정식은 밑을 같게 만들거나, 반복되는 ax를 문자로 바꿉니다.

9x = 27x−1이면 (32)x = (33)x−1이므로 32x = 33x−3입니다. 밑이 같으면 지수가 같아야 하므로 2x = 3x − 3, x = 3입니다. 검산하면 93 = 729, 272 = 729입니다.

2 · 4x − 9 · 2x + 4 = 0은 t = 2x > 0으로 둡니다. 4x = t2이므로 2t2 − 9t + 4 = 0, (2t − 1)(t − 4) = 0입니다. t = 1/2 또는 t = 4입니다. 2x = 2−1이면 x = −1, 2x = 22이면 x = 2입니다. x = −1을 넣으면 2 · (1/4) − 9 · (1/2) + 4 = 0.5 − 4.5 + 4 = 0이고, x = 2이면 32 − 36 + 4 = 0입니다. t가 0 이하로 나오면 버립니다.

로그방정식은 진수 조건을 적은 뒤 한 로그로 모읍니다. log2(x − 1) + log2(x + 1) = 3이면 x − 1 > 0이고 x + 1 > 0이므로 x > 1입니다. log2(x2 − 1) = 3에서 x2 − 1 = 8, x2 = 9, x = 3 또는 x = −3입니다. x > 1이므로 x = 3만 남습니다. log2 2 + log2 4 = 1 + 2 = 3입니다. x = −3은 진수가 음수가 되어 처음부터 정의되지 않습니다.

부등식a > 10 < a < 1
af > agf > gf < g
loga f > loga gf > g (둘 다 양수)f < g (둘 다 양수)

(1/2)x+1 ≥ 4를 풀면, 4 = (1/2)−2입니다. 밑이 1보다 작으므로 부등호가 바뀌어 x + 1 ≤ −2, x ≤ −3입니다. x = −3이면 (1/2)−2 = 4로 등호가 성립하고, x = −4이면 8 ≥ 4입니다. x = −2이면 2 ≥ 4가 되어 탈락합니다.

log1/2(x − 1) ≥ −1이면 진수 조건 x > 1이 먼저입니다. 밑이 1보다 작으므로 부등호가 바뀌어 x − 1 ≤ (1/2)−1 = 2입니다. 따라서 1 < x ≤ 3입니다. x = 3이면 log1/2 2 = −1로 등호, x = 2이면 log1/2 1 = 0으로 참, x = 4이면 진수 3이 2보다 커서 로그 값이 −1보다 작아집니다.

역함수와 교점

y = f(x)와 y = f−1(x)의 그래프는 y = x에 대하여 대칭입니다. 한 그래프 위의 점 (p, q)가 있으면 역함수 그래프에는 (q, p)가 있습니다.

밑이 1보다 크면 더 강한 사실이 있습니다. a > 1일 때 y = ax와 y = loga x의 교점은, 있다면 모두 직선 y = x 위에 있습니다. 교점 (p, q)에서 q = ap이고 p = aq입니다. 만약 p > q이면 밑이 1보다 크므로 ap > aq, 즉 q > p가 되어 모순입니다. q > p도 마찬가지입니다. 따라서 p = q입니다. 교점이 하나도 없을 수도 있으니, 있다는 사실은 식이나 그래프로 확인합니다.

밑이 1보다 작으면 교점이 y = x 밖에 있을 수 있습니다.

1/16 = 2−4이므로 (1/16)1/2 = 2−2 = 1/4, (1/16)1/4 = 2−1 = 1/2입니다. 따라서 log1/16(1/2) = 1/4, log1/16(1/4) = 1/2입니다. 점 (1/2, 1/4)와 (1/4, 1/2)는 두 그래프의 교점인데 y = x 위에 있지 않습니다. 감소함수에는 앞의 증감 비교가 반대로 작용합니다.

f(x) = 2x−2 + 1의 역함수를 구하면 y − 1 = 2x−2, x = log2(y − 1) + 2이므로 f−1(x) = log2(x − 1) + 2입니다. f(2) = 20 + 1 = 2, f(3) = 21 + 1 = 3이고, 역함수도 f−1(2) = 2, f−1(3) = 3입니다. 두 점 (2, 2), (3, 3)은 두 그래프의 교점이고 직선 y = x 위에 있습니다. 밑이 1보다 큰 지수함수를 평행이동해도 증가함수이므로, 이 역함수와의 교점은 y = x 위에서만 찾으면 됩니다.

교점과 넓이

정적분은 수학Ⅰ 범위 밖입니다. 이 과목의 넓이 문제는 교점의 좌표를 구한 뒤, 그 점들을 직선으로 이은 삼각형이나 사각형의 넓이로 계산합니다. 곡선과 곡선 사이의 면적을 적분으로 구하는 문제는 아닙니다.

y = 2x, y = 2−x, y = 2의 교점을 구하면 다음과 같습니다. 2x = 2에서 x = 1, 점 (1, 2). 2−x = 2에서 x = −1, 점 (−1, 2). 2x = 2−x에서 22x = 1, x = 0, 점 (0, 1). 세 점을 꼭짓점으로 하는 삼각형은 밑변의 길이가 2, 높이가 1이므로 넓이는 (1/2) · 2 · 1 = 1입니다.

TIP: 수능형 문항은 보통 세 갈래입니다. 로그 값을 성질과 밑 변환으로 계산하기, 평행이동된 그래프에서 점근선과 점의 좌표를 읽기, 두 그래프의 교점이 어느 직선 위에 있는지 보이기입니다. 식을 풀기 전에 진수 조건과 밑의 대소를 여백에 적고 시작하세요.
③ 확인하기조건이 바뀐 문제로 확인 — 막히면 가장 쉬운 문제부터

자주 나오는 함정

  • log(a + b) = log a + log b로 쓰는 착각. 합으로 갈라지는 것은 진수의 곱입니다.
  • 밑이 1보다 작아도 부등식 방향을 유지하는 착각. 0과 1 사이에서는 지수부등식·로그부등식 모두 방향이 바뀝니다.
  • 진수 조건을 끝에 확인하지 않아 무연근을 답으로 남기는 경우. 로그를 합친 뒤에 나온 근은 다시 대입합니다.
  • 상용로그의 음수 값을 −2.3010처럼 쓰는 경우. 가수는 0 이상 1 미만이라, −1.6990의 지표는 −2이고 가수는 0.3010입니다.
  • (am)n과 a(mn)을 같은 식으로 보는 경우. 거듭제곱 탑은 위쪽부터 계산합니다.
  • 짝수 제곱근에서 n√(an) = a라고 쓰는 경우. 짝수이면 절댓값 |a|입니다.
  • 역함수와의 교점이 언제나 y = x 위라고 외우는 경우. 밑이 1보다 커서 증가함수일 때 성립합니다. 밑이 1보다 작으면 y = x 밖의 교점이 생길 수 있습니다. 밑이 1/16인 예가 본문에 있습니다.
  • 유리수 지수의 밑을 음수로 두는 경우. 실수 범위에서는 밑을 양수로 둡니다.

대표 예제

눌러서 풀이를 펼치세요.

log2 3 = a, log2 5 = b일 때 log6 15를 a, b로 나타내시오.

밑을 2로 통일합니다. log6 15 = log2 15 / log2 6입니다.

분자는 log2(3 · 5) = log2 3 + log2 5 = a + b입니다.

분모는 log2(2 · 3) = log2 2 + log2 3 = 1 + a입니다.

따라서 log6 15 = (a + b) / (1 + a)입니다.

log 2 = 0.3010, log 3 = 0.4771일 때, log 600의 지표와 가수, 그리고 58의 자릿수를 구하시오.

log 5 = 1 − log 2 = 0.6990, log 6 = log 2 + log 3 = 0.7781입니다.

log 600 = log(6 × 100) = 2 + 0.7781 = 2.7781. 지표 2, 가수 0.7781입니다. 600은 3자리로, 지표 + 1과 맞습니다.

log(58) = 8 × 0.6990 = 5.5920. 지표 5이므로 자릿수는 5 + 1 = 6입니다. 실제 58 = 390625입니다.

f(x) = 3x + 1의 그래프에서 점근선, 점 (0, 2)와 y = 4인 점의 좌표를 구하고, 역함수 그래프에서 대응점의 좌표를 구하시오.

3x > 0이므로 점근선은 y = 1입니다. x = 0이면 y = 1 + 1 = 2라 점 (0, 2)를 지납니다.

3x + 1 = 4에서 3x = 3, x = 1. 점 (1, 4)입니다.

y − 1 = 3x에서 x = log3(y − 1)이므로 역함수는 y = log3(x − 1)입니다. 점근선은 x = 1이고, 대응점은 (2, 0), (4, 1)입니다. 원래 점의 좌표를 서로 바꾼 것입니다.

곡선 y = 2x, y = 2−x와 직선 y = 2의 교점 세 개를 꼭짓점으로 하는 삼각형의 넓이를 구하시오.

2x = 2이면 x = 1, 점 (1, 2). 2−x = 2이면 x = −1, 점 (−1, 2). 2x = 2−x이면 22x = 1, x = 0, y = 1, 점 (0, 1)입니다.

세 점 (−1, 2), (1, 2), (0, 1)에서 밑변의 길이는 2, 높이는 1입니다.

넓이 = (1/2) × 2 × 1 = 1입니다. 곡선 사이 면적이 아니라 세 점을 선분으로 이은 삼각형입니다.

한 줄

로그는 “이 밑을 몇 번 곱하면 진수가 되는가”입니다. 지수함수는 (0, 1)을 지나 위로 피하고, 로그함수는 (1, 0)을 지나 옆에서 피합니다. 둘의 그래프는 y = x를 접으면 포개집니다.

  • 밑이 1보다 크면 증가, 1보다 작으면 감소이고 부등식 방향도 같이 바뀝니다.
  • 상용로그는 “10의 몇 제곱인가”이고, 지표에 1을 더하면 1 이상인 수의 자릿수입니다.
  • 교점으로 넓이를 물을 때는 점을 먼저 구하고 직선 도형으로 계산합니다.
고급

풀이 순서는 (1) 정의역·진수 조건 (2) 밑을 같게 만들기 또는 t = ax > 0으로 치환 (3) 나온 근을 조건에 대입 (4) 그래프 문제면 점근선, 증가·감소, 특수점 순으로 읽는 것입니다. 역함수가 보이면 점을 (x, y)에서 (y, x)로 바꾸고, 밑이 1보다 클 때만 교점을 y = x 위에서 찾습니다.

넓이 문항은 교점 좌표를 표로 적은 뒤 밑변과 높이, 또는 사다리꼴로 계산합니다. 곡선으로 둘러싸인 영역의 적분 넓이는 구하지 않습니다.

🗣 말로 설명해 보기
  1. loga(MN) = loga M + loga N이 왜 성립하는지 지수법칙에서 출발해 설명해 보세요.
    내 설명과 비교하기

    loga M = p, loga N = q라 두면 로그의 정의에 따라 ap = M, aq = N입니다. 두 식을 곱하면 지수법칙으로 MN = ap · aq = ap+q이고, 이것을 다시 로그의 정의로 읽으면 loga(MN) = p + q입니다. 즉 곱의 성질은 ‘같은 밑의 곱은 지수를 더한다’를 로그로 옮긴 것입니다. 같은 방법으로 몫은 ap/aq = ap−q에서 차가 되고, 진수의 k제곱은 (ap)k = akp에서 계수 k가 됩니다.

  2. 밑이 1보다 크면 y = ax와 y = loga x의 교점이 왜 직선 y = x 위에만 있는지 말해 보세요.
    내 설명과 비교하기

    교점을 (p, q)라 하면 y = ax 위의 점이므로 q = ap이고, y = loga x 위의 점이므로 q = loga p, 곧 p = aq입니다. 만약 p > q라면 a > 1에서 ax는 증가하므로 ap > aq, 즉 q > p가 되어 모순이고, q > p라고 해도 같은 방법으로 모순입니다. 따라서 p = q이고 교점은 y = x 위에 있습니다. 밑이 1보다 작으면 감소함수라 이 비교가 거꾸로 작용해서, 밑이 1/16일 때처럼 y = x 밖의 교점이 생길 수 있습니다.

책을 덮고 모르는 사람에게 설명하듯 소리 내어 먼저 답해 본 뒤 비교하세요. 막히는 곳이 아직 내 것이 아닌 곳이니, 그 고리만 위 사슬에서 다시 보면 됩니다.
