삼각함수

Part 2 · 수학Ⅰ

호도법·삼각함수의 그래프와 성질·삼각방정식·사인법칙과 코사인법칙

3.0회당 문항 수
10.6점회당 배점
3~3회차별 범위
51최근 17회 누적

수능 2018~2026학년도 + 6·9월 모의평가 17회(2018~2021학년도는 구 교육과정)(510문항) 기준. 문항 본문 키워드로 분류한 값이라 ±1문항 오차가 있을 수 있습니다.

삼각함수는 호의 길이와 넓이, 그래프의 주기와 최댓값, 방정식의 해의 개수, 삼각형에서 법칙을 고르는 문제가 중심입니다. 각은 라디안으로 맞추고, 사분면의 부호를 정한 뒤 기준각의 값을 붙입니다. 도형에서는 주어진 것이 변인지 각인지, 그 각이 끼인각인지에 따라 사인법칙과 코사인법칙이 갈립니다.

논리형

하나만 고른다면삼각함수는 단위원 위 점의 좌표다 — cos θ = x, sin θ = y 하나에서 부호, 관계식, 주기, 그래프가 모두 나온다.

왜 사슬

다음 단계를 먼저 머릿속으로 떠올린 뒤, 가려진 단계를 눌러 맞았는지 확인하세요.

  1. 각을 호의 길이로 잰다(호도법, 180° = π) → 반지름 r, 중심각 θ인 부채꼴의 호 l = rθ와 넓이 S = (1/2)r2θ가 ‘중심각에 비례한다’는 사실 하나에서 나온다
  2. 동경이 단위원과 만나는 점 (x, y)로 정의한다: cos θ = x, sin θ = y, tan θ = y/x → 사분면의 부호는 x, y의 부호이고, 점이 원 위에 있으니 sin2θ + cos2θ = 1
  3. 2π 돌면 같은 점이라 sin·cos의 주기는 2π, π 돌면 점이 (−x, −y)로 가서 y/x가 그대로이므로 tan의 주기는 π
  4. y = a sin(bx + c) + d는 기본 그래프를 늘이고 옮긴 것 → 진폭 |a|, 주기 2π/|b|, 최댓값 |a| + d, 해의 개수는 한 주기 안의 교점 수 × 주기의 개수
  5. 삼각형을 외접원에 넣으면 a = 2R sin A(사인법칙), 좌표로 변의 길이를 재면 a2 = b2 + c2 − 2bc cos A(코사인법칙) → 마주 보는 쌍이면 사인, 끼인각이면 코사인

일반각과 호도법 — 각은 회전량, 단위는 반지름

삼각함수에서 각은 꼭짓점의 벌어진 정도가 아니라 동경이 시초선(양의 x축)에서 얼마나 돌았는가입니다. 시계 반대 방향이 양, 시계 방향이 음이고, 한 바퀴를 더 돌아도 동경의 자리는 같으므로 θ와 θ + 360° × n은 같은 위치입니다. 그래서 420°는 60°와, −150°는 210°와 같은 동경이고 삼각함수 값도 같습니다.

호도법은 각을 호의 길이로 잽니다. 반지름 r인 원에서 호의 길이가 r인 중심각이 1라디안이고, 원 둘레 2πr이 반지름의 2π배이므로 한 바퀴가 2π, 반 바퀴 180°가 π입니다. 따라서 θ(라디안) = θ(도) × π/180이고, 30° = π/6, 60° = π/3, 210° = 7π/6입니다.

라디안을 쓰면 부채꼴 공식이 단순해집니다. 호의 길이는 중심각에 비례하고 1라디안마다 r이므로 l = rθ, 넓이는 원 전체 πr²의 θ/(2π)이므로 S = (1/2)r²θ = (1/2)rl입니다. 반지름 6, 중심각 π/3이면 l = 2π, S = 6π이고, 60을 그대로 넣어 l = 360이라고 하는 실수는 θ가 라디안이라는 전제를 잊은 것입니다.

삼각함수는 단위원 위 점의 좌표

예각의 삼각비는 직각삼각형이 있어야 정의되므로, 120°나 −30°에도 쓰려면 정의를 넓혀야 합니다. 그래서 단위원(원점이 중심, 반지름 1)에서 각 θ의 동경이 만나는 점을 (x, y)라 하고 cos θ = x, sin θ = y, tan θ = y/x로 정합니다. 예각이면 원래 삼각비와 같고, x = 0인 θ = π/2 + nπ에서는 tan θ가 정의되지 않습니다.

공식은 이 정의에서 저절로 나옵니다. 점이 단위원 위에 있으니 x² + y² = 1, 곧 sin²θ + cos²θ = 1이고, 양변을 cos²θ로 나누면 1 + tan²θ = 1/cos²θ입니다. 부호는 좌표의 부호라 제1사분면은 모두 양수, 제2사분면은 sin만, 제3사분면은 tan만, 제4사분면은 cos만 양수이며, sin θ = 3/5인 제2사분면의 θ는 cos θ = −4/5, tan θ = −3/4입니다.

각을 바꾼 값도 점의 대칭으로 읽습니다. π − θ는 점을 y축에 대칭시킨 (−x, y)라 sin은 그대로이고 cos는 부호가 바뀌며, π + θ는 (−x, −y), −θ는 (x, −y)라서 sin(−θ) = −sin θ, cos(−θ) = cos θ이고, π/2 − θ는 x와 y가 바뀌어 sin(π/2 − θ) = cos θ입니다. 값은 각을 0 이상 2π 미만으로 → 사분면으로 부호 → 기준각의 값 순서로 구해, sin 210° = −1/2(제3사분면, 기준각 30°)입니다.

그래프 — 주기·진폭·최댓값은 식의 어느 자리에서 오나

점이 한 바퀴 돌면 같은 좌표로 돌아오므로 y = sin x와 y = cos x의 주기는 2π입니다. tan는 반 바퀴만 돌아도 점이 (−x, −y)가 되어 비 y/x가 같으므로 주기가 π이고, x좌표가 0인 x = π/2 + nπ가 점근선입니다. 또 각에 π/2를 더하면 점 (x, y)가 (−y, x)로 가므로 cos x = sin(x + π/2), 곧 코사인 그래프는 사인 그래프를 왼쪽으로 π/2 옮긴 모양입니다.

y = a sin(bx + c) + d에서 sin 값은 −1과 1 사이이므로 a를 곱하면 폭이 |a|배가 되고 d를 더하면 그만큼 올라가, 최댓값 |a| + d, 최솟값 −|a| + d입니다. bx가 2π만큼 변하려면 x는 2π/|b|만 변하면 되므로 주기는 2π/|b|(tan는 π/|b|)이고, 괄호를 b(x − p) 꼴로 묶어야 좌우 이동량 p가 보입니다. y = 2 sin(2x − π/3) + 1은 2(x − π/6)이라 오른쪽으로 π/6, 주기 π, 최댓값 3, 최솟값 −1입니다.

y = −2 cos x + 3은 cos x = −1인 x = π에서 최댓값 5, cos x = 1에서 최솟값 1입니다. 최댓값을 −2 + 3 = 1로 쓰는 실수는 진폭이 언제나 |a|라는 것을 놓친 것이고, a가 음수이면 산과 골의 위치만 바뀝니다.

삼각방정식과 부등식 — 수평선이 곡선을 몇 번 자르나

sin x = k의 해는 곡선 y = sin x와 수평선 y = k의 교점이라, |k| > 1이면 해가 없고 |k| < 1이면 한 주기에 두 번 만납니다. 두 해는 단위원에서 y좌표가 같은 두 점, 곧 α와 π − α이므로 0 ≤ x < 2π에서 sin x = √3/2의 해는 π/3, 2π/3입니다. 같은 방식으로 cos x = −1/2는 x좌표가 같은 2π/3, 4π/3이고, tan x = 1은 주기가 π라 π/4, 5π/4입니다.

괄호 안이 bx이면 그 전체를 한 문자로 봅니다. 0 ≤ x < 2π에서 sin 2x = 1/2은 t = 2x의 범위가 0 ≤ t < 4π로 두 배가 되므로 t = π/6, 5π/6, 13π/6, 17π/6, 곧 x = π/12, 5π/12, 13π/12, 17π/12의 네 개입니다. 일반적으로 양의 정수 b에 대해 sin bx = k(|k| < 1)의 해는 2b개이고, t의 범위를 늘리지 않으면 뒤쪽 해를 놓칩니다.

부등식은 같은 그림에서 곡선이 수평선보다 위(또는 아래)인 구간을 읽습니다. 0 ≤ x < 2π에서 sin x ≥ 1/2은 π/6 ≤ x ≤ 5π/6, cos x < −1/2은 2π/3 < x < 4π/3이고, 등호가 있을 때만 경계를 넣습니다. 즉 방정식의 해가 부등식의 경계이므로 경계를 먼저 구한 뒤 사이의 점 하나로 참인지 확인합니다.

사인법칙과 넓이 — 외접원 하나로 묶인다

삼각형 ABC의 외접원에 B를 지나는 지름 BA′을 그으면, 같은 호 위의 원주각이라 ∠BA′C = ∠A이고 지름에 대한 원주각이라 ∠BCA′ = 90°입니다. 직각삼각형 A′BC에서 a = 2R sin A이므로 a/sin A = b/sin B = c/sin C = 2R이고, A가 둔각이면 ∠BA′C = 180° − A이지만 sin 값이 같아 그대로 성립합니다.

넓이는 높이에서 나옵니다. 변 AB를 밑변으로 보면 C에서 내린 높이가 b sin A이므로 S = (1/2)bc sin A이고, 쓰는 각은 두 변의 끼인각이며 둔각이어도 sin 값이 양수라 넓이도 양수입니다. 사인법칙의 sin A = a/(2R)를 넣으면 S = abc/(4R)이라, 넓이와 외접원을 두 식으로 서로 검산할 수 있습니다.

코사인법칙 — 좌표로 거리를 재면 나온다

A를 원점, B를 (c, 0)에 두면 단위원 정의에 따라 C는 (b cos A, b sin A)입니다. B와 C 사이 거리의 제곱은 (b cos A − c)² + (b sin A)² = b²(cos²A + sin²A) − 2bc cos A + c²이므로 a² = b² + c² − 2bc cos A이고, A = 90°이면 피타고라스 정리가 됩니다. 코사인법칙은 그 정리를 모든 각으로 넓힌 것입니다.

cos A = (b² + c² − a²)/(2bc)로 바꾸면 각의 종류가 부호로 보여, a²이 b² + c²보다 크면 cos A < 0이라 둔각, 같으면 직각, 작으면 예각입니다. a = 4, b = 3, c = 2이면 cos A = (9 + 4 − 16)/12 = −1/4로 둔각이고, sin A = √15/4, 넓이 3√15/4, 외접원의 반지름 R = a/(2 sin A) = 8√15/15입니다.

법칙 고르기와 교점의 개수 — 주어진 것이 길을 정한다

삼각형 문항은 주어진 자료의 종류가 법칙을 정합니다. 두 각과 한 변이면 사인법칙, 두 변과 끼인각이면 코사인법칙과 넓이 (1/2)bc sin A, 세 변이면 코사인법칙으로 각을 구합니다. 두 변과 끼인각이 아닌 각이면 사인법칙으로 sin B를 구하는데, 이때 B와 180° − B가 모두 후보입니다.

A = 30°, a = √2, b = 2이면 sin B = 2 · (1/2)/√2 = 1/√2라 B = 45° 또는 135°이고, C가 105°, 15°로 두 삼각형이 모두 가능합니다. 각의 합이 180°를 넘는 후보만 버리고 해가 하나라고 단정하지 않습니다. 그래프 교점 문항은 한 주기 안의 교점 수에 주기가 들어가는 횟수를 곱해 세며, 0 ≤ x < 2π에서 |sin 2x| = 1/2은 sin 2x = ±1/2의 해 4개씩을 더해 8개입니다.

외울 것은 이것뿐단위원 정의(cos θ = x, sin θ = y), 특수각 π/6·π/4·π/3의 값, 사인법칙 a/sin A = 2R과 코사인법칙

나머지는 유도부채꼴의 호와 넓이, 사분면 부호, sin2θ + cos2θ = 1과 1 + tan2θ = 1/cos2θ, π ± θ 변환, 주기·최댓값·최솟값, 해의 개수, 넓이 (1/2)bc sin A와 abc/(4R)

논리형 함정공식이 다 유도되니 그래프를 그리지 않고 식만으로 해를 세다가 치환한 변수의 범위를 늘리지 않는 실수를 합니다. 0 ≤ x < 2π에서 sin 2x = k를 풀 때 t = 2x의 범위는 0 ≤ t < 4π입니다.

🗣 말로 설명해 보기
  1. tan의 주기가 sin, cos와 달리 π인 이유를 단위원 위의 점으로 설명해 보세요.
    내 설명과 비교하기

    각 θ의 동경이 단위원과 만나는 점을 (x, y)라 하면 cos θ = x, sin θ = y, tan θ = y/x입니다. 각을 π만큼 더 돌리면 동경이 정반대 방향을 가리키므로 만나는 점은 원점에 대해 대칭인 (−x, −y)가 됩니다. 이때 sin과 cos는 각각 −y, −x로 부호가 바뀌므로 처음 값으로 돌아오려면 2π를 돌아야 하지만, tan은 (−y)/(−x) = y/x로 값이 그대로입니다. 그래서 tan은 반 바퀴마다 같은 값이 반복되어 주기가 π입니다.

  2. 두 변과 끼인각이 아닌 한 각이 주어지면 왜 삼각형이 두 개 나올 수 있는지 말해 보세요.
    내 설명과 비교하기

    한 각 A와 그 마주 보는 변 a, 다른 변 b가 주어지면 사인법칙으로 sin B = b sin A / a를 구합니다. 그런데 sin(180° − B) = sin B라서 sin 값 하나에 예각 B와 둔각 180° − B 두 각이 대응합니다. 두 후보 모두 A와의 합이 180°보다 작으면 각각 삼각형이 되므로 두 후보를 모두 각의 합으로 검사해야 합니다. 예를 들어 A = 30°, a = √2, b = 2이면 sin B = √2/2라서 B = 45°와 B = 135°가 둘 다 가능하고 삼각형이 두 개입니다.

책을 덮고 모르는 사람에게 설명하듯 소리 내어 먼저 답해 본 뒤 비교하세요. 막히는 곳이 아직 내 것이 아닌 곳이니, 그 고리만 위 사슬에서 다시 보면 됩니다.

문제부터 부딪치고 싶다면 대표 예제를 먼저 풀고, 막힌 고리만 사슬에서 찾아 채우세요.

✅ 이 파트 끝내기

암기형

특수각 표, 사분면 부호표, π ± θ 변환표를 가리고 빈칸 채우기로 반복하세요.

암기형에게 이 과목은 — 공식과 풀이 순서를 확실히 쌓으면 앞번호 2·3점 문항이 안정됩니다. 다만 수학은 공식을 ‘언제 쓸 수 있는가’가 관건이라 쓸 수 있는 조건까지 함께 외우세요.

시각형

단위원에 각을 그려 점의 좌표로 sin·cos를 읽고, 그래프는 한 주기의 다섯 점을 먼저 찍어 그리세요.

시각형에게 이 과목은 — 수학은 그래프 한 장이 식 여러 줄을 대신하는 과목이라 시각형에게 잘 맞습니다. 식을 보면 그래프부터 그리는 습관이 관건입니다.

실전형

해의 개수 문항과 사인·코사인법칙 도형 문항을 각각 모아 시간을 재며 반복하세요.

1. 일반각과 호도법, 부채꼴

반직선이 한 점(꼭짓점)을 중심으로 회전한 양을 각이라고 합니다. 시작 위치를 시초선이라 하고, 보통 좌표평면에서는 원점과 양의 x축 방향을 시초선으로 둡니다. 회전한 뒤의 반직선을 동경이라고 합니다. 시계 반대 방향을 양의 각, 시계 방향을 음의 각으로 둡니다.

동경의 위치만 보면 360°를 더하거나 빼도 같은 자리입니다. 라디안으로는 2π만큼입니다. 그래서 θ와 θ + 2nπ (n은 정수)는 같은 동경을 나타냅니다. 420°는 420 − 360 = 60°와 같고, sin 420° = sin 60° = √3 / 2입니다. −150°에 360°를 더하면 210°이므로 −150°와 210°는 같은 동경입니다.

각의 크기를 호의 길이로 재는 방법이 호도법입니다. 반지름 r인 원에서 호의 길이가 r이면 그 중심각을 1라디안이라고 합니다. 반원의 호는 πr이므로 180° = π 라디안입니다.

θ(라디안) = θ(도) × π / 180
θ(도) = θ(라디안) × 180 / π

자주 쓰는 대응은 30° = π/6, 45° = π/4, 60° = π/3, 90° = π/2, 180° = π, 360° = 2π입니다. 210° = 210π/180 = 7π/6입니다.

반지름 r, 중심각 θ(라디안)인 부채꼴에서 호의 길이와 넓이는 다음과 같습니다.

호의 길이 l = rθ
넓이 S = (1/2)r2θ = (1/2)rl

반지름 6, 중심각 60° = π/3이면 l = 6 · π/3 = 2π, S = (1/2) · 36 · π/3 = 6π입니다. (1/2) · r · l = (1/2) · 6 · 2π = 6π로 같습니다. 도 단위로 검산하면 전체 원에서 60/360 = 1/6이므로 호의 길이는 2πr · (1/6) = 2π, 넓이는 πr2 · (1/6) = 6π입니다.

함정: l = rθ, S = (1/2)r2θ에 넣는 θ는 라디안입니다. 60을 그대로 넣어 6 × 60 = 360이라고 하면 안 됩니다. 도가 주어지면 π/180을 먼저 곱하세요.
TIP: 넓이 공식 두 개가 같다는 것은 S = (1/2)rl에서 바로 보입니다. 호와 반지름을 알았으면 각을 다시 구하지 않아도 넓이가 나옵니다.

2. 삼각함수의 정의, 부호, 관계

원점을 중심으로 반지름이 1인 원을 단위원이라고 합니다. 일반각 θ의 동경이 단위원과 만나는 점을 (x, y)라고 하면

cos θ = x,   sin θ = y,   tan θ = y/x (x ≠ 0)

tan θ는 만나는 점의 x좌표가 0일 때, 곧 θ = π/2 + nπ일 때 정의되지 않습니다. 단위원 위의 점이므로 항상 다음이 성립합니다.

sin2θ + cos2θ = 1
tan θ = sin θ / cos θ (cos θ ≠ 0)
1 + tan2θ = 1 / cos2θ

마지막 식은 sin2θ + cos2θ = 1의 양변을 cos2θ로 나눈 것입니다. sin θ = 3/5이고 θ가 제2사분면이면 cos θ는 음수입니다. cos2θ = 1 − 9/25 = 16/25이므로 cos θ = −4/5, tan θ = (3/5)/(−4/5) = −3/4입니다. 9/25 + 16/25 = 1로 맞습니다.

3. 그래프, 주기, 진폭, 평행이동과 최대·최소

y = sin x는 원점을 지나고, x = π/2에서 1, x = 3π/2에서 −1이 됩니다. x절편은 nπ입니다. y = cos x는 (0, 1)을 지나고 x절편은 π/2 + nπ입니다. y = tan x는 원점을 지나며 x = π/2 + nπ를 점근선으로 하고, 각 구간에서 증가합니다.

sin, cos의 기본 주기: 2π
tan의 기본 주기: π

y = a sin(bx + c) + d (b ≠ 0)를 읽을 때는 괄호를 b로 묶어 b(x − p) 꼴로 만듭니다.

y = −2 cos x + 3이면 진폭은 2, 주기는 2π입니다. cos x = −1일 때 y = −2 · (−1) + 3 = 5가 최댓값이고, cos x = 1일 때 y = 1이 최솟값입니다. 최댓값이 되는 한 점은 x = π입니다. a가 음수여도 진폭은 |a|이고, 최댓값은 |a| + d입니다.

y = 2 sin(2x − π/3) + 1은 2x − π/3 = 2(x − π/6)이므로 오른쪽으로 π/6만큼 이동합니다. 진폭 2, 주기 2π/2 = π, 위로 1입니다. 최댓값은 3, 최솟값은 −1입니다.

y = sin(x − π/3) + 1은 오른쪽 π/3, 위 1만큼의 이동입니다. 점 (π/3, 1)을 지나고 최댓값 2, 최솟값 0, 주기 2π입니다.

그래프에서 읽는 순서

  1. 축의 눈금이 도인지 라디안인지 확인합니다. 수능 그래프의 눈금은 π/2, π처럼 라디안입니다.
  2. |a|로 위아래 폭, |b|로 한 바퀴의 길이를 정합니다. b의 절댓값이 크면 주기가 짧아져 같은 구간에 파동이 더 많이 들어옵니다.
  3. 괄호 안을 묶어 좌우 이동량을 읽고, 마지막 상수로 위아래 이동을 읽습니다.
  4. 최댓값은 |a| + d, 최솟값은 −|a| + d입니다. a가 음수이면 산과 골짜기의 위치가 바뀝니다.
  5. 점근선이 있는 tan는 주기를 π/|b|로 자르고, 잘린 구간마다 한 번씩 증가하는 곡선으로 봅니다.

한 주기만 정확히 그리면 나머지가 따라옵니다.

sin은 0에서 시작해 1, 0, −1, 0으로 한 주기를 마칩니다. cos는 1에서 시작해 0, −1, 0, 1입니다. 평행이동한 뒤에는 이 다섯 점을 이동량만큼 옮겨 찍으면 개형이 정해집니다.

4. 삼각방정식과 부등식

sin x = k는 |k| > 1이면 해가 없고, |k| = 1이면 한 주기에 한 번, |k| < 1이면 한 주기에 두 번 만납니다. cos도 같습니다. tan x = k는 점근선 사이의 각 구간마다 정확히 한 번 만납니다. k가 어떤 실수여도 됩니다.

sin x = sin α ⇒ x = nπ + (−1)n α
cos x = cos α ⇒ x = 2nπ ± α
tan x = tan α ⇒ x = nπ + α

0 ≤ x < 2π에서 sin x = √3 / 2이면 x = π/3, 2π/3입니다. 일반해는 x = nπ + (−1)n(π/3)입니다. n = 0이면 π/3, n = 1이면 π − π/3 = 2π/3, n = 2이면 2π + π/3으로 이어집니다.

cos x = −1/2이면 0 ≤ x < 2π에서 x = 2π/3, 4π/3이고, 일반해는 x = 2nπ ± 2π/3입니다. tan x = 1이면 x = π/4, 5π/4이고, 일반해는 x = nπ + π/4입니다. 5π/4 = π + π/4이므로 주기를 π로 더하면 됩니다. 3π/4는 tan가 −1인 각이라 넣으면 안 됩니다.

계수가 붙은 방정식은 괄호 안 전체를 한 문자로 봅니다. 0 ≤ x < 2π에서 sin 2x = 1/2이면 t = 2x로 둘 때 0 ≤ t < 4π입니다. t = π/6, 5π/6, 그리고 2π를 더한 13π/6, 17π/6입니다. 따라서 x = π/12, 5π/12, 13π/12, 17π/12로 네 개입니다. 양의 정수 b에 대해 0 ≤ x < 2π에서 sin(bx) = k (|k| < 1)의 해는 2b개입니다. b = 1이면 2개, b = 2이면 4개, b = 3이면 6개입니다.

부등식은 그 구간의 그래프에 수평선 y = k를 그어, 곡선이 직선 위에 있는 구간을 읽습니다. 등호가 있으면 교점을 포함하고, 없으면 빼니다.

0 ≤ x < 2π에서 sin x ≥ 1/2인 구간은 π/6 ≤ x ≤ 5π/6입니다. cos x < −1/2이면, cos x = −1/2인 점이 2π/3과 4π/3이므로 2π/3 < x < 4π/3입니다. x = π에서 cos x = −1로 참이고, x = 2π/3에서는 등호라서 부등호가 순수하게 작다면 포함하지 않습니다.

함정: 일반해를 쓸 때 sin의 주기를 2π로만 더하면, π − α 쪽 해가 빠집니다. sin은 nπ + (−1)n α, tan은 주기가 π입니다. 또 해의 범위를 구할 때 t = 2x처럼 치환했다면 t의 범위가 두 배가 됩니다.

5. 사인법칙, 코사인법칙, 넓이와 외접원

삼각형 ABC에서 각 A, B, C의 마주 보는 변을 a, b, c라고 하고, 외접원의 반지름을 R이라고 합니다.

a / sin A = b / sin B = c / sin C = 2R
a2 = b2 + c2 − 2bc cos A
cos A = (b2 + c2 − a2) / (2bc)
S = (1/2)bc sin A

넓이에서 두 변은 그 끼인각을 사이에 둔 변입니다. 각 C를 쓸 때는 S = (1/2)ab sin C입니다. sin은 둔각에서도 양수이므로, 각이 둔각이어도 넓이 공식의 sin 값 자체는 양수로 넣습니다.

A = 30°, B = 60°, C = 90°, a = 3이면 a / sin A = 3 / (1/2) = 6 = 2R이므로 R = 3입니다. b = 6 sin 60° = 6 · √3 / 2 = 3√3, c = 6 sin 90° = 6입니다. 32 + (3√3)2 = 9 + 27 = 36 = 62이라 피타고라스 정리와도 맞습니다. 직각삼각형의 외심은 빗변의 중점이므로 R은 빗변의 절반인 3입니다. 넓이 S = (1/2) · 3 · 3√3 · sin 90° = 9√3 / 2입니다.

코사인법칙에서 cos A의 부호가 각의 종류를 정합니다. a2이 b2 + c2보다 작으면 예각, 같으면 직각, 크면 둔각입니다. a = 4, b = 3, c = 2이면 가장 긴 변은 a입니다.

cos A = (9 + 4 − 16) / (2 · 3 · 2) = −3/12 = −1/4

cos A < 0이므로 각 A는 둔각입니다. sin A = √(1 − (−1/4)2) = √(15/16) = √15 / 4입니다. 둔각의 사인은 양수입니다. 넓이 S = (1/2) · 3 · 2 · √15 / 4 = 3√15 / 4입니다. R = a / (2 sin A) = 4 / (2 · √15 / 4) = 8/√15 = 8√15 / 15입니다. 검산으로 S = abc / (4R)을 쓰면, a = 2R sin A를 S = (1/2)bc sin A에 넣은 식입니다. 4 · 3 · 2 / (4 · 8/√15) = 24 · √15 / 32 = 3√15 / 4로 넓이와 같습니다.

abc / (4R)은 외운 식보다 유도가 안전합니다.

사인법칙에서 sin A = a / (2R)입니다. 이것을 S = (1/2)bc sin A에 넣으면 S = abc / (4R)이 됩니다. 두 식으로 같은 넓이가 나오면 계산이 맞은 것입니다.

두 변과 끼인각이 아닌 각사인법칙마주 보는 각이 예각·둔각 두 가지일 수 있음

마지막 경우는 한 각 A와 그 마주 보는 변 a, 그리고 다른 변 b가 주어진 상황입니다. sin B = b sin A / a를 구한 뒤 B와 180° − B를 둘 다 검사합니다. 각의 합이 180°를 넘으면 그 후보는 버립니다.

A = 30°, a = √2, b = 2이면 sin B = 2 · sin 30° / √2 = 2 · (1/2) / √2 = 1/√2입니다. 따라서 B = 45° 또는 B = 135°입니다. B = 45°이면 C = 105°, B = 135°이면 C = 15°로 둘 다 삼각형이 됩니다. 각 A가 예각이고, 변 a가 b sin A = 1보다 크면서 b = 2보다 작기 때문입니다. 해가 하나뿐이라고 단정하면 하나가 빠집니다.

그래프의 교점 개수는 한 주기 안의 횟수에, 주어진 구간에 주기가 몇 번 들어가는지를 곱합니다. 0 ≤ x < 2π에서 y = cos x와 y = 1/2의 교점은 x = π/3, 5π/3로 2개입니다. 같은 구간에서 y = sin 2x와 y = 1/2의 교점은 앞 절에서 센 4개입니다. |sin 2x| = 1/2처럼 절댓값이 붙으면 sin 2x = 1/2과 sin 2x = −1/2를 따로 세어 8개가 됩니다. t = 2x의 범위가 0 이상 4π 미만이고, 그 안에 각 방정식의 해가 4개씩이기 때문입니다.

TIP: 도형 문항은 그림에 주어진 각과 변을 표시한 뒤, 끼인각이 있으면 코사인, 마주 보는 각과 변의 쌍이 있으면 사인으로 시작합니다. 그래프 문항은 주기를 먼저 구하고, 그 주기 칸 안에 수평선이 곡선을 몇 번 지나는지 센 다음 칸 수를 곱합니다.

자주 나오는 함정

  • 호도법 공식에 도 단위 각을 그대로 넣는 경우. l = rθ의 θ는 라디안입니다.
  • sin과 tan의 주기를 둘 다 2π로 두는 경우. tan의 주기는 π입니다.
  • y = −2 cos x + 3의 최댓값을 −2 + 3 = 1로 쓰는 경우. 진폭은 |−2| = 2이고 최댓값은 5입니다.
  • 제2사분면에서 cos를 양수로 두는 경우. 제2사분면은 sin만 양수입니다.
  • 코사인법칙의 부호를 반대로 쓰는 경우. 둔각이면 cos가 음수이고, 마주 보는 변의 제곱은 다른 두 변의 제곱의 합보다 큽니다.
  • 끼인각이 아닌 두 변과 한 각에서 예각 해만 답으로 쓰는 경우. 180°에서 그 각을 뺀 값도 각의 합을 통과하면 답입니다.
  • 둔각의 sin을 음수로 넣어 넓이가 음수가 되는 경우. 넓이 공식의 sin은 양수입니다.
  • sin x = 2처럼 |k| > 1인 방정식에 해가 있다고 보는 경우. 사인·코사인의 범위는 −1 이상 1 이하입니다.

대표 예제

눌러서 풀이를 펼치세요.

반지름이 10이고 중심각이 2라디안인 부채꼴의 호의 길이와 넓이를 구하시오.

각이 이미 라디안이므로 공식에 바로 넣습니다.

l = rθ = 10 × 2 = 20.

S = (1/2)r2θ = (1/2) × 100 × 2 = 100.

검산: (1/2)rl = (1/2) × 10 × 20 = 100. 도를 360으로 나누는 식은 쓰지 않습니다.

sin θ = 3/5이고 θ가 제2사분면의 각일 때 cos θ와 tan θ를 구하시오.

sin2θ + cos2θ = 1에서 cos2θ = 1 − 9/25 = 16/25입니다.

제2사분면이므로 cos θ < 0. 따라서 cos θ = −4/5.

tan θ = sin θ / cos θ = (3/5) / (−4/5) = −3/4.

9/25 + 16/25 = 1로 맞습니다.

0 ≤ x < 2π에서 방정식 sin 2x = 1/2의 해를 모두 구하고 개수를 말하시오.

t = 2x로 두면 0 ≤ t < 4π이고 sin t = 1/2입니다.

t = π/6, 5π/6, 13π/6, 17π/6.

x = t/2이므로 x = π/12, 5π/12, 13π/12, 17π/12의 4개입니다.

양의 정수 b = 2이고 |k| < 1이므로 해의 개수 2b = 4와 일치합니다.

두 변의 길이가 5, 7이고 그 끼인각이 60°일 때, 끼인각의 마주 보는 변의 길이, 삼각형의 넓이, 외접원의 반지름을 구하시오.

a2 = 52 + 72 − 2 · 5 · 7 · cos 60° = 25 + 49 − 70 · (1/2) = 74 − 35 = 39.

마주 보는 변은 √39입니다.

S = (1/2) · 5 · 7 · sin 60° = (35/2) · (√3 / 2) = 35√3 / 4.

2R = a / sin A이므로 R = √39 / (2 · √3 / 2) = √39 / √3 = √13.

검산: abc / (4R) = 5 · 7 · √39 / (4√13) = 35√3 / 4. 넓이와 같습니다.

한 줄

단위원에서 가로좌표가 코사인, 세로좌표가 사인입니다. 사인은 한 바퀴(2π)마다, 탄젠트는 반 바퀴(π)마다 같은 모양이 반복됩니다. 삼각형은 마주 보는 쌍이 보이면 사인, 끼인각이 보이면 코사인입니다.

  • 부채꼴 공식의 각은 라디안입니다.
  • 최댓값은 진폭의 절댓값에 위아래 이동을 더한 값입니다.
  • 넓이 (1/2)ab sin C에서 sin은 둔각이어도 양수입니다.
고급

그래프 문항은 주기를 구한 뒤 한 주기 칸에 수평선이 몇 번 닿는지 세고, 구간에 칸이 몇 개인지 곱합니다. 치환 t = bx를 했으면 t의 범위를 먼저 늘려 적습니다. 방정식의 일반해는 sin, cos, tan의 주기 공식을 섞지 않고 함수마다 따로 씁니다.

도형 문항은 (1) 그림에 변·각 표시 (2) 끼인각이면 코사인, 마주 보는 쌍이면 사인 (3) 끼인각이 아닌 경우에는 예각·둔각 두 후보를 각의 합으로 검사 (4) 넓이와 R을 서로 다른 식으로 한 번 더 계산해 검산하는 순서입니다.
