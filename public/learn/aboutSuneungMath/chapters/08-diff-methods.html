여러 가지 미분법

Part 8 · 미적분

지수·로그함수·삼각함수의 극한과 미분·몫·합성·역함수·음함수·매개변수 미분·도함수의 활용

3.9회당 문항 수
12.7점회당 배점
2~6회차별 범위
66최근 17회 누적

수능 2018~2026학년도 + 6·9월 모의평가 17회(2018~2021학년도는 구 교육과정)(510문항) 기준. 문항 본문 키워드로 분류한 값이라 ±1문항 오차가 있을 수 있습니다.

수학Ⅱ의 다항함수 미분 위에, 지수·로그·삼각함수와 합성·역함수·음함수·매개변수가 올라갑니다. 수능은 공식 암기보다 그래프에서 기울기를 읽어 합성·역함수의 미분계수를 묻고, 접선의 기울기 조건, 극값의 개수, 변곡점에서 볼록이 바뀌는지를 묻습니다. 각의 단위는 라디안입니다. 이 약속이 어긋나면 sin x / x의 극한부터 무너집니다.

1. 지수함수와 로그함수의 극한

e는 수열 (1 + 1/n)n의 극한으로 정의합니다. 이항정리로 전개하면

(1 + 1/n)n = Σk=0n (1/k!) · (1 · (1 − 1/n) · … · (1 − (k−1)/n))

각 곱의 인수는 n이 커지면 커지고, 더해지는 양의 항도 늘어나므로 이 수열은 증가합니다. 또 k ≥ 1이면 k! = 1·2·3·…·k ≥ 2k−1이므로 1/k! ≤ 1/2k−1입니다. 따라서 수열은 1 + Σ 1/2k−1 < 1 + 2 = 3보다 작습니다. 증가하고 위로 유계이므로 단조수렴정리에 의해 수렴하고, 그 극한을 e라고 합니다. 2 < e < 3이고, 값은 약 2.718입니다.

실수 변수로 확장한 표준 극한은 다음입니다. a > 0, a ≠ 1입니다.

limx→0 (1 + x)1/x = e
limx→∞ (1 + a/x)x = ea
limx→0 ln(1 + x) / x = 1
limx→0 (ex − 1) / x = 1
limx→0 (ax − 1) / x = ln a
limx→0 loga(1 + x) / x = 1 / ln a

세 번째에서 네 번째로 가는 길은 치환입니다. ex − 1 = t로 두면 x → 0일 때 t → 0이고 x = ln(1+t)이므로 (ex − 1)/x = t / ln(1+t) = 1 / (ln(1+t)/t) → 1입니다. ln은 밑이 e인 로그이고, 지수함수 ex의 역함수입니다.

TIP: 꼴을 표준 극한으로 맞춥니다. (e2x − 1)/x = 2 · (e2x − 1)/(2x) → 2. ln(1+3x)/x = 3 · ln(1+3x)/(3x) → 3입니다. 속 표현 전체를 분모에 만들고, 앞에 남는 상수를 적습니다.

ax는 ex ln a로 읽어 둡니다. 미분할 때 이 표현이 그대로 쓰입니다. 정의역은 지수함수가 실수 전체, 로그함수가 양수입니다.

2. 삼각함수의 덧셈정리와 극한

각은 라디안입니다. sin, cos, tan의 그래프와 주기, sin²x + cos²x = 1은 수학Ⅰ의 내용이고, 미적분에서는 덧셈과 극한, 도함수로 넘어갑니다.

sin(α+β) = sin α cos β + cos α sin β
sin(α−β) = sin α cos β − cos α sin β
cos(α+β) = cos α cos β − sin α sin β
cos(α−β) = cos α cos β + sin α sin β
tan(α+β) = (tan α + tan β) / (1 − tan α tan β)
tan(α−β) = (tan α − tan β) / (1 + tan α tan β)

tan의 분모가 0이면 그 각에서는 정리를 쓰지 않습니다. β = α를 넣으면 배각공식입니다.

sin 2α = 2 sin α cos α
cos 2α = cos²α − sin²α = 2cos²α − 1 = 1 − 2sin²α
tan 2α = 2 tan α / (1 − tan²α)

제곱을 낮추는 꼴은 적분에서 바로 쓰입니다. cos 2α = 1 − 2sin²α에서 sin²α = (1 − cos 2α)/2, cos 2α = 2cos²α − 1에서 cos²α = (1 + cos 2α)/2입니다.

a sin x + b cos x는 진폭 √(a² + b²)의 사인으로 모읍니다. R = √(a² + b²), cos φ = a/R, sin φ = b/R라 두면

a sin x + b cos x = R sin(x + φ)

예를 들어 sin x + cos x = √2 sin(x + π/4)입니다. 최댓값은 √2, 최솟값은 −√2입니다.

삼각함수의 극한

limx→0 (sin x) / x = 1
limx→0 (tan x) / x = 1
limx→0 (1 − cos x) / x = 0
limx→0 (1 − cos x) / x² = 1/2

마지막은 배각으로 확인합니다. 1 − cos x = 2 sin²(x/2)이므로 (1 − cos x)/x² = (1/2) [sin(x/2) / (x/2)]² → 1/2입니다. 상수배는 속으로 넣습니다.

limx→0 sin(kx) / x = k
limx→0 tan(kx) / x = k
limx→0 (1 − cos(kx)) / x² = k² / 2
함정: 각을 도로 재면 sin x / x는 1이 아닙니다. 수능과 교과서의 삼각함수 미분은 모두 라디안입니다. 1°는 π/180라디안이라는 환산을 극한 식 안에 남기면 다른 값이 나옵니다.

sec, csc, cot

sec x = 1/cos x, csc x = 1/sin x, cot x = cos x / sin x = 1/tan x

sec x와 tan x는 cos x = 0인 각 x = π/2 + nπ에서 정의되지 않습니다. csc x와 cot x는 sin x = 0인 각 x = nπ에서 정의되지 않습니다. 이 함수는 tan, cot의 도함수와 그 부정적분을 적기 위해 도입합니다.

함수도함수음이 붙는 곳
sin xcos x없음
cos x−sin x코사인의 미분에 음의 부호
tan xsec² x없음. 정의되는 구간에서 항상 양수
cot x−csc² x음의 부호
sec xsec x tan x없음
csc x−csc x cot x음의 부호

(tan x)'은 몫의 미분으로 확인합니다. (sin x / cos x)' = (cos²x + sin²x) / cos²x = 1/cos²x = sec² x입니다. (sec x)' = (cos x)−1의 합성 미분으로 sin x / cos² x = sec x tan x입니다.

3. 여러 가지 미분법

미분계수는 극한 f'(a) = limh→0 (f(a+h) − f(a))/h이고, 그 값이 모든 a에서 함수가 되면 도함수입니다. 미분가능하면 연속입니다. 역은 성립하지 않습니다.

지수·로그·삼각함수의 도함수

(ex)' = ex
(ax)' = ax ln a (a > 0, a ≠ 1)
(ln x)' = 1/x (x > 0)
(loga x)' = 1/(x ln a)
(ln|x|)' = 1/x (x ≠ 0)

(ex)'의 계산: (ex+h − ex)/h = ex (eh − 1)/h → ex · 1입니다. ax = ex ln a이므로 연쇄법칙을 쓰면 상수 ln a가 곱해집니다. (ln x)'은 정의로 보면 (ln(x+h) − ln x)/h = ln(1 + h/x) / h = [ln(1 + h/x) / (h/x)] · (1/x) → 1/x입니다. x < 0에서는 ln(−x)를 미분하면 마찬가지로 1/x가 나옵니다. 그래서 부정적분은 ln|x|입니다.

(sin x)'도 덧셈정리와 앞의 극한으로 나옵니다.

(sin(x+h) − sin x)/h = sin x · (cos h − 1)/h + cos x · (sin h)/h
(cos h − 1)/h = h · (cos h − 1)/h² → 0
따라서 (sin x)' = cos x, 같은 방식으로 (cos x)' = −sin x

곱, 몫, 합성

(fg)' = f'g + fg'
(f/g)' = (f'g − fg') / g² (g ≠ 0)
(f(g(x)))' = f'(g(x)) · g'(x)

곱은 각 인수를 한 번씩 미분해서 더합니다. 몫은 분자에 “분모 미분을 뺀” 순서입니다. 순서가 바뀌면 부호가 뒤집힙니다. 합성은 겉미분 곱하기 속미분입니다. 속을 미분하지 않으면 e2x의 도함수를 e2x로 쓰게 되고, 맞는 값은 2e2x입니다.

확인용으로 f(x) = x e−x를 두 가지로 미분해 봅니다. 곱으로 하면 e−x + x(−e−x) = e−x(1 − x)입니다. 몫 x/ex로 하면 (ex − x ex)/e2x = (1 − x)e−x입니다. 같습니다.

y = xx (x > 0)처럼 밑과 지수가 모두 변수이면 양변에 자연로그를 취합니다. ln y = x ln x, 양변을 미분하면 y'/y = ln x + 1이므로 y' = xx(ln x + 1)입니다. x = 1에서 기울기는 1입니다.

역함수

f가 미분가능하고, 어떤 구간에서 f' ≠ 0이면 그 구간에서 f는 일대일이라 역함수가 있습니다. y = f−1(x)의 그래프는 y = f(x)를 직선 y = x에 대해 대칭 이동한 것입니다. 접선의 기울기는 역수가 됩니다.

b = f(a), f'(a) ≠ 0일 때 (f−1)'(b) = 1 / f'(a)

점을 바꾸어 말하지 않습니다. 역함수의 미분계수를 구하는 x좌표는, 원래 함수의 y좌표입니다. f(2) = 5, f'(2) = 4이면 역함수의 x = 5에서 기울기는 1/4입니다. 1/f'(5)가 아닙니다.

f'(a) = 0이면 원래 접선이 수평이라, 대칭시킨 접선은 수직입니다. 그 점에서 역함수는 미분가능하지 않습니다. 예를 들어 x³의 역함수인 세제곱근은 x = 0에서 기울기가 무한대가 됩니다.

짧은 예: f(x) = x + ex이면 f'(x) = 1 + ex > 0이라 역함수가 있습니다. f(0) = 1, f'(0) = 2이므로 (f−1)'(1) = 1/2입니다.

음함수

F(x, y) = 0처럼 관계식으로만 주어진 곡선에서는 y를 x의 함수로 보고 양변을 x로 미분한 뒤 y'에 대해 정리합니다.

x² + y² = r² → 2x + 2y y' = 0 → y' = −x/y (y ≠ 0)

점 (√2/2, √2/2)에서 기울기는 −1이고, 접선은 y = −x + √2입니다. 반지름의 기울기 1과 곱이 −1이므로 접선과 반지름은 수직입니다. y = 0인 점에서는 공식이 몫을 만들지 못하고, 접선은 세로 방향입니다.

절차는 네 줄입니다. y를 x의 함수로 본다. 양변을 미분한다. y가 들어 있는 항에는 연쇄법칙으로 y'를 붙인다. y'로 정리한 뒤에 점의 좌표를 넣는다. 좌표를 먼저 넣어 y를 지워 버리면 미분할 대상이 사라집니다.

매개변수로 나타낸 함수

x = f(t), y = g(t)이고 dx/dt ≠ 0이면 y를 x의 함수로 볼 수 있고, 기울기는 매개변수의 변화율의 비입니다.

dy/dx = (dy/dt) / (dx/dt)
d²y/dx² = (d/dt (dy/dx)) / (dx/dt)
함정: 이계도함수를 (d²y/dt²) / (d²x/dt²)로 계산하면 틀립니다. 먼저 dy/dx를 t의 식으로 만든 다음, 그 식을 t로 미분하고, dx/dt로 다시 나눕니다.

x = t², y = t³, t = 2를 보겠습니다. dx/dt = 2t = 4, dy/dt = 3t² = 12, dy/dx = 12/4 = 3입니다. 점은 (4, 8), 접선은 y − 8 = 3(x − 4), 즉 y = 3x − 4입니다. dy/dx = 3t/2이므로 t로 미분하면 3/2, 이것을 dx/dt = 2t로 나누면 d²y/dx² = 3/(4t)입니다. t = 2에서 3/8입니다. 잘못된 비 (6t)/2 = 3t는 t = 2에서 6이 되어 3/8과 다릅니다. t = 0에서는 dx/dt = 0이라 이 공식을 쓰지 않습니다.

4. 접선, 증감, 오목·볼록, 그래프

접선의 방정식

곡선 y = f(x) 위의 점 (a, f(a))에서 기울기 f'(a)인 접선은 다음과 같습니다. 음함수·매개변수 곡선도 그 점의 기울기만 구하면 같은 모양입니다.

y − f(a) = f'(a) (x − a)

기울기가 m인 접선을 구하려면 f'(t) = m인 t를 먼저 찾고, 점 (t, f(t))를 접선 식에 넣습니다. y = ex의 기울기 2인 접선은 et = 2, t = ln 2, 점 (ln 2, 2)이므로 y − 2 = 2(x − ln 2)입니다.

곡선 밖의 점에서 그은 접선은, 접점을 (t, f(t))로 두고 그 접선이 주어진 점을 지나게 합니다. y = ln x에 원점에서 그은 접선은 접점 (t, ln t), 기울기 1/t입니다. 원점을 대입하면 −ln t = −1, t = e, 기울기 1/e, 접선은 y = x/e입니다. g(x) = ln x − x/e는 x = e에서만 0이고 그 점이 최댓값이므로, 직선과 곡선은 그 점에서만 만납니다.

두 곡선이 접한다는 것은 어떤 점에서 함숫값이 같고 도함수도 같다는 뜻입니다. f(a) = g(a)이고 f'(a) = g'(a)인 a가 있으면 그 점에서 공통 접선을 갖습니다.

증가·감소와 극값

구간에서 f'(x)가 양수이면 f는 그 구간에서 증가하고, 음수이면 감소합니다. 부호를 표로 남기는 것이 그래프 문항의 기본입니다.

f'의 부호 변화f이름
양수에서 음수로증가하다가 감소극대
음수에서 양수로감소하다가 증가극소
부호가 바뀌지 않음계속 증가 또는 감소극값 아님

f'(c) = 0은 극값의 충분조건이 아닙니다. f(x) = x³이면 f'(x) = 3x² ≥ 0이라 x = 0에서 도함수는 0이지만 부호가 바뀌지 않고, 함수는 계속 증가합니다. 극값이 없습니다. 반대로 f'(c) = 0이 아니어도, 도함수가 존재하지 않는 꺾인 점에서 극값이 생길 수 있습니다. 수능 그래프에서는 “부호가 바뀌는가”를 기준으로 봅니다.

이계도함수 판정은 지름길입니다. f'(c) = 0이고 f''(c) < 0이면 극대, f''(c) > 0이면 극소입니다. f''(c) = 0이면 이 판정은 침묵합니다. x³은 f''(0) = 0이고 극값이 없고, x⁴은 f''(0) = 0이지만 f'(x) = 4x³의 부호가 음에서 양으로 바뀌어 극소입니다.

오목·볼록과 변곡점

f''(x) > 0 → 아래로 볼록 (접선이 곡선의 아래, 물이 고이는 모양)
f''(x) < 0 → 위로 볼록 (접선이 곡선의 위)
변곡점: f''의 부호가 바뀌는 점

f''(c) = 0만으로는 변곡점이 아닙니다. x⁴은 f''(x) = 12x² ≥ 0이라 x = 0에서 이계도함수가 0이지만 부호가 바뀌지 않습니다. 변곡점이 아닙니다. x³은 f''(x) = 6x라서 x = 0의 좌우에서 부호가 바뀝니다. 변곡점이고, 그 접선 y = 0은 곡선을 관통합니다.

f'의 그래프가 주어졌을 때의 읽기 규칙은 다음과 같습니다.

  • f'이 x축보다 위에 있는 구간에서 f는 증가하고, 아래에서 감소합니다.
  • f'이 위쪽에서 아래쪽으로 x축을 통과하면 f는 극대, 아래에서 위로 통과하면 극소입니다. 접고 되돌아가면 극값이 아닙니다.
  • f' 자신이 증가하는 구간에서 f는 아래로 볼록, 감소하는 구간에서 위로 볼록입니다. f'의 극점은 f의 변곡점 후보입니다.

개형을 그리는 순서

  1. 정의역, 대칭(우함수·기함수), 주기를 적습니다.
  2. x절편, y절편을 구합니다.
  3. x → ±∞와 정의역의 경계에서 극한을 구해 점근선을 표시합니다. 분자 차수가 분모보다 1 크면 나눗셈으로 일차 점근선을 얻습니다. (x² + 1)/x = x + 1/x의 점근선은 y = x입니다.
  4. f'의 부호표로 증감과 극값을 적습니다.
  5. f''의 부호표로 오목·볼록과 변곡점을 적습니다.
  6. 극값의 y좌표와 점근선을 한 그림에 모읍니다.

표준 개형 두 개만 확실히 잡아 둡니다. y = ex는 점 (0, 1)을 지나고, 증가하며 아래로 볼록하고, x → −∞일 때 x축에 붙습니다. y = ln x는 점 (1, 0)을 지나고, 증가하며 위로 볼록하고(이계도함수 −1/x² < 0), x → 0⁺에서 음의 무한대입니다. 둘은 y = x에 대해 대칭입니다.

f(x) = x e−x로 순서를 한 번 밟겠습니다. f'(x) = e−x(1 − x)이므로 x < 1에서 증가, x > 1에서 감소, x = 1에서 극대이고 극댓값은 1/e입니다. f''(x) = e−x(x − 2)이므로 x < 2에서 위로 볼록, x > 2에서 아래로 볼록, 변곡점은 (2, 2/e²)입니다. x → ∞이면 0에 붙습니다. 먼저 g(u) = eu − u − 1로 두면 g(0) = 0, g'(u) = eu − 1이라 u < 0에서 g는 감소, u > 0에서 증가합니다. 최솟값이 0이므로 eu ≥ 1 + u입니다. u = x/2 > 0이면 ex/2 ≥ 1 + x/2이고, 양변은 양수이므로 제곱하면 ex ≥ (1 + x/2)² = 1 + x + x²/4 ≥ x²/4입니다. 따라서 0 < x e−x ≤ 4/x → 0입니다. x → −∞이면 x는 음으로, e−x는 양으로 매우 커져 f(x) → −∞입니다. 방정식 x e−x = k의 실근 개수는 이 개형과 수평선 y = k의 교점 개수입니다. k > 1/e이면 0개, k = 1/e이면 1개, 0 < k < 1/e이면 2개, k = 0이면 x = 0 하나, k < 0이면 1개입니다.

5. 방정식·부등식, 속도와 가속도

방정식과 부등식

방정식 f(x) = k의 실근 개수는 y = f(x)와 직선 y = k의 교점 개수입니다. f(x) = g(x)는 y = f(x) − g(x)와 x축의 교점으로 옮깁니다. 부등호 f(x) ≥ k가 모든 실수에서 성립하려면, 최솟값이 존재할 때 그 최솟값이 k 이상이면 됩니다.

ex ≥ 1 + x (모든 실수, 등호는 x = 0)
ln x ≤ x − 1 (x > 0, 등호는 x = 1)

첫째는 그래프 개형에서 x e−x → 0을 보일 때 확인한 부등식입니다. g(x) = ex − x − 1의 최솟값이 0이기 때문입니다. 둘째는 p(x) = x − 1 − ln x의 도함수 p'(x) = 1 − 1/x가 x < 1에서 음, x > 1에서 양이라 최솟값 p(1) = 0이라는 사실입니다.

직선과 곡선의 교점 개수는 극값과 기울기를 비교합니다. ex = kx에서 k > 0이면 h(x) = ex − kx의 도함수 ex − k가 0이 되는 점은 x = ln k 하나이고, 그 점이 최솟값입니다. 최솟값 k(1 − ln k)가 음이 되려면 k > e, 0이면 k = e, 양이면 0 < k < e입니다. h는 양 끝에서 양의 무한대로 가므로 실근은 k > e일 때 2개, k = e일 때 1개(x = 1에서 접함), 0 ≤ k < e일 때 0개입니다. k < 0이면 h'이 항상 양수이고 h가 단조증가하므로 실근은 1개입니다. k = e인 접선은 y = ex이고, 접점은 (1, e)입니다.

직선 운동의 속도·가속도

수직선 위를 움직이는 점의 위치가 x(t)일 때 속도와 가속도는 도함수입니다. 속도는 부호가 있는 변화율이고, 속력은 그 절댓값입니다.

속도 v(t) = x'(t), 속력 |v(t)|, 가속도 a(t) = v'(t) = x''(t)
부호의미
v > 0양의 방향으로 운동
v < 0음의 방향으로 운동
v = 0이고 부호가 바뀜운동 방향이 바뀌는 시각
v = 0이지만 부호가 그대로순간적으로 속력만 0, 방향은 유지
v와 a의 부호가 같음속력이 증가 (빨라짐)
v와 a의 부호가 다름속력이 감소 (느려짐)
함정: 가속도가 음수라는 문장만으로 속력이 줄어든다고 말할 수 없습니다. 속도도 음수이면 음의 방향으로 더 빨라집니다. 속력의 증감은 속도의 부호와 가속도의 부호가 같은지로 판정합니다.

x(t) = sin t + cos t = √2 sin(t + π/4)를 보겠습니다. v(t) = cos t − sin t, a(t) = −sin t − cos t입니다. t = 0에서 x = 1, v = 1, a = −1입니다. 양의 방향으로 가지만 속력은 줄어듭니다. t = π/4에서 v = 0, x = √2이고, 그 전후 v의 부호가 양에서 음으로 바뀌므로 방향이 바뀌고 위치는 극대입니다. t = π/2에서 v = −1, a = −1이라 음의 방향으로 속력이 증가합니다.

수능에서 묻는 방식

  • 접선의 기울기 조건. f'(t) = m을 풀거나, 두 곡선의 함숫값과 도함수를 동시에 같게 둡니다. 밖의 점에서 그으면 접점의 좌표를 미지수로 남깁니다.
  • 극값의 개수. f'(x) = 0의 근 개수가 아니라, f'의 부호가 실제로 바뀌는 점의 개수입니다. 매개변수 k가 있으면 극댓값·극솟값과 k의 위치를 비교해 교점 개수를 센다.
  • 변곡점 조건. f''(c) = 0인 후보를 구한 뒤 좌우에서 f''의 부호가 바뀌는지 확인합니다. 바뀌지 않으면 탈락입니다.
  • 합성함수의 미분값. (f∘g)'(a) = f'(g(a)) g'(a). 그래프가 주어지면 g(a)의 높이를 읽고, 그 높이에서 f의 기울기를 읽은 다음 g의 기울기를 곱합니다.
  • 역함수의 미분값. 점 (a, b)에서의 기울기가 m이면, 역함수 위의 점 (b, a)에서 기울기는 1/m입니다. m = 0이면 미분가능하지 않습니다.
  • 그래프 추론. f'의 부호로 f의 증감, f'의 증감으로 f의 오목·볼록을 복원합니다. 극값의 y좌표는 문제의 다른 조건(함수식, 정적분, 통과하는 점)으로 확정합니다.

자주 나오는 함정

  • 도를 라디안으로 착각하기. x → 0일 때 sin x / x → 1은 라디안일 때만 성립합니다.
  • 코사인·코시컨트·코탄젠트의 미분 부호를 빼먹기. (cos x)' = −sin x, (csc x)' = −csc x cot x, (cot x)' = −csc² x입니다.
  • 몫의 미분에서 분자 순서를 바꾸거나, 합성에서 속미분을 빼먹기. 분자는 f'g − fg'이고, (e2x)' = 2e2x입니다.
  • 역함수의 점을 혼동하기. f(a) = b, f'(a) = m이면 역함수의 미분계수는 x = b에서 1/m입니다. 1/f'(b)가 아닙니다.
  • 매개변수 이계도함수를 y''(t)/x''(t)로 계산하기. dy/dx를 먼저 t의 식으로 만든 뒤, 그 식을 t로 미분하고 dx/dt로 나눕니다.
  • f'(c) = 0이면 극값, f''(c) = 0이면 변곡점이라고 단정하기. x³은 전자의 반례, x⁴은 후자의 반례입니다. 부호가 바뀌어야 합니다.
  • 가속도가 음수이면 속력이 줄어든다고 보기. 속도도 음수이면 속력은 증가합니다. 부호가 같은지로 판정합니다.
  • 아래로 볼록과 위로 볼록을 바꾸기. f''이 양수이면 아래로 볼록입니다. 접선이 곡선 아래에 있습니다.

대표 예제

눌러서 풀이를 펼치세요.

x가 0으로 갈 때 (e^(2x) − 1) / sin 3x 의 극한값은?

표준 극한으로 맞춥니다.

(e2x − 1) / sin 3x = [(e2x − 1)/(2x)] · 2x / sin 3x

= [(e2x − 1)/(2x)] · 2 · (1/3) · (3x / sin 3x)

x → 0이면 각 인수는 1, 2·(1/3), 1로 갑니다. 극한값은 2/3입니다.

각은 라디안입니다. sin 3x를 3x로 바꾸는 상수 3을 분자에 남기지 않으면 2가 되어 틀립니다.

f(x) = e^(2x) sin x 일 때 f'(0)과 f''(0)은?

곱의 미분입니다. f'(x) = 2e2x sin x + e2x cos x = e2x(2 sin x + cos x)입니다.

f'(0) = 1 · (0 + 1) = 1입니다.

다시 곱합니다. f''(x) = 2e2x(2 sin x + cos x) + e2x(2 cos x − sin x)

= e2x[4 sin x + 2 cos x + 2 cos x − sin x] = e2x(3 sin x + 4 cos x)입니다.

f''(0) = 1 · (0 + 4) = 4입니다.

곡선 x² + xy + y² = 7 위의 점 (2, 1)에서 접선의 방정식은?

점이 곡선 위인지 먼저 확인합니다. 4 + 2 + 1 = 7입니다.

y를 x의 함수로 보고 미분하면 2x + (y + x y') + 2y y' = 0입니다.

2x + y + (x + 2y) y' = 0이므로 y' = −(2x + y)/(x + 2y)입니다. x + 2y ≠ 0인 점에서만 이 식을 씁니다.

(2, 1)에서 y' = −(4 + 1)/(2 + 2) = −5/4입니다.

접선은 y − 1 = (−5/4)(x − 2), 즉 y = −(5/4)x + 7/2입니다. 정수 계수로 쓰면 5x + 4y − 14 = 0입니다. 점 (2, 1)을 넣으면 10 + 4 − 14 = 0입니다.

f(x) = x e^(−x)의 극댓값과 변곡점의 좌표는?

f'(x) = e−x − x e−x = e−x(1 − x)입니다. e−x은 항상 양수이므로 부호는 1 − x가 결정합니다.

x < 1에서 f' > 0, x > 1에서 f' < 0입니다. x = 1에서 극대이고, 극댓값은 f(1) = 1/e입니다.

f''(x) = −e−x(1 − x) + e−x(−1) = e−x(x − 2)입니다.

x < 2에서 f'' < 0, x > 2에서 f'' > 0이므로 부호가 바뀝니다. 변곡점은 (2, 2/e²)입니다. f''(2) = 0이면서 부호가 바뀌므로 변곡점 조건을 둘 다 만족합니다.

한 줄

겉을 미분하고 속을 곱합니다. 역함수의 기울기는 역수, 음함수는 양변을 미분한 뒤 y'로 정리, 매개변수는 변화율의 비입니다.

  • x → 0이면 (sin x)/x → 1, (ex − 1)/x → 1입니다. 각은 라디안입니다.
  • f'의 부호가 바뀌면 극값, f''의 부호가 바뀌면 변곡점입니다.
  • f''이 양수이면 아래로 볼록입니다.
  • 속력이 늘고 줄고는 속도와 가속도의 부호가 같은지로 봅니다.
고급

그래프 추론은 f의 식이 없어도 됩니다. f' 그래프에서 증감을 읽고, f'의 증감에서 오목·볼록을 읽습니다. 합성 (f∘g)'(a)는 g(a)를 먼저 구한 뒤 그 점의 f'과 g'(a)를 곱하는 순서를 고정합니다. 역함수는 점을 (a, b)에서 (b, a)로 뒤집은 다음 기울기만 역수로 취합니다.

극값 개수·교점 개수는 함수를 직접 풀지 않고, 도함수의 영점과 극값의 높이를 수평선 y = k와 비교합니다. 접선 조건이 있으면 “만나는 점”과 “기울기가 같은 점”을 같은 문자로 두어 두 식을 연립합니다. 매개변수 이계도함수는 dy/dx를 t로 나타낸 뒤에만 한 번 더 미분합니다.
