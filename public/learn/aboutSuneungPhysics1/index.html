이 단원은 결국 이걸 배운다

단원마다 한 줄입니다. 줄마다 내 정답률이 같이 보이니, 낮은 단원은 이름을 눌러 노트를 다시 보고 기출로 그 유형 문제를 다시 풉니다.

운동
속도와 가속도로 위치를 예측한다
s = v0 + v2 t, v = v0 + at
기출 →
뉴턴 법칙
힘이 가속도를 만든다 (알짜힘이 0이면 속도가 그대로다)
F = ma
기출 →
운동량
충돌해도 운동량의 합은 그대로다
p = mv, I = FΔt = Δp
기출 →
역학적 에너지
마찰이 없으면 운동 에너지와 퍼텐셜 에너지의 합은 그대로다 (마찰이 있으면 그만큼 줄어든다)
Ek + Ep = 일정
기출 →
열역학
받은 열 = 내부 에너지 증가 + 한 일. 열기관은 받은 열의 일부만 일로 바꾼다
Q = ΔU + W, e = WQ1
기출 →
특수 상대성
빛의 속력은 누구에게나 같다 → 움직이는 쪽의 시간은 느리게 가고 길이는 짧아진다 (수능은 계산보다 누가 더 길고 짧은지를 묻는다)
Δt = γΔt0, L = L0/γ
기출 →
핵반응
질량수와 전하량은 보존되고, 줄어든 질량이 에너지가 된다
E = Δmc2
기출 →
원자·스펙트럼
전자는 정해진 에너지 준위에만 있고, 준위를 옮길 때 그 차이만큼의 빛을 내거나 흡수한다
ΔE = hf = hcλ
기출 →
반도체
띠 간격이 전기 전도성을 정하고, 다이오드는 한 방향으로만 전류가 흐른다
순방향: p형에 (+), n형에 (−)
기출 →
전기력
전하 사이의 힘은 전하량의 곱에 비례하고 거리의 제곱에 반비례한다
F = k q1q2r2
기출 →
전류의 자기장
전류가 자기장을 만든다 (방향은 오른손으로)
직선 도선 B = k Ir
기출 →
자성체
강자성체는 자석을 치워도 자성이 남고, 상자성체는 사라지고, 반자성체는 반대 방향으로 자기화된다
기출 →
전자기 유도
코일을 지나는 자기 선속이 변하면, 그 변화를 방해하는 방향으로 전류가 흐른다
V = −N ΔΦΔt
기출 →
파동·굴절
매질이 바뀌어도 진동수는 그대로이고 속력과 파장이 바뀐다. 느린 매질에서 빠른 매질로 임계각보다 크게 들어가면 전반사한다
v = fλ, sin isin r = v1v2 (각은 법선 기준)
기출 →
전자기파
파장이 짧을수록 진동수와 에너지가 크다. 종류마다 쓰이는 곳이 다르다
감마선 < X선 < 자외선 < 가시광선 < 적외선 < 마이크로파 < 라디오파 (파장)
기출 →
간섭
두 파동이 겹치면 커지거나(보강) 없어진다(상쇄)
마루+마루·골+골 / 마루+골
기출 →
이중성
빛은 입자처럼(광전 효과), 입자는 파동처럼(물질파) 군다
E = hf, λ = hp = hmv

이 노트가 다루는 것

수능 물리학Ⅰ의 전 범위를 세 단원, 일곱 파트로 나눠 정리했습니다. 각 파트는 개념 정리 → 그래프·표 읽는 법 → 기출에서 반복되는 함정 → 대표 예제 → 짝짓기·퀴즈 → 실제 기출 풀어보기 순으로 이어집니다. 파트마다 모션 노트의 해당 장면으로 바로 이동할 수 있습니다.
