이 노트가 다루는 것

수능 물리학Ⅰ의 전 범위를 세 단원, 일곱 파트로 나눠 정리했습니다. 각 파트는 개념 정리 → 그래프·표 읽는 법 → 기출에서 반복되는 함정 → 대표 예제 → 짝짓기·퀴즈 → 실제 기출 풀어보기 순으로 이어집니다. 파트마다 모션 노트의 해당 장면으로 바로 이동할 수 있습니다.
