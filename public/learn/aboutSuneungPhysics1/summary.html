💥운동량과 충격량

p = mv (벡터)
I = FΔt = Δp = mv′ − mv

분열

⚠ 이 파트 함정 — 이렇게 속입니다

  • 최고점에서 가속도 0→속도만 0, 가속도는 g
  • 작용·반작용 = 힘의 평형→같은 물체에 작용하는지부터 확인
  • 비탄성 충돌에서 K 보존→p만 보존
  • 부호를 무시한 v′→반대로 튀면 v′는 음수, x축 아래 넓이는 음의 변위
  • 충돌 중 두 물체가 받는 힘이 다르다→크기는 항상 같음
  • 외력이 있어도 p 보존→벽·바닥이 외력이면 성립 안 함

수능은 이렇게 묻는다v–t 그래프의 기울기·넓이 → 연결된 물체의 a와 T → 충돌·분열에서 운동량 보존(부호 주의)

⚠ 자주 걸리는 함정

  • 최고점에서 가속도 0이라는 보기 — 속도만 0입니다. 가속도는 g.
  • 작용·반작용을 힘의 평형으로 읽기 — 같은 물체에 작용하는지 먼저 확인.
  • 비탄성 충돌에서 K가 보존된다는 보기 — p만 보존됩니다.
  • 부호 실수 — 반대 방향으로 튀어 나오는 물체의 v′는 음수입니다. v–t 그래프에서 x축 아래 넓이는 음(−)의 변위입니다.
  • 충돌 중 두 물체가 받는 힘이 다르다는 보기 — 크기는 항상 같습니다.
  • 운동량 보존은 외력이 있으면 성립하지 않습니다. 바닥과 붙어 있는 계, 벽과의 충돌은 벽이 외력을 줍니다.

Part 2 · 에너지와 열

Ⅰ. 역학과 에너지 · 역학적 에너지 보존 · 열역학 제1법칙 · 열기관

📌 한눈에 요약에너지는 사라지지 않고 모양만 바뀐다 — 표 하나로 열역학 그래프 끝회당 평균 1.7문항 · 4.3점

⚡일과 역학적 에너지

W = Fs cosθ K = ½mv²
U = mgh U = ½kx²
W알짜 = ΔK (일·에너지 정리)
보존력만
E = K + U 일정 — 경로의 모양·길이·시간은 무관, 같은 높이면 같은 속력
마찰
사라지는 게 아니라 열로 전환, 손실 ΔE = 마찰력 × 구간 길이
  1. 높이 h에서 출발v² = 2gh
  2. 마찰 구간 L 통과v′² = 2gh − 2μgL

🌀용수철

½kx² = ½mv² (압축 x → 속력 v)
속력 최대
용수철을 벗어나는 순간(탄성 에너지 → 운동 에너지)
최대 압축
두 물체가 부딪혀 용수철이 가장 줄었을 때 → 두 물체의 속도가 같음

💡줄어든 운동 에너지가 탄성 에너지로 저장된 순간입니다.

🌡️열과 온도

Q = cmΔT = CΔT (C: 열용량)
열평형: 고온이 잃은 열 = 저온이 얻은 열
같은 열
온도 변화는 열용량 C에 반비례
열의 이동
항상 고온 → 저온 (자발적)

🔄열역학 제1법칙 — 네 과정

Q = ΔU + W (Q: 흡수한 열, ΔU: 내부 에너지 증가, W: 기체가 한 일)
이상 기체의 U ∝ T (온도만의 함수)
과정성질WΔUQ
등적V 일정0= QT↑이면 흡열
등압P 일정PΔV (팽창 +)T에 비례ΔU + PΔV
등온T 일정= Q0팽창하면 흡열
단열Q = 0= −ΔU팽창하면 감소0

🏭열기관과 열효율

e = W / Q고 = 1 − Q저 / Q고 W = Q고 − Q저
e < 1
열을 전부 일로 바꾸는 기관은 없음 (제2법칙)
순환 과정
P–V 그래프가 둘러싼 넓이 = 알짜 일, 과정마다 Q의 부호(흡열/방열)부터 표시 → 흡열의 합 = Q고

⚠ 이 파트 함정 — 이렇게 속입니다

  • 단열 팽창에서 열 흡수→Q = 0, 일을 한 만큼 U 감소 → 온도 하강
  • 등온 팽창에서 U 증가→U 불변, 흡수한 열이 전부 일
  • 경로가 길수록 / 가파를수록 속력이 크다→마찰 없으면 높이 차이로만 결정
  • 마찰 구간에서 에너지가 사라진다→열로 전환, 전체 에너지는 보존
  • 열효율의 분모에 방열 Q→분모는 고열원에서 받은 열 Q고

수능은 이렇게 묻는다역학적 에너지 보존 + 마찰 구간 → P–V 그래프의 과정별 W·ΔU·Q 부호 → 순환 과정의 열효율

📋 본문에서 뽑은 공식·표 시트 펼치기

일과 에너지

W = Fs cosθ
운동 에너지 K = ½mv²
중력 퍼텐셜 에너지 U = mgh
탄성 퍼텐셜 에너지 U = ½kx²
일·에너지 정리: W알짜 = ΔK

역학적 에너지 보존

마찰이 있는 구간

높이 h에서 정지 출발 → 마찰 없는 바닥: v² = 2gh
길이 L, 마찰 계수 μ인 수평 구간 통과 후: v′² = 2gh − 2μgL

열과 온도

열량 Q = cmΔT = CΔT (C: 열용량)
열평형 온도: 고온 물체가 잃은 열 = 저온 물체가 얻은 열

열역학 제1법칙

Q = ΔU + W
(Q: 기체가 흡수한 열, ΔU: 내부 에너지 증가, W: 기체가 외부에 한 일)
과정성질WΔUQ
등적V 일정0= QT 오르면 흡열
등압P 일정PΔV (팽창하면 +)T에 비례= ΔU + PΔV
등온T 일정= Q0팽창하면 흡열
단열Q = 0= −ΔU팽창하면 감소0 (열 출입 없음)

열기관과 열효율

열효율 e = W / Q고 = 1 − Q저 / Q고

핵심 용어

용어뜻
단열 팽창Q=0, 온도 하강
등온 팽창ΔU=0, 흡열=일
등적 과정W=0
열효율W/Q고
마찰 구간 손실마찰력 × 길이

⚠ 자주 걸리는 함정

  • 단열 팽창에서 열을 흡수한다 — Q = 0입니다. 팽창하며 일을 한 만큼 내부 에너지가 줄어 온도가 내려갑니다.
  • 등온 팽창에서 내부 에너지가 증가 — 변하지 않습니다. 흡수한 열이 전부 일로 나갑니다.
  • 경로가 길수록 속력이 커진다(또는 빗면이 가파를수록 나중 속력이 크다) — 마찰이 없으면 높이 차이로만 결정됩니다.
  • 마찰 구간에서 역학적 에너지가 사라진다 — 열로 전환된 것이며, 전체 에너지는 보존됩니다.
  • 열효율은 흡수한 열이 아니라 ‘고열원에서 받은 열’ 기준입니다. 방열 과정의 Q를 분모에 넣지 마세요.

⚠ 이 파트 함정 — 이렇게 속입니다

  • 운동하는 쪽이 재면 항상 고유 시간→두 사건이 같은 위치에서 일어난 관성계
  • 길이 수축은 모든 방향→운동 방향만, 고유 길이 대비
  • 빛의 속력은 관찰자마다 다르다→어느 관성계에서도 c
