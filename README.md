# Nanamate Lab

지식마다 다른 게임을 둔다. 퀴즈 스킨이 아닙니다.

과목당 9장. 수능 23과목은 **기본 / 심화** 두 난이도입니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:8080` 을 엽니다.

```bash
npm run build
npm run typecheck
```
